## Points for T3.2 that are not renames

- The 13.5 snippet calls `load(model_id)`, which can contact the Hub. Under D23, set
  `HF_HUB_OFFLINE=1` and `HF_HUB_DISABLE_TELEMETRY=1` before importing the Hub library, resolve
  the pinned snapshot with `huggingface_hub.snapshot_download(repo_id, revision=<commit>,
  local_files_only=True)`, and pass that directory to `load`, as the smoke script does.
- `peak_memory` is in GB. The smoke script reports MB as GB x 1000, and the measured value was in
  the expected range (300 to 8000 MB). The `generation_attempts.peak_memory_mb` column (section
  8.1) needs the same conversion; the snippet's `peak_memory_gb` name does not match it.
- `LLMOutput` is not defined in the design doc, `complete`'s parameters are untyped (section 17.1
  requires types and pyright strict in `src/`), and `last` is `None` when the stream yields
  nothing. The smoke script raises in that case.
- `mx.random.seed` sets MLX's global random state. The caller passes the seed in (CLAUDE.md), and
  it is set right before each generation.
- Llama 3.x chat templates may insert the current date into the prompt, so the determinism
  results above hold for one day only.

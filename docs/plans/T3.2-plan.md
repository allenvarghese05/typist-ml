# T3.2 Implementation Plan — MLXRuntime, prompt v1, LLM generator

## 1. Summary

This plan implements `Arm.LLM` (the fourth and final drill generator in Typist-ML):
- Adds the 6 frozen LLM configuration keys to `experiment_config` via Alembic migration `0010_llm_config`.
- Implements Prompt v1 templates, dynamic bigram prompt formatting, and post-processing (character cleaning and word-boundary truncation preserving tokens for the validator's real-word ratio gate).
- Builds `MLXRuntime` (offline local model execution via `mlx-lm` on Apple Silicon with lazy dynamic imports to ensure Linux CI safety) and `FakeLLMRuntime` (for fast deterministic tests).
- Implements `LLMGenerator` satisfying `DrillGenerator`, populating `model_id`, `prompt_version`, `gen_ms`, `gen_tokens`, `tokens_per_sec`, and `peak_memory_mb` in `DrillCandidate` and persisting them to `generation_attempts`.
- Wires `Arm.LLM` into `worker.py::build_default_generators` with dependency injection for testability and graceful fallback when un-cached off-Mac.

## 2. Design

### Key decisions and rationale

1. **Protocol-based runtime abstraction (`LLMRuntimeProtocol`).**
   `CLAUDE.md` mandates: *"Code that talks to the model goes through MLXRuntime; tests use a fake runtime."*
   `LLMRuntimeProtocol` defines `complete(messages, *, max_tokens, temp, top_p, seed) -> LLMOutput`.
   `MLXRuntime` implements this protocol for Apple Silicon execution using `mlx-lm`. `FakeLLMRuntime` implements it for unit tests and CI.
   *Rejected alternative:* Direct instantiation of `mlx_lm` inside `LLMGenerator`, which would require monkeypatching global module state and risk leaking `mlx` imports onto Linux CI.

2. **Lazy, dynamic module loading for `mlx`, `mlx_lm`, and `huggingface_hub`.**
   Cloud CI and developer containers run on Linux x86_64 where `mlx` and `mlx-lm` cannot be installed. `src/` is strictly type-checked under `pyright` strict mode. All imports of `mlx.core`, `mlx_lm`, and `huggingface_hub` are performed lazily inside `MLXRuntime` methods using `importlib.import_module` with explicit type annotations. Importing `typist.generation.llm` or `typist.worker` never imports `mlx` at module level.
   *Rejected alternative:* Top-level `try: import mlx except ImportError:` which triggers pyright `reportMissingImports` errors on Linux CI.

3. **Offline Hugging Face Hub isolation (D19, D23).**
   `configure_hub_env(offline=True)` sets `HF_HUB_DISABLE_TELEMETRY=1` and `HF_HUB_OFFLINE=1` before `huggingface_hub` is imported. Model weights are resolved from the local cache (`~/.cache/huggingface/hub`) using `snapshot_download(..., local_files_only=True)`. If weights are missing, `ModelNotDownloadedError` is raised with a clear message directing the user to run `just mlx-smoke --download`.
   *Rejected alternative:* Allowing `local_files_only=False` or network lookups during generation, violating D19.

4. **Post-processing and validator responsibility split (Owner Answers 1 & 2).**
   `clean_llm_output()` cleans characters (lowercasing, replacing non-`[a-z]` with space, collapsing spaces) and truncates at a word boundary to $\le 300$ characters. It does NOT drop non-dictionary words. Words are left intact in `candidate.text` so that `validator.validate()` measures `real_word_ratio` against the unified 20,000-word vocabulary (`WordIndex.words`) and strictly enforces the `drill_min_real_word_ratio` (0.8) gate on `Arm.LLM`.
   *Rejected alternative:* Filtering non-dictionary words in the generator, which would artificially make `real_word_ratio` always 1.0 and render the validator's fairness gate inert.

5. **Prompt v1 formatting and few-shot consistency (Owner Answer 4).**
   Target bigrams are interpolated via `", ".join(spec.target_bigrams)` (e.g. `"ck, ow"` or `"th, ea, in, st"`). The few-shot assistant example turn provides lowercase single-spaced words without punctuation, reinforcing the system constraint.

6. **Worker wiring and testability (Owner Answer 5).**
   `build_default_generators` accepts an optional `runtime: LLMRuntimeProtocol | None = None`. If provided, `Arm.LLM` is registered with the injected runtime. If omitted, it inspects `is_apple_silicon()` and checks if the local model snapshot directory exists. If available, `MLXRuntime` is instantiated; otherwise `Arm.LLM` is omitted, allowing Linux CI and non-LLM worker tests to pass cleanly.

  ```python
  """Prompt v1 templates and message construction for Arm.LLM (design doc 13.5).

  Constructs the chat-formatted messages for Prompt v1 with few-shot example turn:
  - System message specifying lowercase English words with single spaces and no punctuation.
  - User few-shot turn requesting words containing 'ck, ow'.
  - Assistant few-shot turn demonstrating the output without punctuation.
  - User turn interpolating the drill's target bigrams separated by comma-space.
  """

  from collections.abc import Sequence
  from typing import Final

  PROMPT_VERSION_V1: Final[str] = "v1"

  PROMPT_V1_SYSTEM: Final[str] = (
      "You write typing practice text. Reply with one line of lowercase English words "
      "separated by single spaces. No punctuation, numbers, quotes or explanations."
  )

  PROMPT_V1_EXAMPLE_USER: Final[str] = (
      "Write 60 common English words. Many words must contain these letter pairs: ck, ow. "
      "Each pair should appear at least 3 times. Real words only."
  )

  PROMPT_V1_EXAMPLE_ASSISTANT: Final[str] = (
      "back know clock snow check brown quick below track show neck grow"
  )

  PROMPT_V1_USER_TEMPLATE: Final[str] = (
      "Write 60 common English words. Many words must contain these letter pairs: {bigrams}. "
      "Each pair should appear at least 3 times. Real words only."
  )


  def format_target_bigrams(target_bigrams: Sequence[str]) -> str:
      """Format target bigrams as comma-space separated string (owner answer 4)."""
      return ", ".join(target_bigrams)


  def build_prompt_v1_messages(target_bigrams: Sequence[str]) -> list[dict[str, str]]:
      """Build the 4-message Prompt v1 payload for chat-templated models."""
      formatted = format_target_bigrams(target_bigrams)
      user_content = PROMPT_V1_USER_TEMPLATE.format(bigrams=formatted)
      return [
          {"role": "system", "content": PROMPT_V1_SYSTEM},
          {"role": "user", "content": PROMPT_V1_EXAMPLE_USER},
          {"role": "assistant", "content": PROMPT_V1_EXAMPLE_ASSISTANT},
          {"role": "user", "content": user_content},
      ]
  ```

  ```python
  """Post-processing for LLM generated text (design doc 13.5; owner answers 1 and 2).

  Transforms raw model text into valid typing practice candidate text:
  1. Lowercase ASCII conversion.
  2. Any character outside [a-z] is replaced with a space (stripping punctuation, digits, quotes).
  3. Consecutive whitespace is collapsed to single spaces and stripped from ends.
  4. Truncates cleanly at a word boundary to max_chars (default 300).
  5. Leaves words intact so validator.validate() measures real_word_ratio and applies the gate.
  """

  import re
  from typing import Final

  _NON_AZ_PATTERN: Final[re.Pattern[str]] = re.compile(r"[^a-z]+")


  def clean_llm_output(raw_output: str, max_chars: int = 300) -> str:
      """Clean and truncate raw LLM output at a word boundary up to max_chars.

      Returns lowercase words separated by single spaces. Does not drop non-dictionary words;
      the validator evaluates real_word_ratio against WordIndex.words.
      """
      lowered = raw_output.lower()
      spaced = _NON_AZ_PATTERN.sub(" ", lowered).strip()
      if not spaced:
          return ""
      words = spaced.split()
      selected: list[str] = []
      length = 0
      for word in words:
          addition = len(word) + (1 if selected else 0)
          if length + addition > max_chars:
              break
          selected.append(word)
          length += addition
      return " ".join(selected)
  ```

  Create `services/api/src/typist/generation/llm/runtime.py`:
  ```python
  """Model runtime protocol and MLX implementation for Arm.LLM (design doc 13.5; D09, D23).

  Provides:
  - LLMOutput: dataclass holding completion text and audit metrics (tokens, tokens_per_sec,
    peak_memory_mb, gen_ms).
  - LLMRuntimeProtocol: protocol required by LLMGenerator.
  - MLXRuntime: loads local Apple Silicon model snapshot offline via mlx-lm with lazy dynamic
    imports to preserve Linux CI compatibility.
  - FakeLLMRuntime: configurable test runtime that generates deterministic outputs without models.
  """

  import importlib
  import os
  import platform
  import sys
  import time
  from collections.abc import Sequence
  from dataclasses import dataclass
  from pathlib import Path
  from typing import Any, Protocol, runtime_checkable

  DEFAULT_MODEL_ID = "mlx-community/Llama-3.2-1B-Instruct-4bit"
  DEFAULT_MODEL_REVISION = "08231374eeacb049a0eade7922910865b8fce912"


  class ModelNotDownloadedError(RuntimeError):
      """Raised when the requested model snapshot is missing from the local Hugging Face cache."""


  @dataclass(frozen=True)
  class LLMOutput:
      """Result of one model completion call with performance metrics."""

      text: str
      tokens: int
      tokens_per_sec: float
      peak_memory_mb: float
      gen_ms: float = 0.0


  @runtime_checkable
  class LLMRuntimeProtocol(Protocol):
      """Contract for LLM execution wrappers."""

      def complete(
          self,
          messages: Sequence[dict[str, str]],
          *,
          max_tokens: int = 160,
          temp: float = 0.8,
          top_p: float = 0.9,
          seed: int = 0,
      ) -> LLMOutput: ...


  def is_apple_silicon() -> bool:
      """Return True if running on macOS on Apple Silicon (arm64)."""
      return sys.platform == "darwin" and platform.machine() == "arm64"


  def configure_hub_env(*, offline: bool = True) -> None:
      """Configure Hugging Face Hub environment variables (D23)."""
      os.environ["HF_HUB_DISABLE_TELEMETRY"] = "1"
      os.environ["HF_HUB_OFFLINE"] = "1" if offline else "0"


  def gb_to_mb(gb: float) -> float:
      """Convert peak memory from GB to MB (GB * 1000.0), rounded to 1 decimal place."""
      return round(gb * 1000.0, 1)


  def resolve_model_snapshot(model_id: str, revision: str) -> Path:
      """Resolve local cache snapshot path; raises ModelNotDownloadedError if not present."""
      configure_hub_env(offline=True)
      try:
          hub: Any = importlib.import_module("huggingface_hub")
          snapshot_download = hub.snapshot_download
      except ImportError as exc:
          raise RuntimeError("huggingface_hub is not installed; run with --extra mlx") from exc
      try:
          path = snapshot_download(
              repo_id=model_id,
              revision=revision,
              local_files_only=True,
          )
      except OSError as exc:
          raise ModelNotDownloadedError(
              f"model {model_id} at revision {revision} is not in the Hugging Face cache. "
              "Run `just mlx-smoke --download` once to fetch it."
          ) from exc
      return Path(path)


  def is_model_cached(model_id: str, revision: str) -> bool:
      """Return True if the model snapshot exists in the local Hugging Face cache."""
      try:
          resolve_model_snapshot(model_id, revision)
          return True
      except (ModelNotDownloadedError, RuntimeError):
          return False


  class MLXRuntime:
      """Apple Silicon neural generation runtime using mlx-lm."""

      def __init__(
          self,
          model_id: str = DEFAULT_MODEL_ID,
          revision: str = DEFAULT_MODEL_REVISION,
      ) -> None:
          if not is_apple_silicon():
              raise RuntimeError("MLXRuntime requires macOS on Apple Silicon (arm64)")
          configure_hub_env(offline=True)
          self.model_id = model_id
          self.revision = revision
          self.model_dir = resolve_model_snapshot(model_id, revision)

          mlx_lm: Any = importlib.import_module("mlx_lm")
          self._model, self._tokenizer = mlx_lm.load(str(self.model_dir))

      def complete(
          self,
          messages: Sequence[dict[str, str]],
          *,
          max_tokens: int = 160,
          temp: float = 0.8,
          top_p: float = 0.9,
          seed: int = 0,
      ) -> LLMOutput:
          mx: Any = importlib.import_module("mlx.core")
          mlx_lm: Any = importlib.import_module("mlx_lm")
          sample_utils: Any = importlib.import_module("mlx_lm.sample_utils")

          mx.random.seed(seed)
          prompt = self._tokenizer.apply_chat_template(
              list(messages), add_generation_prompt=True, tokenize=False
          )
          sampler = sample_utils.make_sampler(temp=temp, top_p=top_p)

          start_time = time.perf_counter()
          text = ""
          last: Any = None
          for resp in mlx_lm.stream_generate(
              self._model, self._tokenizer, prompt, max_tokens=max_tokens, sampler=sampler
          ):
              text += resp.text
              last = resp
  ```

  ```python
  """The LLM drill generator: on-device neural language model generation (design doc 13.5).

  LLMGenerator implements Arm.LLM (D03). Given a DrillSpec, it:
  1. Constructs Prompt v1 messages interpolating spec.target_bigrams.
  2. Invokes LLMRuntimeProtocol.complete() deterministically with spec.seed.
  3. Post-processes output via clean_llm_output() (lowercased, non-letters replaced by spaces,
     collapsed spaces, word-boundary truncation <= spec.length_chars).
  4. Emits a DrillCandidate populating raw_output, clean text, generator_version, seed,
     model_id, prompt_version, gen_ms, gen_tokens, tokens_per_sec, and peak_memory_mb.
  """

  from typing import Final

  from typist.corpus.word_index import WordIndex
  from typist.generation.base import Arm, DrillCandidate, DrillSpec
  from typist.generation.llm.postprocess import clean_llm_output
  from typist.generation.llm.prompt import PROMPT_VERSION_V1, build_prompt_v1_messages
  from typist.generation.llm.runtime import DEFAULT_MODEL_ID, LLMRuntimeProtocol
  from typist.generation.validator import ValidatorConfig

  _VERSION: Final[str] = "llm-v1"


  class LLMGenerator:
      """The 13.5 neural language model drill generator for Arm.LLM."""

      arm = Arm.LLM
      version = _VERSION

      def __init__(
          self,
          index: WordIndex,
          config: ValidatorConfig,
          runtime: LLMRuntimeProtocol,
          model_id: str = DEFAULT_MODEL_ID,
          prompt_version: str = PROMPT_VERSION_V1,
          temperature: float = 0.8,
          top_p: float = 0.9,
          max_tokens: int = 160,
      ) -> None:
          self._index = index
          self._config = config
          self._runtime = runtime
          self._model_id = model_id
          self._prompt_version = prompt_version
          self._temperature = temperature
          self._top_p = top_p
          self._max_tokens = max_tokens

      def generate(self, spec: DrillSpec) -> DrillCandidate:
          """Generate one LLM candidate drill deterministically for spec.seed."""
          messages = build_prompt_v1_messages(spec.target_bigrams)
          output = self._runtime.complete(
              messages,
              max_tokens=self._max_tokens,
              temp=self._temperature,
              top_p=self._top_p,
              seed=spec.seed,
          )
          cleaned_text = clean_llm_output(output.text, max_chars=spec.length_chars)
          return DrillCandidate(
              text=cleaned_text,
              raw_output=output.text,
              generator_version=self.version,
              seed=spec.seed,
              model_id=self._model_id,
              prompt_version=self._prompt_version,
              gen_ms=output.gen_ms,
              gen_tokens=output.tokens,
              tokens_per_sec=output.tokens_per_sec,
              peak_memory_mb=output.peak_memory_mb,
          )
  ```

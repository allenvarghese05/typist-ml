## 1. Summary

When this plan is done, `typist corpus build` writes two deterministic JSON artifacts to
`Settings.corpus_dir` — `words.json` (the top `corpus_word_count` a–z words with their wordfreq
frequencies, in rank order) and `top_bigrams.json` (the top `tracked_bigram_count` letter-letter
bigrams ranked by frequency-weighted occurrence) — via `corpus/build.py`. `corpus/word_index.py`
loads them into a `WordIndex` (words, frequencies, tracked bigrams, a bigram→words index) and exposes
`count_bigrams(text)` (letter-letter within words only). `services/test_composer.py` composes form A:
a pure, seeded, coverage-efficient lowest-coverage-first composer (`compose_baseline`) following
design doc 13.3 but scoring words by deficit-weighted coverage per unit length (O1a), plus a
separate DB writer (`persist_baseline`) that is idempotent and refuses to break a referenced,
frozen passage. `typist corpus compose-baseline [--replace]` wires them together. The two baseline texts are composed at `baseline_part_chars = 2700` (one part per baseline session,
owner option A); the two sessions together type both parts and give every tracked bigram ≥ 15
occurrences combined. A data-only Alembic migration `0002_baseline_config` seeds six new
`experiment_config` keys without touching 0001's.
`Settings.corpus_dir` is added, `wordfreq==3.1.1` becomes a runtime dependency, the README gets a
"Data and licences" citation, and tests prove the acceptance (every tracked bigram ≥
`baseline_min_occurrences` combined, and `bigram_counts` equals an independent recount), determinism,
idempotency, the `--replace` refusal, and the migration keys.

## 2. Design

- **Two artifacts, built once, loaded read-only (owner answers 3, 4).** `build.py` computes and
  writes `words.json` and `top_bigrams.json` atomically (write to a `.tmp` sibling, `os.replace`).
  `word_index.py` loads them into an immutable `WordIndex`. The order-3 n-gram model (13.4) is **not**
  built — it is T3.1's acceptance; `corpus/ngram.py` is not created. The `corpus build` help says so.
  Rejected: building the n-gram model now — out of scope, risks pulling T3.1 work into T1.8 (brief
  risk 7).
- **One bigram definition, reused (D13, 12.3).** `count_bigrams(text)` counts only letter-letter
  pairs **within** a token (split on single spaces), never across a space, matching
  `attribution._is_letter` and the seed fixture `{"th":1,"he":1,"ca":1,"at":1}` for `"the cat"`. The
  composer sets each passage's `bigram_counts` with this function; the acceptance test independently
  re-slides over the text to confirm. Rejected: a sliding window over the whole string — it would
  count space-crossing pairs (brief edge case 4).
- **The composer is the 13.3 lowest-coverage-first loop, made coverage-efficient, pure and fast
  (owner answer 8; O1a; brief performance note).** `compose_baseline(config, index, rng)` precomputes,
  once, a per-tracked-bigram candidate list sorted by `log(frequency)` descending. Each step: pick a
  tracked bigram still **under** `baseline_min_occurrences` (largest remaining deficit first, ties
  broken by `rng`; falling back to the lowest-coverage bigram once all are satisfied); gather the
  first ≤`_CANDIDATE_POOL` still-eligible candidates for it (≤2 uses this part); score each by its
  **deficit-weighted** still-under-target bigram contribution **per unit length** (log-frequency a
  mild tie-break); softmax-sample (temperature 0.5) one of the top ≤`_TOP_CANDIDATES`; append it and
  bump coverage for every tracked bigram it contains. The per-bigram lists are sorted once at setup,
  and each step touches at most `_CANDIDATE_POOL` words, so the loop is ~O(steps × pool). Coverage is
  shared across both parts (O3); the use counter resets per part. Rejected: the earlier static
  `density × log(frequency)` score — it needed ~4,800 chars/part to reach 15 (scratch), missing the
  ~2,700 target; rejected: scoring the whole vocabulary each step — too slow (owner answer 10).
- **Pure composition, separate DB write (brief explicit requirement).** `compose_baseline` returns
  `list[TextPassage]` and touches no database; `persist_baseline(session, passages, replace=…)` does
  all I/O. This makes the determinism tests trivial (no DB) and keeps the idempotency/refusal logic in
  one place.
- **Idempotency and the freeze guard (owner answer 7).** `persist_baseline` compares the composed
  texts to the existing shared form A rows: none → insert ("created"); byte-identical → no write
  ("unchanged"); different and no `--replace` → raise (CLI exit 1); different and `--replace` → refuse
  (exit 1) if any `session_blocks` row references a form A passage, else delete-and-reinsert
  ("replaced"). `frozen_at` enforcement remains T3.5; this is the "no block has typed it yet" guard.
- **Config, not literals (17.1; owner answer 2).** The six parameters live in `experiment_config`,
  seeded by a data-only migration `0002_baseline_config` that only *adds* keys (never touches 0001's)
  and whose downgrade deletes *only* those six. The composer and CLI read them from the DB. The 13.3
  algorithm constants stay literals (O2, T1.7 precedent).
- **Determinism (13.1, 17.1, CLAUDE.md).** `wordfreq` is pinned to `3.1.1`; the ranking and both
  artifacts sort by stable keys; the composer takes a `random.Random` seeded from `corpus_seed`. Same
  seed and pinned version ⇒ identical artifacts and identical texts. Row ids still come from
  `new_id()` (CLAUDE.md: ids are not results).

  ```python
  """Load the corpus artifacts and expose the bigram definition shared across the project (T1.8).

  count_bigrams is the single letter-letter bigram count for text: it splits on single spaces and
  counts only adjacent a-z pairs within a token, never across a space (D13; design doc 12.3). It
  matches typist.services.attribution's letter rule and the seed fixture ("the cat" ->
  {"th":1,"he":1,"ca":1,"at":1}). WordIndex loads words.json and top_bigrams.json (written by
  corpus/build.py) and provides the words, their frequencies, the ranked tracked bigrams and a
  bigram -> words index. The order-3 n-gram model (design doc 13.4) is not built here; it is T3.1.
  """

  import json
  from collections import defaultdict
  from dataclasses import dataclass
  from pathlib import Path
  from typing import Any

  WORDS_FILENAME = "words.json"
  TOP_BIGRAMS_FILENAME = "top_bigrams.json"


  def count_bigrams(text: str) -> dict[str, int]:
      """Return the count of each letter-letter bigram in text (within tokens, never across a space).

      Splits on single spaces; for each token counts adjacent positions where both characters are
      a-z. Space-crossing pairs are never counted, and any non a-z character breaks a pair (D13).
      A bigram with zero count is simply absent (never a JSON null, per the JSONText contract).
      """
      counts: dict[str, int] = {}
      for token in text.split(" "):
          for i in range(len(token) - 1):
              first, second = token[i], token[i + 1]
              if "a" <= first <= "z" and "a" <= second <= "z":
                  bigram = first + second
                  counts[bigram] = counts.get(bigram, 0) + 1
      return counts


  def _word_bigrams(word: str) -> list[str]:
      """Return the list of adjacent 2-character slices of word (its letter bigrams, with repeats)."""
      return [word[i : i + 2] for i in range(len(word) - 1)]


  @dataclass(frozen=True)
  class WordIndex:
      """The corpus in memory: words in rank order, their frequencies, tracked bigrams, and a
      bigram -> words index. Built by WordIndex.load from the two JSON artifacts. Immutable."""

      words: tuple[str, ...]
      frequencies: dict[str, float]
      tracked_bigrams: tuple[str, ...]
      by_bigram: dict[str, tuple[str, ...]]

      @classmethod
      def load(cls, corpus_dir: Path) -> "WordIndex":
          """Load words.json and top_bigrams.json from corpus_dir and build the bigram index.

          Raises FileNotFoundError if either artifact is missing (the caller tells the user to run
          `typist corpus build`). The bigram index maps every letter bigram that appears in any word
          to the tuple of words that contain it, in the words' rank order.
          """
          words_data: Any = json.loads((corpus_dir / WORDS_FILENAME).read_text(encoding="utf-8"))
          bigrams_data: Any = json.loads(
              (corpus_dir / TOP_BIGRAMS_FILENAME).read_text(encoding="utf-8")
          )
          words = tuple(str(entry[0]) for entry in words_data["words"])
          frequencies = {str(entry[0]): float(entry[1]) for entry in words_data["words"]}
          tracked_bigrams = tuple(str(entry[0]) for entry in bigrams_data["bigrams"])
          grouped: dict[str, list[str]] = defaultdict(list)
          for word in words:
              for bigram in set(_word_bigrams(word)):
                  grouped[bigram].append(word)
          by_bigram = {bigram: tuple(members) for bigram, members in grouped.items()}
          return cls(
              words=words,
              frequencies=frequencies,
              tracked_bigrams=tracked_bigrams,
              by_bigram=by_bigram,
          )

      def words_containing(self, bigram: str) -> tuple[str, ...]:
          """Return the words (rank order) that contain bigram, or an empty tuple if none do."""
          return self.by_bigram.get(bigram, ())
  ```

  ```python
  """Build the corpus artifacts from wordfreq (design doc 13.1-13.3; D17): deterministic JSON.

  top_words takes the most frequent pure a-z words; rank_tracked_bigrams ranks letter-letter
  bigrams by frequency-weighted occurrence (owner answer 6). build_corpus writes words.json and
  top_bigrams.json to corpus_dir atomically (write to a .tmp sibling, then os.replace), so a run
  never leaves a half-written file and re-running yields byte-identical artifacts (13.1
  determinism). The order-3 n-gram model (13.4) is T3.1, not built here.
  """

  import json
  import os
  from collections import defaultdict
  from pathlib import Path
  from typing import Any

  from wordfreq import top_n_list, word_frequency

  from typist.corpus.word_index import TOP_BIGRAMS_FILENAME, WORDS_FILENAME, _word_bigrams

  # Candidates to scan before filtering: wordfreq's list includes non a-z tokens, so scan a
  # multiple of the target count and stop once enough pure a-z words are collected.
  _SCAN_FACTOR = 3


  def top_words(word_count: int) -> list[tuple[str, float]]:
      """Return the word_count most frequent pure a-z words as (word, frequency), in rank order.

      Scans wordfreq's English list (most frequent first), keeping words that are pure ASCII
      letters (a-z after wordfreq's lowercasing) with a positive frequency, until word_count are
      collected. Deterministic for a pinned wordfreq (D17).
      """
      collected: list[tuple[str, float]] = []
      for word in top_n_list("en", word_count * _SCAN_FACTOR):
          if word.isascii() and word.isalpha():
              frequency = word_frequency(word, "en")
              if frequency > 0.0:
                  collected.append((word, frequency))
                  if len(collected) >= word_count:
                      break
      return collected


  def rank_tracked_bigrams(
      words: list[tuple[str, float]], tracked_count: int
  ) -> list[tuple[str, float]]:
      """Rank letter-letter bigrams by frequency-weighted occurrence; return the top tracked_count.

      Each bigram's weight is the sum, over the words that contain it, of word_frequency times the
      number of times it occurs in the word. Ranked by weight descending, ties broken by the
      bigram ascending (so the ranking is total and deterministic). Returns (bigram, weight).
      """
      weights: dict[str, float] = defaultdict(float)
      for word, frequency in words:
          for bigram in _word_bigrams(word):
              weights[bigram] += frequency
      ranked = sorted(weights.items(), key=lambda item: (-item[1], item[0]))
      return ranked[:tracked_count]


  def _write_json_atomic(path: Path, payload: Any) -> None:
      """Write payload as JSON to path atomically: write path.tmp then os.replace onto path."""
      path.parent.mkdir(parents=True, exist_ok=True)
      tmp = path.with_suffix(path.suffix + ".tmp")
      tmp.write_text(json.dumps(payload, ensure_ascii=True), encoding="utf-8")
      os.replace(tmp, path)


  def build_corpus(corpus_dir: Path, *, word_count: int, tracked_count: int) -> None:
      """Build words.json and top_bigrams.json into corpus_dir (atomic, deterministic).

      words.json: {"corpus_word_count": N, "words": [[word, frequency], ...]} in rank order.
      top_bigrams.json: {"tracked_bigram_count": M, "bigrams": [[bigram, weight], ...]} ranked.
      """
      words = top_words(word_count)
      bigrams = rank_tracked_bigrams(words, tracked_count)
      _write_json_atomic(
          corpus_dir / WORDS_FILENAME,
          {"corpus_word_count": word_count, "words": [[w, f] for w, f in words]},
      )
      _write_json_atomic(
          corpus_dir / TOP_BIGRAMS_FILENAME,
          {"tracked_bigram_count": tracked_count, "bigrams": [[b, w] for b, w in bigrams]},
      )
  ```

- `test_composer.py` (complete):
  ```python
  """Compose the baseline (form A) texts and write them to text_passages (design doc 13.3; T1.8).

  compose_baseline is the pure, seeded, coverage-efficient 13.3 composer (plan O1a): each step
  sources candidates from a tracked bigram still under baseline_min_occurrences (largest deficit
  first, ties broken by the caller's random generator; falling back to the lowest-coverage bigram
  once all are satisfied), scores eligible words by their deficit-weighted still-under-target bigram
  contribution per unit length (log-frequency a mild tie-break), softmax-samples one of the top 50,
  and repeats until each part reaches its character budget (13.3). Coverage is shared across the two
  parts so part 1 keeps lifting whatever part 0 left lowest; the "at most twice" word-use limit
  resets per part (owner answer 8). It
  returns TextPassage rows and touches no database. persist_baseline is the only DB writer: it is
  idempotent and refuses to overwrite a form A passage a session block already references
  (owner answer 7). frozen_at enforcement is T3.5.
  """

  import math
  import random
  from dataclasses import dataclass

  from sqlmodel import Session, col, select

  from typist.corpus.word_index import WordIndex, _word_bigrams, count_bigrams
  from typist.models import ExperimentConfig, SessionBlock, TextPassage

  # Design-doc constants for the 13.3 composer loop; not experiment knobs, so not in experiment_config
  # (cf. T1.7 keeping the 2000 ms pause threshold as a literal). Changing these changes the algorithm.
  _TEMPERATURE = 0.5  # 13.3 step 4 softmax temperature.
  _TOP_CANDIDATES = 50  # 13.3 step 4 "sample one of the top 50".
  _CANDIDATE_POOL = 400  # eligible words gathered per step before deficit-weighted re-ranking (O1a).
  _MIN_WORD_LEN = 2  # 13.4 word-length range, applied to real words (owner answer 8).
  _MAX_WORD_LEN = 10
  _MAX_USES_PER_PART = 2  # 13.3 step 5 "skip words already used twice" (owner answer 8).

  _BASELINE_CONFIG_KEYS = (
      "tracked_bigram_count",
      "baseline_min_occurrences",
      "baseline_parts",
      "baseline_part_chars",
      "corpus_seed",
  )


  @dataclass(frozen=True)
  class BaselineConfig:
      """The experiment_config values the baseline composer needs (all integers)."""

      tracked_bigram_count: int
      baseline_min_occurrences: int
      baseline_parts: int
      baseline_part_chars: int
      corpus_seed: int


  class MissingConfigError(LookupError):
      """An experiment_config key the baseline composer needs is absent (run migrations)."""


  class BaselineTextsDifferError(RuntimeError):
      """Shared form A passages already exist and differ from the composed texts (need --replace)."""


  class BaselinePassagesInUseError(RuntimeError):
      """A session block references a form A passage, so it must not be replaced (freeze guard)."""


  @dataclass(frozen=True)
  class BaselinePersistResult:
      """Outcome of persist_baseline: status is 'created', 'unchanged' or 'replaced'."""

      status: str
      parts: int


  @dataclass(frozen=True)
  class _Candidate:
      """A usable word: its log wordfreq frequency and tracked bigrams (with multiplicity)."""

      log_frequency: float
      target_bigrams: tuple[str, ...]


  def load_baseline_config(session: Session) -> BaselineConfig:
      """Read the five baseline keys from experiment_config; raise MissingConfigError if any is absent."""
      values: dict[str, int] = {}
      for key in _BASELINE_CONFIG_KEYS:
          row = session.get(ExperimentConfig, key)
          if row is None:
              raise MissingConfigError(key)
          values[key] = int(row.value)
      return BaselineConfig(**values)


  def _eligible(words: tuple[str, ...], used: dict[str, int]) -> list[str]:
      """Return the first up to _CANDIDATE_POOL words not yet used _MAX_USES_PER_PART times."""
      out: list[str] = []
      for word in words:
          if used.get(word, 0) < _MAX_USES_PER_PART:
              out.append(word)
              if len(out) >= _CANDIDATE_POOL:
                  break
      return out


  def _has_eligible(words: tuple[str, ...], used: dict[str, int]) -> bool:
      """True if any word in words has been used fewer than _MAX_USES_PER_PART times this part."""
      return any(used.get(word, 0) < _MAX_USES_PER_PART for word in words)


  def _source_bigram(
      tracked: tuple[str, ...],
      coverage: dict[str, int],
      target: int,
      used: dict[str, int],
      by_target: dict[str, tuple[str, ...]],
      rng: random.Random,
  ) -> str | None:
      """Pick the tracked bigram to source candidate words from this step (plan O1a).

      Prefer a still-under-target bigram (coverage < target) that still has an eligible word,
      choosing the largest remaining deficit (target - coverage) with ties broken by rng over the
      sorted bigrams. When every tracked bigram has reached target, fall back to the lowest-coverage
      bigram that still has an eligible word (to fill the remaining length with real words). Return
      None when no tracked bigram has any eligible word left this part (the part then ends).
      """
      under = [
          bigram
          for bigram in tracked
          if coverage[bigram] < target and _has_eligible(by_target[bigram], used)
      ]
      if under:
          most = max(target - coverage[bigram] for bigram in under)
          tied = sorted(bigram for bigram in under if target - coverage[bigram] == most)
          return rng.choice(tied)
      available = [bigram for bigram in tracked if _has_eligible(by_target[bigram], used)]
      if not available:
          return None
      lowest = min(coverage[bigram] for bigram in available)
      tied = sorted(bigram for bigram in available if coverage[bigram] == lowest)
      return rng.choice(tied)


  def _choose_word(
      eligible: list[str],
      candidates: dict[str, _Candidate],
      coverage: dict[str, int],
      target: int,
      rng: random.Random,
  ) -> str:
      """Deficit-weighted, per-unit-length selection among eligible (plan O1a; 13.3 step 4).

      Each word's gain is the sum over its tracked bigrams of max(target - coverage[b], 0), divided
      by len(word) + 1 (per unit length including the following space). Words are ranked by gain
      descending, then log-frequency descending (a mild tie-break), then the word ascending; one of
      the top _TOP_CANDIDATES is softmax-sampled with temperature _TEMPERATURE using rng.
      """

      def gain(word: str) -> float:
          contribution = sum(
              max(target - coverage[bigram], 0) for bigram in candidates[word].target_bigrams
          )
          return contribution / (len(word) + 1)

      ranked = sorted(
          ((gain(word), word) for word in eligible),
          key=lambda item: (-item[0], -candidates[item[1]].log_frequency, item[1]),
      )
      pool = ranked[:_TOP_CANDIDATES]
      scores = [score for score, _ in pool]
      words = [word for _, word in pool]
      highest = max(scores)
      weights = [math.exp((score - highest) / _TEMPERATURE) for score in scores]
      threshold = rng.random() * sum(weights)
      cumulative = 0.0
      for word, weight in zip(words, weights, strict=True):
          cumulative += weight
          if threshold <= cumulative:
              return word
      return words[-1]


  def compose_baseline(
      config: BaselineConfig, index: WordIndex, rng: random.Random
  ) -> list[TextPassage]:
      """Compose config.baseline_parts shared form A passages with the coverage-efficient composer.

      Pure: returns TextPassage rows (kind='baseline', form='A', participant_id=None, part=i),
      with text over a-z + single spaces (no leading/trailing space) and bigram_counts the
      letter-letter counts of that text. Deterministic for a given rng and WordIndex. Coverage is
      shared across parts; the per-part word-use limit resets each part.
      """
      tracked = tuple(index.tracked_bigrams[: config.tracked_bigram_count])
      tracked_set = set(tracked)
      target = config.baseline_min_occurrences
      candidates: dict[str, _Candidate] = {}
      grouped: dict[str, list[str]] = {bigram: [] for bigram in tracked}
      for word in index.words:
          if not (_MIN_WORD_LEN <= len(word) <= _MAX_WORD_LEN):
              continue
          word_bigrams = _word_bigrams(word)
          targets = tuple(bigram for bigram in word_bigrams if bigram in tracked_set)
          if not targets:
              continue
          candidates[word] = _Candidate(
              log_frequency=math.log(index.frequencies[word]), target_bigrams=targets
          )
          for bigram in set(targets):
              grouped[bigram].append(word)
      for bigram in tracked:
          grouped[bigram].sort(key=lambda word: (-candidates[word].log_frequency, word))
      by_target: dict[str, tuple[str, ...]] = {
          bigram: tuple(members) for bigram, members in grouped.items()
      }

      coverage: dict[str, int] = dict.fromkeys(tracked, 0)
      passages: list[TextPassage] = []
      for part in range(config.baseline_parts):
          used: dict[str, int] = {}
          chosen_words: list[str] = []
          length = 0
          while length < config.baseline_part_chars:
              source = _source_bigram(tracked, coverage, target, used, by_target, rng)
              if source is None:
                  break
              eligible = _eligible(by_target[source], used)
              word = _choose_word(eligible, candidates, coverage, target, rng)
              used[word] = used.get(word, 0) + 1
              for bigram in candidates[word].target_bigrams:
                  coverage[bigram] += 1
              length += len(word) + (1 if chosen_words else 0)
              chosen_words.append(word)
          text = " ".join(chosen_words)
          passages.append(
              TextPassage(
                  kind="baseline",
                  form="A",
                  part=part,
                  participant_id=None,
                  text=text,
                  bigram_counts=count_bigrams(text),
              )
          )
      return passages


  def persist_baseline(
      session: Session, passages: list[TextPassage], *, replace: bool = False
  ) -> BaselinePersistResult:
      """Write the composed shared form A passages idempotently; commit. Statuses: see the dataclass.

      No existing shared form A rows -> insert ('created'). Existing rows byte-identical to the
      composed texts -> no write ('unchanged'). Different and replace is False -> BaselineTextsDiffer
      Error. Different and replace is True -> BaselinePassagesInUseError if any session_blocks row
      references a form A passage, else delete the old rows and insert the new ones ('replaced').
      """
      existing = list(
          session.exec(
              select(TextPassage)
              .where(
                  col(TextPassage.kind) == "baseline",
                  col(TextPassage.form) == "A",
                  col(TextPassage.participant_id).is_(None),
              )
              .order_by(col(TextPassage.part))
          ).all()
      )
      composed_by_part = {passage.part: passage.text for passage in passages}
      if not existing:
          session.add_all(passages)
          session.commit()
          return BaselinePersistResult(status="created", parts=len(passages))
      if {passage.part: passage.text for passage in existing} == composed_by_part:
          return BaselinePersistResult(status="unchanged", parts=len(existing))
      if not replace:
          raise BaselineTextsDifferError("shared form A passages already exist and differ")
      existing_ids = [passage.id for passage in existing]
      referenced = session.exec(
          select(SessionBlock.id).where(col(SessionBlock.passage_id).in_(existing_ids))
      ).first()
      if referenced is not None:
          raise BaselinePassagesInUseError("a session block references a form A passage")
      for passage in existing:
          session.delete(passage)
      session.flush()
      session.add_all(passages)
      session.commit()
      return BaselinePersistResult(status="replaced", parts=len(passages))
  ```

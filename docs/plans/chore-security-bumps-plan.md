## 2. Design

- **Web (owner answers 1–2).** Hand-edit `apps/web/package.json` `"vite"` from `8.3.1` to `8.3.3`
  (first patched, exact), then `pnpm install` to update the lockfile, then
  `pnpm install --frozen-lockfile` to prove it installs clean. A one-line manifest edit is explicit
  and reviewable. Rejected: `pnpm update vite --latest` (rewrites the manifest range and jumps to
  dist-tag latest 8.3.4 per brief edge case 2) and `pnpm update vite` alone (a no-op on an exact
  pin, brief edge case 1).
- **Python (owner answer 3).** From `services/api`: `uv lock --upgrade-package certifi`, then
  `uv sync --locked`. `certifi` is a leaf with no deps and no tight parent constraint, so only its
  entry moves. Rejected: bare `uv lock --upgrade` (re-resolves everything, brief edge case 5) and
  pinning `certifi` in `pyproject.toml` (T0.3: transitive versions live in `uv.lock`).
- **Two commits, one PR (owner answer 4).** vite commit first, then certifi, for clean bisection.
- **Who runs what (brief section 6).** The owner runs every network/commit step (edit-apply,
  `pnpm install`, `uv lock`/`uv sync`, commits, `just security`, `just check`). The builder writes
  the two verify scripts and the message/PR files and runs the offline verification. This mirrors
  the chore-source-map-js split.
- **Expected diff scope / stop rule.** Web: `apps/web/package.json` (only line 32) plus
  `apps/web/pnpm-lock.yaml` vite entries, and at most `rolldown` moving within `~1.2.x` (expected
  per brief edge case 3). Python: `services/api/uv.lock`, certifi entry only. Any other file, any
  other package moving, or `pyproject.toml` changing is a **stop** — revert and report to the owner.

- **File:** `/Users/allen/typist-ml/.git/chore-security-bumps/verify-web.sh` (create the dir).
  Exact content:

```sh
#!/bin/sh
# Verifies the web bump touches only vite (8.3.1->8.3.3) and at most rolldown
# within ~1.2.x. Usage: sh verify-web.sh [base]  (base defaults to HEAD; pass
# main after both commits). Prints FAIL lines and exits 1 on any failure.
set -u
LC_ALL=C; export LC_ALL
repo=/Users/allen/typist-ml
base=${1:-HEAD}
fail=0
bad() { printf 'FAIL: %s\n' "$*"; fail=1; }

# 1. Only package.json and pnpm-lock.yaml changed under apps/web; nothing outside apps/web.
changed=$(git -C "$repo" diff --name-only "$base" -- apps/web | sort | tr '\n' ' ')
[ "$changed" = "apps/web/package.json apps/web/pnpm-lock.yaml " ] \
  || bad "changed under apps/web: [$changed], expected package.json + pnpm-lock.yaml only"
other=$(git -C "$repo" diff --name-only "$base" -- . ':(exclude)apps/web' | grep .)
[ -z "$other" ] || bad "files changed outside apps/web: $other"

# 2. The only package.json change is the vite pin 8.3.1 -> 8.3.3.
pj=$(git -C "$repo" diff -U0 "$base" -- apps/web/package.json | grep '^[-+]' | grep -Ev '^(---|\+\+\+) ')
exp_pj='-    "vite": "8.3.1",
+    "vite": "8.3.3",'
[ "$pj" = "$exp_pj" ] || bad "package.json diff is not only the vite pin:
$pj"

# 3. In the lockfile, 8.3.1 is gone and 8.3.3 is present; no vite version other than 8.3.3 remains.
grep -q 'vite@8\.3\.1' "$repo/apps/web/pnpm-lock.yaml" && bad "vite@8.3.1 still in lockfile"
grep -q 'vite@8\.3\.3' "$repo/apps/web/pnpm-lock.yaml" || bad "vite@8.3.3 not found in lockfile"
badv=$(grep -oE 'vite@8\.3\.[0-9]+' "$repo/apps/web/pnpm-lock.yaml" | grep -v 'vite@8\.3\.3' | sort -u)
[ -z "$badv" ] || bad "unexpected vite versions in lockfile: $badv"

# 4. Every package that moved in the lockfile is vite or rolldown only (rolldown must stay ~1.2.x).
moved=$(git -C "$repo" diff -U0 "$base" -- apps/web/pnpm-lock.yaml \
  | grep -E '^[-+]  [@a-z]' | sed -E 's/^[-+]  //; s/[@(].*//' | sort -u | grep .)
for p in $moved; do
  case "$p" in
    vite|rolldown|@rolldown/binding-*) ;;
    *) bad "unexpected package moved in lockfile: $p" ;;
  esac
done
bad_rolldown=$(grep -oE 'rolldown@1\.[0-9]+\.[0-9]+' "$repo/apps/web/pnpm-lock.yaml" \
  | grep -vE 'rolldown@1\.2\.' | sort -u)
[ -z "$bad_rolldown" ] || bad "rolldown moved outside ~1.2.x: $bad_rolldown"

if [ "$fail" = 0 ]; then
  printf 'PASS: web change is vite 8.3.1->8.3.3 (rolldown stays ~1.2.x)\n'
else
  exit 1
fi
```

# services/api/uv.lock. Usage: sh verify-py.sh [base]  (base defaults to HEAD).
set -u

  && bad "certifi 2026.7.22 still in uv.lock"
grep -q 'version = "2026.10.19"' "$repo/services/api/uv.lock" \
  || bad "certifi 2026.10.19 not found in uv.lock"

if [ "$fail" = 0 ]; then
  printf 'PASS: uv.lock change is certifi 2026.7.22->2026.10.19 only\n'
else

fi

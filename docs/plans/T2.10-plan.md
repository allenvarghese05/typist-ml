# T2.10 Implementation Plan: Dev-only pipeline test using scripted keystrokes

## 1. Summary

This plan implements an automated, dev-only end-to-end pipeline test that validates the complete Typist-ML experiment lifecycle in 2-set mode (`arms_enabled = ["control", "heuristic"]`). A realistic scripted typist generates well-formed keystroke streams (with realistic IKI, dwells, keyups, and backspace error recoveries) across baseline, assignment, practice, and retest phases. The flow runs hermetically via FastAPI `TestClient` and background workers in CI via `pytest` and on-demand via the CLI command `typist dev test-pipeline`. It proves Milestone 2 completion, confirms data-quality checks and stats idempotence, and guarantees simulated keystrokes are never persisted to pilot data.

## 2. Design

The pipeline test executes the full participant lifecycle DAG through public REST endpoints (`/api/v1/participants`, `/api/v1/sessions`, `/api/v1/blocks/{bid}/start`, `/events`, `/complete`, `/api/v1/admin/participants/{pid}/assign`, `/api/v1/admin/pool/replenish`, `/api/v1/admin/checks/{pid}`) and worker execution functions (`run_worker_once`). 

1. **Keystroke Simulation (`script_keystrokes`):** A pure generator in `services/api/src/typist/services/pipeline.py` that walks a target text string, emitting valid `KeystrokeEventIn` rows. For each character, it produces monotonic `t_down_ms` timestamps, valid `dwell_ms` (50ms) and `t_up_ms = t_down_ms + dwell_ms`, and valid `iki_ms`. At a configurable error rate (default 5%), it simulates a realistic substitution error (`outcome = "error"`, `first_attempt = True`), followed by a backspace row (`outcome = "backspace"`, `key = "Backspace"`, `expected_char = None`, `first_attempt = None`, `target_index = max(0, i - 1)` per D25), followed by the corrected keypress (`outcome = "correct"`, `first_attempt = False`). This satisfies all `KeystrokeEventIn` invariants, produces qualifying errors for bigram attribution, and guarantees 0% missing keyups and 0 dwell anomalies for daily checks.
2. **2-Set Mode Configuration (M2 Cut-Line):** Overrides `experiment_config` in test to set `arms_enabled = ["control", "heuristic"]`, `assignment_per_set = 8`, `assignment_per_set_fallback = 6`, and `practice_days = 2`. This exercises Latin-square rotation across days 1 and 2 (`("control", "heuristic")` on Day 1, `("heuristic", "control")` on Day 2) while keeping total execution runtime under 3 seconds in CI.
3. **Hermetic Corpus & Baseline Passages:** Uses a module-scoped temporary corpus fixture built via `build_corpus(tmp_path / "corpus", word_count=5000, tracked_count=50)` and seeds Form A baseline passages covering the top tracked bigrams with $\ge 15$ occurrences so assignment satisfies D28 (`assignment_min_observations = 15`) without missing candidate errors.
4. **Dual Runner Interface (pytest + CLI):** The core lifecycle engine `run_pipeline` is exposed both as a standard pytest integration suite (`services/api/tests/integration/test_pipeline.py`) running in `just check-api` / CI and as a CLI command `typist dev test-pipeline` in `services/api/src/typist/cli.py` for terminal diagnostics against an isolated temporary SQLite database.

*Rejected alternative:* Running end-to-end tests via a headless browser with Playwright. Rejected because Playwright is not installed in `apps/web` or CI, would balloon CI runtime by orders of magnitude for 14 sessions and >4,000 keystrokes, and is reserved solely for browser smoke testing (§5.1, §17.2).

- `services/api/src/typist/services/pipeline.py` (CREATE): Core scripted typist generator (`script_keystrokes`) and end-to-end study pipeline test runner (`run_pipeline`).

```python
"""Scripted keystroke generator and dev-only pipeline test runner (design doc 16; T2.10)."""

import random
from typing import Final

from typist.schemas.events import KeystrokeEventIn

DEFAULT_TYPING_IKI_MS: Final[float] = 100.0
DEFAULT_TYPING_DWELL_MS: Final[float] = 50.0
_PRINTABLE_SUBSTITUTES: Final[dict[str, str]] = {
    "a": "b",
    "b": "c",
    "c": "d",
    "d": "e",
    "e": "f",
    "f": "g",
    "g": "h",
    "h": "i",
    "i": "j",
    "j": "k",
    "k": "l",
    "l": "m",
    "m": "n",
    "n": "o",
    "o": "p",
    "p": "q",
    "q": "r",
    "r": "s",
    "s": "t",
    "t": "u",
    "u": "v",
    "v": "w",
    "w": "x",
    "x": "y",
    "y": "z",
    "z": "a",
    " ": "e",
}


def _char_to_code(char: str) -> str:
    if char == " ":
        return "Space"
    return f"Key{char.upper()}"


def script_keystrokes(
    target_text: str,
    *,
    error_rate: float = 0.05,
    rng: random.Random | None = None,
    start_time_ms: float = 0.0,
    iki_ms: float = DEFAULT_TYPING_IKI_MS,
    dwell_ms: float = DEFAULT_TYPING_DWELL_MS,
) -> list[KeystrokeEventIn]:
    """Generate a well-formed list of KeystrokeEventIn rows typing through target_text.

    Simulates realistic human-like typing:
    - Monotonically increasing t_down_ms advancing by iki_ms per key event.
    - Constant positive dwell_ms with t_up_ms = t_down_ms + dwell_ms (0% missing keyups).
    - When an error is injected (with probability error_rate on alphabetic chars):
      1. Types an incorrect char (outcome='error', first_attempt=True).
      2. Types 'Backspace' (outcome='backspace', expected_char=None, first_attempt=None,
         target_index=max(0, i - 1) per D25).
      3. Types the correct char (outcome='correct', first_attempt=False).
    - seq strictly increases starting from 0 with no gaps.
    - All generated rows strictly pass KeystrokeEventIn._check_invariants.
    """
    effective_rng = rng if rng is not None else random.Random(42)
    events: list[KeystrokeEventIn] = []
    current_t = start_time_ms
    prev_down_t: float | None = None

    for i, expected in enumerate(target_text):
        should_error = (
            error_rate > 0.0 and expected in _PRINTABLE_SUBSTITUTES and effective_rng.random() < error_rate
        )
        if should_error:
            # 1. Error keystroke
            wrong_key = _PRINTABLE_SUBSTITUTES[expected]
            iki = None if prev_down_t is None else (current_t - prev_down_t)
            events.append(
                KeystrokeEventIn(
                    seq=len(events),
                    key=wrong_key,
                    code=_char_to_code(wrong_key),
                    t_down_ms=current_t,
                    t_up_ms=current_t + dwell_ms,
                    dwell_ms=dwell_ms,
                    iki_ms=iki,
                    target_index=i,
                    expected_char=expected,
                    outcome="error",
                    first_attempt=True,
                    after_pause=False,
                    handler_ms=0.1,
                    dispatch_lag_ms=0.1,
                )
            )
            prev_down_t = current_t
            current_t += iki_ms

            # 2. Backspace
            backspace_target_index = max(0, i - 1)
            iki = current_t - prev_down_t
            events.append(
                KeystrokeEventIn(
                    seq=len(events),
                    key="Backspace",
                    code="Backspace",
                    t_down_ms=current_t,
                    t_up_ms=current_t + dwell_ms,
                    dwell_ms=dwell_ms,
                    iki_ms=iki,
                    target_index=backspace_target_index,
                    expected_char=None,
                    outcome="backspace",
                    first_attempt=None,
                    after_pause=False,
                    handler_ms=0.1,
                    dispatch_lag_ms=0.1,
                )
            )
            prev_down_t = current_t
            current_t += iki_ms

            # 3. Corrected keystroke
            iki = current_t - prev_down_t
            events.append(
                KeystrokeEventIn(
                    seq=len(events),
                    key=expected,
                    code=_char_to_code(expected),
                    t_down_ms=current_t,
                    t_up_ms=current_t + dwell_ms,
                    dwell_ms=dwell_ms,
                    iki_ms=iki,
                    target_index=i,
                    expected_char=expected,
                    outcome="correct",
                    first_attempt=False,
                    after_pause=False,
                    handler_ms=0.1,
                    dispatch_lag_ms=0.1,
                )
            )
            prev_down_t = current_t
            current_t += iki_ms
        else:
            # Clean typing
            iki = None if prev_down_t is None else (current_t - prev_down_t)
            events.append(
                KeystrokeEventIn(
                    seq=len(events),
                    key=expected,
                    code=_char_to_code(expected),
                    t_down_ms=current_t,
                    t_up_ms=current_t + dwell_ms,
                    dwell_ms=dwell_ms,
                    iki_ms=iki,
                    target_index=i,
                    expected_char=expected,
                    outcome="correct",
                    first_attempt=True,
                    after_pause=False,
                    handler_ms=0.1,
                    dispatch_lag_ms=0.1,
                )
            )
            prev_down_t = current_t
            current_t += iki_ms

    return events
```

```python
from collections.abc import Callable
from dataclasses import dataclass
from datetime import UTC, datetime
from pathlib import Path
from typing import TYPE_CHECKING, Any

from sqlalchemy import Engine
from sqlmodel import Session, col, select

from typist.corpus.word_index import WordIndex
from typist.models import ExperimentConfig, TextPassage
from typist.services.session_planner import replenish_drill_pool
from typist.services.session_stats import recompute_stats
from typist.services.test_composer import BaselineConfig, compose_baseline, persist_baseline
from typist.worker import run_worker_once

if TYPE_CHECKING:
    from fastapi.testclient import TestClient


@dataclass(frozen=True)
class PipelineStepLog:
    step: str
    phase: str
    detail: str


@dataclass(frozen=True)
class PipelineResult:
    participant_id: str
    alias: str
    status: str
    completed_sessions: int
    frozen_bigrams: int
    arms_used: tuple[str, ...]
    checks_passed: bool
    duration_s: float
    steps: tuple[PipelineStepLog, ...]


def setup_pipeline_environment(
    session: Session,
    index: WordIndex,
    *,
    practice_days: int = 2,
    seed: int = 20261027,
) -> None:
    """Configure experiment_config for 2-set mode and ensure Form A passages exist."""
    # 1. Configure 2-set mode
    arms_row = session.get(ExperimentConfig, "arms_enabled")
    if arms_row is not None:
        arms_row.value = ["control", "heuristic"]
        session.add(arms_row)

    days_row = session.get(ExperimentConfig, "practice_days")
    if days_row is not None:
        days_row.value = practice_days
        session.add(days_row)

    per_set_row = session.get(ExperimentConfig, "assignment_per_set")
    if per_set_row is not None:
        per_set_row.value = 8
        session.add(per_set_row)

    fallback_row = session.get(ExperimentConfig, "assignment_per_set_fallback")
    if fallback_row is not None:
        fallback_row.value = 6
        session.add(fallback_row)

    session.commit()

    # 2. Ensure Form A baseline passages exist covering tracked bigrams
    existing_form_a = session.exec(
        select(TextPassage).where(
            col(TextPassage.kind) == "baseline",
            col(TextPassage.form) == "A",
            col(TextPassage.participant_id).is_(None),
        )
    ).all()
    if not existing_form_a:
        cfg = BaselineConfig(
            tracked_bigram_count=min(50, len(index.tracked_bigrams)),
            baseline_min_occurrences=15,
            baseline_parts=2,
            baseline_part_chars=600,
            corpus_seed=seed,
        )
        passages = compose_baseline(cfg, index, random.Random(seed))
        persist_baseline(session, passages)


def run_pipeline(
    client: "TestClient",
    engine: Engine,
    index: WordIndex,
    db_path: Path,
    *,
    alias: str = "test-pipeline-dev",
    practice_days: int = 2,
    error_rate: float = 0.05,
    seed: int = 20261027,
    progress_callback: Callable[[PipelineStepLog], None] | None = None,
) -> PipelineResult:
    """Execute the complete within-person study pipeline in 2-set mode end-to-end.

    Lifecycle executed:
    1. Setup: configure 2-set mode in experiment_config, compose & persist Form A baseline texts.
    2. Enrolment & Consent: create participant (enrolled -> baseline).
    3. Baseline Sessions (2 parts): plan, type Form A parts 0 and 1, complete blocks and sessions.
    4. Assignment: POST /api/v1/admin/participants/{pid}/assign -> freezes 16 bigrams into 2 sets,
       composes Form B passages (status -> assigned).
    5. Drill Generation: replenish pool and execute worker loop with Control & Heuristic generators.
    6. Practice Sessions (practice_days sessions, Latin square rotated):
       Session 1: consumes drills, status -> practice.
       Session 2..N: consumes drills, on final practice session status -> retest.
       After each practice session, runs worker to replenish drill pool.
    7. Retest Sessions (2 parts): plan Form B parts 0 and 1, type and complete.
       Final retest session completes -> status -> done.
    8. Post-study Verification:
       - Starting another session returns 409 Conflict.
       - Admin data quality checks return passed=True (0 seq gaps, 0 dwell anomalies, 0 short blocks,
         0 missing keyups, 0 lingering sessions).
       - Stats recompute is idempotent (recompute_stats matches computed stats).
    """
    t_start = datetime.now(UTC)
    rng = random.Random(seed)
    steps: list[PipelineStepLog] = []

    def _log(step: str, phase: str, detail: str) -> None:
        log_entry = PipelineStepLog(step=step, phase=phase, detail=detail)
        steps.append(log_entry)
        if progress_callback is not None:
            progress_callback(log_entry)

    with Session(engine) as session:
        setup_pipeline_environment(session, index, practice_days=practice_days, seed=seed)
    _log("setup", "init", "Configured 2-set mode and baseline passages")

    # 1. Enrolment & Consent
    p_resp = client.post("/api/v1/participants", json={"alias": alias, "is_builder": False, "is_blinded": True})
    assert p_resp.status_code == 201, p_resp.text
    pid = p_resp.json()["id"]
    _log("enrol", "enrolled", f"Created participant {pid} (alias={alias})")

    c_resp = client.post(f"/api/v1/participants/{pid}/consent")
    assert c_resp.status_code == 200, c_resp.text
    assert c_resp.json()["status"] == "baseline"
    _log("consent", "baseline", "Recorded consent; status advanced to baseline")

    # Helper to type and complete a planned session
    def _type_session(session_plan: dict[str, Any]) -> None:
        sid = session_plan["session_id"]
        for block in session_plan["blocks"]:
            bid = block["block_id"]
            start_resp = client.post(f"/api/v1/blocks/{bid}/start")
            assert start_resp.status_code == 200, start_resp.text

            target_text = block["target_text"]
            events = script_keystrokes(target_text, error_rate=error_rate, rng=rng)
            event_payload = {"events": [e.model_dump() for e in events]}
            ev_resp = client.post(f"/api/v1/blocks/{bid}/events", json=event_payload)
            assert ev_resp.status_code == 200, ev_resp.text
            assert ev_resp.json()["accepted"] == len(events)

            comp_b_resp = client.post(f"/api/v1/blocks/{bid}/complete")
            assert comp_b_resp.status_code == 200, comp_b_resp.text

        comp_s_resp = client.post(f"/api/v1/sessions/{sid}/complete")
        assert comp_s_resp.status_code == 200, comp_s_resp.text

    # 2. Baseline Sessions (2 parts)
    for part in range(2):
        s_resp = client.post(f"/api/v1/participants/{pid}/sessions")
        assert s_resp.status_code == 200, s_resp.text
        plan = s_resp.json()
        assert plan["phase"] == "baseline"
        _type_session(plan)
        _log("baseline", "baseline", f"Completed baseline session part {part}")

    # 3. Assignment
    assign_resp = client.post(f"/api/v1/admin/participants/{pid}/assign")
    assert assign_resp.status_code == 200, assign_resp.text
    assign_data = assign_resp.json()
    assert assign_data["status"] == "assigned"
    frozen_count = assign_data["frozen_bigrams"]
    assert frozen_count == 16, f"Expected 16 frozen bigrams, got {frozen_count}"
    assert assign_data["form_b_composed"] is True
    _log("assign", "assigned", f"Assigned participant: {frozen_count} bigrams frozen; Form B composed")

    # 4. Generate Initial Drill Pool
    repl_resp = client.post("/api/v1/admin/pool/replenish", json={"participant_id": pid})
    assert repl_resp.status_code == 200, repl_resp.text
    while True:
        claimed = run_worker_once(engine, db_path, index)
        if claimed is None:
            break
    _log("worker", "assigned", "Drill pool populated via generation worker")

    # 5. Practice Sessions
    for day in range(1, practice_days + 1):
        s_resp = client.post(f"/api/v1/participants/{pid}/sessions")
        assert s_resp.status_code == 200, s_resp.text
        plan = s_resp.json()
        assert plan["phase"] == "practice"
        assert plan["day_index"] == day
        _type_session(plan)
        _log("practice", "practice", f"Completed practice session day {day}")

        # Replenish and run worker
        while True:
            claimed = run_worker_once(engine, db_path, index)
            if claimed is None:
                break

    # 6. Retest Sessions (2 parts)
    for part in range(2):
        s_resp = client.post(f"/api/v1/participants/{pid}/sessions")
        assert s_resp.status_code == 200, s_resp.text
        plan = s_resp.json()
        assert plan["phase"] == "retest"
        assert plan["day_index"] == part + 1
        _type_session(plan)
        _log("retest", "retest", f"Completed retest session part {part}")

    # Verify participant reaches 'done'
    p_final = client.get("/api/v1/participants").json()
    p_record = next(p for p in p_final if p["id"] == pid)
    final_status = p_record["status"]
    assert final_status == "done", f"Expected participant status 'done', got {final_status}"

    # Verify attempting another session is rejected
    post_done_resp = client.post(f"/api/v1/participants/{pid}/sessions")
    assert post_done_resp.status_code == 409

    # 7. Quality Checks Verification
    checks_resp = client.get(f"/api/v1/admin/checks/{pid}")
    assert checks_resp.status_code == 200, checks_resp.text
    checks_data = checks_resp.json()
    assert checks_data["passed"] is True, f"Checks failed: {checks_data}"
    _log("checks", "done", "Participant daily quality checks PASSED")

    # 8. Idempotent Stats Recomputation
    with Session(engine) as session:
        recompute_res = recompute_stats(session, pid)
        total_expected_sessions = 2 + practice_days + 2
        assert recompute_res.recomputed == total_expected_sessions
        assert recompute_res.skipped == 0
    _log("recompute", "done", f"Recomputed stats for {total_expected_sessions} sessions idempotently")

    duration = (datetime.now(UTC) - t_start).total_seconds()
    return PipelineResult(
        participant_id=pid,
        alias=alias,
        status=final_status,
        completed_sessions=2 + practice_days + 2,
        frozen_bigrams=frozen_count,
        arms_used=("control", "heuristic"),
        checks_passed=checks_data["passed"],
        duration_s=duration,
        steps=tuple(steps),
    )
```

dev_app = typer.Typer(
    help="Developer diagnostics and testing commands (design doc 16; T2.10).",
    no_args_is_help=True,
)
app.add_typer(dev_app, name="dev")


@dev_app.callback()
def dev() -> None:
    """Developer diagnostics and testing commands (design doc section 16)."""


@dev_app.command("test-pipeline")
def test_pipeline_command(
    alias: str = typer.Option(
        "dev-pipeline-test", "--alias", help="Participant alias for the test run."
    ),
    practice_days: int = typer.Option(
        2, "--practice-days", help="Number of practice days to simulate (default: 2)."
    ),
    error_rate: float = typer.Option(
        0.05, "--error-rate", help="Simulated typing error rate (0.0 to 1.0; default: 0.05)."
    ),
    seed: int = typer.Option(
        20261027, "--seed", help="Random seed for deterministic typing and assignment."
    ),
    db_path: Path | None = typer.Option(
        None, "--db-path", help="Optional path to SQLite file; defaults to temporary isolated DB."
    ),
) -> None:
    """Run the complete study pipeline test end-to-end using scripted keystrokes.

    Simulates participant enrollment, consent, 2 baseline sessions, weak bigram ranking and
    freeze, drill pool generation via worker, practice sessions, retest sessions, quality checks,
    and stats recompute. Runs hermetically on a temporary database. Never used as empirical evidence.
    """
    import tempfile
    from fastapi.testclient import TestClient

    from typist.api.routers.admin import get_word_index
    from typist.config import Settings
    from typist.corpus.build import build_corpus
    from typist.main import create_app
    from typist.services.pipeline import PipelineStepLog, run_pipeline

    with tempfile.TemporaryDirectory() as tmp_dir_str:
        tmp_dir = Path(tmp_dir_str)
        target_db = db_path if db_path is not None else tmp_dir / "test_pipeline.db"
        corpus_dir = tmp_dir / "corpus"

        typer.echo("Building temporary corpus...")
        build_corpus(corpus_dir, word_count=5000, tracked_count=50)
        index = WordIndex.load(corpus_dir)

        test_settings = Settings(db_path=target_db, corpus_dir=corpus_dir)
        engine = create_db_engine(target_db)
        from alembic import command
        from alembic.config import Config
        from typist.migrations import ALEMBIC_INI

        cfg = Config(str(ALEMBIC_INI))
        cfg.set_main_option("sqlalchemy.url", f"sqlite:///{target_db}")
        command.upgrade(cfg, "head")

        api_app = create_app(test_settings)
        api_app.dependency_overrides[get_word_index] = lambda: index

        def _print_step(step_log: PipelineStepLog) -> None:
            typer.echo(f"  [{step_log.phase:<10}] {step_log.step}: {step_log.detail}")

        typer.echo(f"Starting pipeline test (alias={alias}, practice_days={practice_days})...")
        try:
            with TestClient(api_app) as client:
                result = run_pipeline(
                    client,
                    engine,
                    index,
                    target_db,
                    alias=alias,
                    practice_days=practice_days,
                    error_rate=error_rate,
                    seed=seed,
                    progress_callback=_print_step,
                )
        except Exception as err:
            typer.echo(f"Pipeline test FAILED: {err}", err=True)
            raise typer.Exit(code=1) from err
        finally:

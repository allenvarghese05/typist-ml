# T4.5 Implementation Plan — Debrief page: Shows arm mapping only after retest

## 1. Summary

This plan implements the Debrief page (`#/results/:pid` and `#/debrief/:pid`), the final screen of the participant study flow (§11.1, §11.3). For completed participants (`status === "done"`), it unmasks the experimental arm assignments (Control, Heuristic, Markov, LLM), displays weak bigrams by set, shows primary error rate ($E(s)$) and secondary timing ($F(s)$) targeting effects with forest plots, and provides post-retest diagnostic nudges (D12). For active participants (`status !== "done"`), it strictly enforces single-blind integrity (D18), rendering a locked status banner with zero arm names, zero block-to-arm mappings, and zero targeting metrics.

## 2. Design

- **Approach:**
  - **Single-blind enforcement at UI boundary (D18):** When a participant has not completed retest (`status !== "done"`), the backend `/analysis/participants/{pid}` endpoint returns HTTP 409 (`ParticipantNotDoneError`). `DebriefPage` catches this state and renders a dedicated locked view (`DebriefLockedView`) showing the participant's current study phase, progress note, and blinding explanation. Under no circumstances are arm identities or block mappings rendered before `status === "done"`.
  - **Arm Reveal Staging (§3.2, §11.3):** For completed participants, an "Arm Reveal" card presents the unmasked mapping of sets (A, B, C, D) to their true training generators (`Control (held-out)`, `Dictionary Heuristic`, `Markov Chain`, `On-device 1B LLM`). An interactive toggle ("Mask Arm Identities" / "Reveal Arm Identities") allows participants to toggle between blinded practice block labels (`Block 1..4`) and unblinded generator identities.
  - **Diagnostic Nudges (D12):** Decision D12 defers diagnostic typing feedback to post-retest debrief. `DebriefPage` inspects retest bigram accuracy across the analyzed retest sessions (via `fetchSessionMatrix`); any assigned bigram exhibiting persistent weakness (>5% error rate or >250 ms median latency) is surfaced in a diagnostic feedback card with targeted motor advice.
  - **Route & Navigation Integration (§11.3):** `useHashRoute.ts` parses `#/results/:pid` and `#/debrief/:pid` (plus query parameter fallbacks). Top navbar in `App.tsx` gains a "Debrief" link, and `ParticipantList.tsx` adds a per-participant "Debrief" row action.
- **Rejected alternatives:**
  - *Server-side mock arm masking when status != "done":* Rejected because the backend already returns HTTP 409 Conflict per pre-registration; attempting to return a partial payload creates data-leakage surface area and alters frozen API contracts.
  - *Querying BigramAssignment table directly in the frontend:* Rejected because admin endpoints leak arm mappings for unblinded participants, violating single-blind isolation.

```typescript
export type Route =
  | { readonly name: "demo" }
  | { readonly name: "matrix"; readonly sessionId: string }
  | { readonly name: "admin"; readonly participantId?: string }
  | { readonly name: "dashboard"; readonly participantId?: string; readonly tab?: string }
  | { readonly name: "debrief"; readonly participantId?: string };

export function parseHash(hash: string): Route {
  const matrixMatch = /^#\/matrix\/(.+)$/.exec(hash);
  const matrixEncoded = matrixMatch?.[1];
  if (matrixEncoded !== undefined) {
    return { name: "matrix", sessionId: decodeURIComponent(matrixEncoded) };
  }
  const adminMatch = /^#\/admin(?:\?(.*))?$/.exec(hash);
  if (adminMatch) {
    const search = adminMatch[1];
    const params = new URLSearchParams(search ?? "");
    const participantId = params.get("participant") ?? undefined;
    return { name: "admin", participantId };
  }
  const dashboardMatch = /^#\/dashboard(?:\?(.*))?$/.exec(hash);
  if (dashboardMatch) {
    const search = dashboardMatch[1];
    const params = new URLSearchParams(search ?? "");
    const participantId = params.get("participant") ?? undefined;
    const tab = params.get("tab") ?? undefined;
    return { name: "dashboard", participantId, tab };
  }
  const debriefMatch = /^#\/(?:results|debrief)(?:\/([^?]+?))?\/?(?:\?(.*))?$/.exec(hash);
  if (debriefMatch) {
    const pathPid = debriefMatch[1];
    const search = debriefMatch[2];
    const params = new URLSearchParams(search ?? "");
    const participantId = pathPid
      ? decodeURIComponent(pathPid)
      : (params.get("participant") ?? undefined);
    return { name: "debrief", participantId };
  }
  return { name: "demo" };
}
```

```tsx
function formatPercent(value: number | null, decimals = 1): string {
  if (value === null) return "—";
  return `${(value * 100).toFixed(decimals)}%`;
}

function formatRate(value: number | null): string {
  if (value === null) return "—";
  return value > 0 ? `+${(value * 100).toFixed(2)}%` : `${(value * 100).toFixed(2)}%`;
}

function formatMs(value: number | null): string {
  if (value === null) return "—";
  return value > 0 ? `+${value.toFixed(1)} ms` : `${value.toFixed(1)} ms`;
}

interface WeakBigramNudge {
  readonly bigram: string;
  readonly setLabel: string;
  readonly arm: string;
  readonly errorRate: number;
  readonly medianIkiMs: number | null;
}

export function DebriefPage({
  initialParticipantId,
  fetchImpl = fetch,
}: DebriefPageProps): React.JSX.Element {
  const [participants, setParticipants] = useState<readonly ParticipantResponse[]>([]);
  const [loadingParticipants, setLoadingParticipants] = useState(true);
  const [selectedId, setSelectedId] = useState<string>(initialParticipantId ?? "");
  const [revealed, setRevealed] = useState(true);

  const [resultsState, setResultsState] = useState<{
    readonly status: "loading" | "ok" | "not-done" | "not-found" | "error";
    readonly results: ParticipantResults | null;
    readonly message?: string;
  }>({ status: "loading", results: null });

  const [nudges, setNudges] = useState<readonly WeakBigramNudge[]>([]);

  // 1. Fetch participants on mount
  useEffect(() => {
    let cancelled = false;
    setLoadingParticipants(true);
    fetchParticipants(fetchImpl)
      .then((parts) => {
        if (cancelled) return;
        setParticipants(parts);
        setLoadingParticipants(false);

        // Determine initial participant if none explicitly chosen
        if (!initialParticipantId && parts.length > 0) {
          const firstDone = parts.find((p) => p.status === "done");
          const defaultPid = firstDone ? firstDone.id : parts[0]?.id;
          if (defaultPid) {
            setSelectedId(defaultPid);
            window.location.hash = `#/results/${encodeURIComponent(defaultPid)}`;
          }
        }
      })
      .catch(() => {
        if (cancelled) return;
        setLoadingParticipants(false);
      });

    return () => {
      cancelled = true;
    };
  }, [fetchImpl, initialParticipantId]);

  // Sync with prop changes
  useEffect(() => {
    if (initialParticipantId) {
      setSelectedId(initialParticipantId);
    }
  }, [initialParticipantId]);

  const handleSelectParticipant = (pid: string) => {
    setSelectedId(pid);
    window.location.hash = `#/results/${encodeURIComponent(pid)}`;
  };

  // 2. Fetch analysis results whenever selectedId changes
  useEffect(() => {
    if (!selectedId) {
      setResultsState({ status: "not-found", results: null });
      setNudges([]);
      return;
    }

    let cancelled = false;
    setResultsState({ status: "loading", results: null });
    setNudges([]);

    fetchParticipantResults(selectedId, fetchImpl).then((res) => {
      if (cancelled) return;
      if (res.status === "ok") {
        setResultsState({ status: "ok", results: res.results });

        // Fetch retest session matrices to compute diagnostic nudges (D12)
        const retestSessionIds = res.results.analyzed_retest_session_ids;
        if (retestSessionIds.length > 0) {
          Promise.all(retestSessionIds.map((sid) => fetchSessionMatrix(sid, fetchImpl)))
            .then((matrixResults) => {
              if (cancelled) return;
              const completedMatrices = matrixResults
                .filter((mr) => mr.status === "ok")
                .map((mr) => (mr as { status: "ok"; matrix: { cells: readonly { bigram: string; attempts: number; errors: number; error_rate: number | null; iki_median_ms: number | null }[] } }).matrix);

              const bigramStats = new Map<string, { attempts: number; errors: number; ikiValues: number[] }>();
              for (const m of completedMatrices) {
                for (const cell of m.cells) {
                  const existing = bigramStats.get(cell.bigram) ?? { attempts: 0, errors: 0, ikiValues: [] };
                  existing.attempts += cell.attempts;
                  existing.errors += cell.errors;
                  if (cell.iki_median_ms !== null) existing.ikiValues.push(cell.iki_median_ms);
                  bigramStats.set(cell.bigram, existing);
                }
              }

              const foundNudges: WeakBigramNudge[] = [];
              for (const set of res.results.sets) {
                for (const bg of set.retained_bigrams) {
                  const stat = bigramStats.get(bg);
                  if (stat && stat.attempts > 0) {
                    const errRate = stat.errors / stat.attempts;
                    const medIki = stat.ikiValues.length > 0 ? stat.ikiValues[0] ?? null : null;
                    if (errRate > 0.05 || (medIki !== null && medIki > 250)) {
                      foundNudges.push({
                        bigram: bg,
                        setLabel: set.set_label,
                        arm: set.arm,
                        errorRate: errRate,
                        medianIkiMs: medIki,
                      });
                    }
                  }
                }
              }
              setNudges(foundNudges);
            })
            .catch(() => {
              // Graceful fallback: ignore diagnostic fetch error
            });
        }
      } else if (res.status === "not-done") {
        setResultsState({ status: "not-done", results: null, message: res.message });
      } else if (res.status === "not-found") {
        setResultsState({ status: "not-found", results: null });
      } else {
        setResultsState({ status: "error", results: null, message: res.message });
      }
    });

    return () => {
      cancelled = true;
    };
  }, [selectedId, fetchImpl]);

  if (loadingParticipants) {
    return (
      <div className="p-8 max-w-6xl mx-auto text-center text-gray-500 animate-pulse">
        Loading debrief participants...
      </div>
    );
  }

      {/* Top Header & Participant Dropdown */}
      <div className="flex flex-col md:flex-row md:items-center justify-between gap-4 border-b border-gray-200 pb-5">
        <div>
          <h1 className="text-2xl font-bold tracking-tight text-gray-900">Study Debrief</h1>
          <p className="text-xs text-gray-500 mt-1">
            Participant debrief, experimental unblinding, and targeting outcomes (§11.3).
          </p>
        </div>

        {participants.length > 0 ? (
          <div className="flex items-center gap-3">
            <label
              htmlFor="debrief-participant-select"
              className="text-xs font-semibold text-gray-700 shrink-0"
            >
              Participant:
            </label>
            <select
              id="debrief-participant-select"
              aria-label="Participant selector"
              value={selectedId}
              onChange={(e) => handleSelectParticipant(e.target.value)}
              className="text-sm border border-gray-300 rounded-md px-3 py-1.5 bg-white text-gray-900 shadow-sm focus:outline-none focus:ring-1 focus:ring-blue-500 font-mono"
            >
              {participants.map((p) => (
                <option key={p.id} value={p.id}>
                  {p.alias} ({p.status}){p.is_builder ? " [Builder]" : ""}
                </option>
              ))}
            </select>
          </div>
        ) : (
          <div className="text-xs text-gray-500 italic">No participants enrolled.</div>
        )}
      </div>

      {/* Participant Identity Banner */}
      {currentParticipant && (
        <div className="bg-white border border-gray-200 rounded-lg p-4 flex flex-wrap items-center justify-between gap-3 shadow-sm">
          <div className="flex items-center gap-3">
            <div className="text-sm font-bold text-gray-900">{currentParticipant.alias}</div>
            <span
              className={`inline-block px-2.5 py-0.5 rounded text-xs uppercase font-medium ${
                currentParticipant.status === "done"
                  ? "bg-green-100 text-green-800"
                  : "bg-amber-100 text-amber-800"
              }`}
            >
              Status: {currentParticipant.status}

              🔒
            </div>
            <div>
              <h2 className="text-lg font-bold text-gray-900">
                Study Debrief Locked (Experimental Blinding Active)
              </h2>
              <p className="text-sm text-gray-600 mt-1">
                To preserve scientific validity (D18), arm mappings and targeted drill outcomes
                remain strictly blinded until all post-practice retest sessions have concluded.
              </p>
            </div>
          </div>

          <div className="p-4 bg-amber-50 rounded-md border border-amber-200 text-xs text-amber-900 space-y-1">
            <div className="font-semibold">Current Phase: {currentParticipant?.status ?? "in progress"}</div>

              Welcome to your debrief! In the baseline phase, your keystrokes were analyzed to
              identify your slowest and most error-prone bigrams. These were dealt in snake order
              into balanced sets (A, B, C, D) and trained over 10 practice days using 4 distinct
              methods disguised as Blocks 1 to 4. Below is your overall performance change between
```

## 1. Summary

When this plan is done, `services/api/src/typist/services/attribution.py` holds the only bigram
attribution in the project (CLAUDE.md): a pure `attribute_block(target_text, rows)` that implements
design doc section 12.3 verbatim with the D24 pause amendment (pause = `b.after_pause` **or**
`b.t_down_ms - a.t_down_ms > 2000`, strict `>`) and D23(a) (a paused or error pair still counts an
attempt, and an error if `b` is an error; only the IKI sample is dropped). It returns a list of frozen
`BigramStat` sorted by bigram, omitting bigrams with zero attempts, with `iki_median_ms` from
`statistics.median`. A thin `attribute_block_from_db(session, block_id)` loads the block's
`target_text` and rows and calls it. Tests prove: the DB path reproduces the golden fixture's 19
expected rows exactly; the pure path produces the identical result; the result is order-independent;
and a Hypothesis property test over well-formed generated streams holds the three invariants from
owner answer 5. `hypothesis==6.170.5` is added to the dev group, `uv.lock` is regenerated, and a
derandomised Hypothesis profile is registered in `tests/conftest.py`.

## 2. Design

- **A pure algorithm plus a thin DB wrapper (owner answer 1).** `attribute_block(target_text, rows)`
  is the whole algorithm; it sorts `rows` by `seq` internally so callers may pass them in any order.
  `attribute_block_from_db(session, block_id)` only loads `SessionBlock.target_text` and the block's
  `KeystrokeEvent` rows and delegates. Keeping the algorithm pure makes the fixture test and the
  property test trivial to drive without a DB, and the DB path adds nothing to prove (the pure-path
  test asserts the identical output).
- **Per block, never across a block boundary (owner answer 3; brief risk 9).** `attribute_block`
  receives one block's rows and one `target_text`. There is no session-level entry point in T1.7; the
  per-session merge (sum attempts/errors, pool raw samples, then median — not a median of medians) is
  T1.9's job and is enabled by exposing raw samples via `attribute_block_samples`/`BigramSamples`.
- **Section 12.3 verbatim, with the two amendments inlined (brief, derivation A.0).** For each `j ≥ 1`
  where `target[j-1]` and `target[j]` are both letters: pick `a` = the first-attempt row at `j-1` and
  `b` = the first-attempt row at `j`; skip in this fixed order — a/b missing, then `a.outcome !=
  "correct"`, then a backspace row strictly between `a.seq` and `b.seq`; otherwise it is an attempt;
  an error if `b.outcome == "error"`; else an IKI sample `b.t_down_ms - a.t_down_ms` only when
  `b.seq == a.seq + 1` and the pair is not paused, where paused = `b.after_pause or (b.t_down_ms -
  a.t_down_ms) > 2000`.
- **First-attempt lookup by `target_index` (brief risk 4, derivation A.4).** `a` and `b` are the rows
  with `first_attempt is True` at positions `j-1` and `j`. Backspace and retype rows have
  `first_attempt` null/false and are never chosen as `a` or `b`. Exactly one first-attempt row exists
  per position, so the map is unambiguous.
- **Backspace-between is strict (brief risk 5; cases c, d).** "A backspace happened between a and b"
  means any row with `outcome == "backspace"` whose `seq` is strictly between `a.seq` and `b.seq`
  (`a.seq < seq < b.seq`). Multiple backspaces in the interval are all caught.
- **Median by `statistics.median` for all n (owner answer 6, derivation A.6).** Even counts give the
  mean of the two middle values (`th` → 95, `ll` → 165.25); odd counts give the sorted middle (`he`
  `[140,95,110]` → 110, not the unsorted 95). `iki_median_ms is None` exactly when `iki_n == 0`.
- **Zero-attempt bigrams omitted (owner answer 1, derivation A.6).** `ma`, `al`, `il`, `id`, `of`,
  `ed`, `rm` never appear; only bigrams with ≥ 1 attempt are returned. Results are sorted by bigram
  so the output is deterministic and converts to a dict trivially.
- **Config, floats, exactness.** There is no configuration to add: the only constant is the 2000 ms
  pause threshold, which is fixed by D24 and written as the literal `2000` with a citing comment (it
  is a design constant, not an experiment knob, so it does not go in `experiment_config`). All fixture
  times are whole or quarter milliseconds, so the computed medians compare to the fixture by exact
  `==` (brief risk 6).
- **Determinism for Hypothesis (owner answer 4; CLAUDE.md seeded randomness).** A `ci` profile is
  registered and loaded in `tests/conftest.py` (`derandomize=True, max_examples=200, deadline=None`),
  so the property test is reproducible and never flaky on timing. The order-independence test shuffles
  rows with an explicitly seeded `random.Random(...)` (CLAUDE.md).
- **Rejected alternatives.** (1) A single session-level entry point that groups rows by block —
  rejected: T1.7 is per block (owner answer 3); grouping is T1.9's, and a cross-block pair would be
  wrong (brief risk 9). (2) Returning only `BigramStat` (no raw samples) — rejected: T1.9 must pool
  raw samples, and recomputing from medians is impossible (owner answer 3). (3) Writing a
  `bigram_stats` model or migration — rejected: that table is T2.1; T1.7 returns in-memory results
  only (brief risk 8).

### Step 2: The attribution module

- File: create `services/api/src/typist/services/attribution.py`.

- Complete contents:
  ```python
  """Bigram attribution: the only place a keystroke is attributed to a bigram (CLAUDE.md).

  Implements design doc section 12.3 verbatim, with two amendments the golden fixture pins:

  * D24 (docs/decisions/D24): a pair is "paused" when the second key carries after_pause OR the
    press-to-press gap exceeds 2000 ms. The threshold is strict: a gap of exactly 2000 ms is NOT a
    pause and still yields an IKI sample (fixture case o, bigram "ld").
  * D23(a) (docs/decisions/D23): a paused pair, and an error pair, still count an attempt (and an
    error when the second key is an error). Only the IKI *sample* is dropped.

  For each position j >= 1 where target[j-1] and target[j] are both letters (D13): a is the
  first-attempt keystroke at j-1 and b the first-attempt keystroke at j. The pair is skipped, in this
  order, when a or b is missing, when a is not correct, or when a Backspace row lies strictly between
  a.seq and b.seq. Otherwise it is an attempt; an error when b is an error; otherwise an IKI sample
  b.t_down_ms - a.t_down_ms when b is adjacent (b.seq == a.seq + 1) and the pair is not paused.

  iki_median_ms is statistics.median over the raw samples (mean of the two middle values on an even
  count, the sorted middle on an odd count; owner answer 6, derivation A.6); it is None exactly when
  iki_n == 0. Bigrams with zero attempts are omitted. attribute_block returns a list sorted by bigram.
  Pairs never cross a block boundary: this function attributes one block; T1.9 aggregates a session's
  blocks by pooling raw samples (not a median of medians), which is why attribute_block_samples is
  exposed. The browser never attributes bigrams (CLAUDE.md).
  """

  from collections.abc import Sequence
  from dataclasses import dataclass
  from statistics import median

  from sqlmodel import Session, col, select

  from typist.models import KeystrokeEvent, SessionBlock

  PAUSE_GAP_MS = 2000.0
  """Press-to-press gap above which a pair is a pause (D24). Strict: exactly 2000 ms is not a pause."""


  @dataclass(frozen=True)
  class BigramSamples:
      """Raw per-bigram attribution for one block: counts plus the IKI samples before any median.

      attempts and errors follow D23(a) (paused and error pairs still count). iki_samples holds the
      clean, unpaused, adjacent samples in a.seq order. Exposed so T1.9 can pool samples across a
      session's blocks before taking one median (owner answer 3).
      """

      bigram: str
      attempts: int
      errors: int
      iki_samples: tuple[float, ...]


  @dataclass(frozen=True)
  class BigramStat:
      """Reduced per-bigram stats matching the section 8.1 bigram_stats columns the fixture asserts.

      iki_median_ms is statistics.median over the samples, or None when iki_n == 0; iki_n is the
      sample count. The browser computes display stats only; this is the authoritative computation.
      """

      bigram: str
      attempts: int
      errors: int
      iki_median_ms: float | None
      iki_n: int


  def _is_letter(char: str) -> bool:
      """True for a single lowercase a-z character (D13 tracks letter-letter bigrams only)."""
      return "a" <= char <= "z"


  def attribute_block_samples(
      target_text: str, rows: Sequence[KeystrokeEvent]
  ) -> dict[str, BigramSamples]:
      """Attribute one block's rows to bigrams, returning raw counts and IKI samples per bigram.

      rows may arrive in any order; they are sorted by seq internally. Only bigrams with at least one
      attempt appear in the result. Implements design doc 12.3 with D24 and D23(a) (see the module
      docstring). This is the low-level form; attribute_block reduces it to medians.
      """
      ordered = sorted(rows, key=lambda row: row.seq)
      first_attempt_at: dict[int, KeystrokeEvent] = {}
      backspace_seqs: list[int] = []
      for row in ordered:
          if row.outcome == "backspace":
              backspace_seqs.append(row.seq)
          elif row.first_attempt:
              first_attempt_at[row.target_index] = row

      attempts: dict[str, int] = {}
      errors: dict[str, int] = {}
      samples: dict[str, list[float]] = {}

      for j in range(1, len(target_text)):
          if not (_is_letter(target_text[j - 1]) and _is_letter(target_text[j])):
              continue
          a = first_attempt_at.get(j - 1)
          b = first_attempt_at.get(j)
          if a is None or b is None:
              continue
          if a.outcome != "correct":
              continue
          if any(a.seq < seq < b.seq for seq in backspace_seqs):
              continue
          bigram = target_text[j - 1] + target_text[j]
          attempts[bigram] = attempts.get(bigram, 0) + 1
          errors.setdefault(bigram, 0)
          samples.setdefault(bigram, [])
          if b.outcome == "error":
              errors[bigram] += 1
          elif b.seq == a.seq + 1:
              gap = b.t_down_ms - a.t_down_ms
              paused = b.after_pause or gap > PAUSE_GAP_MS
              if not paused:
                  samples[bigram].append(gap)

      return {
          bigram: BigramSamples(
              bigram=bigram,
              attempts=count,
              errors=errors[bigram],
              iki_samples=tuple(samples[bigram]),
          )
          for bigram, count in attempts.items()
      }


  def attribute_block(target_text: str, rows: Sequence[KeystrokeEvent]) -> list[BigramStat]:
      """Attribute one block and reduce to BigramStat, sorted by bigram.

      Bigrams with zero attempts are omitted. iki_median_ms is statistics.median over the samples, or
      None when there are none. rows may arrive in any order (sorted internally), so the result is
      order-independent.
      """
      per_bigram = attribute_block_samples(target_text, rows)
      stats: list[BigramStat] = []
      for bigram in sorted(per_bigram):
          entry = per_bigram[bigram]
          iki_n = len(entry.iki_samples)
          iki_median_ms = median(entry.iki_samples) if iki_n > 0 else None
          stats.append(
              BigramStat(
                  bigram=bigram,
                  attempts=entry.attempts,
                  errors=entry.errors,
                  iki_median_ms=iki_median_ms,
                  iki_n=iki_n,
              )
          )
      return stats


  def attribute_block_from_db(session: Session, block_id: str) -> list[BigramStat]:
      """Load one block's target_text and keystroke rows and attribute them (design doc 12.3).

      Raises LookupError if no session_blocks row has the id. Otherwise delegates to attribute_block,
      so the DB path and the in-memory path produce identical results.
      """
      block = session.get(SessionBlock, block_id)
      if block is None:
          raise LookupError(f"no session_blocks row with id {block_id!r}")
      rows = session.exec(
          select(KeystrokeEvent).where(col(KeystrokeEvent.block_id) == block_id)
      ).all()
      return attribute_block(block.target_text, rows)
  ```

  **not** suppress it; the field is `float | None` and `median` over a `tuple[float, ...]` is `float`.
  Should pyright narrow it to `float` exactly, no change is needed. If it reports anything, stop and
  report the message verbatim.

- `tests/unit/_stream_strategy.py` (complete) — the well-formed stream generator (owner answer 5):
  ```python
  """A Hypothesis helper that builds a well-formed keystroke stream for one target (T1.7).

  It walks the target the way TextCursor/KeystrokeRecorder do (first attempt per position, Backspace
  rows with null expected_char/first_attempt, contiguous seq from 0, non-decreasing t_down_ms,
  arbitrary after_pause). It is used only by the property test; it is not imported into src/ and never
  ports TextCursor (owner answer 5). "Well-formed" means every position has at most one first-attempt
  row, which is exactly what makes the attempts-vs-letter-pairs invariant provable.
  """

  from typing import Final

  from hypothesis import strategies as st
  from hypothesis.strategies import DrawFn

  from typist.models import KeystrokeEvent

  TARGET_ALPHABET: Final = "abc "
  _WRONG_FOR: Final = {"a": "b", "b": "c", "c": "a", " ": "a"}


  def targets() -> st.SearchStrategy[str]:
      """Targets over a small [a-z ] alphabet, including empty and single-char (D13 charset)."""
      return st.text(alphabet=TARGET_ALPHABET, min_size=0, max_size=12)


  def letter_pair_positions(target: str) -> int:
      """Number of positions j in 1..len-1 where target[j-1] and target[j] are both a-z letters."""
      return sum(
          1
          for j in range(1, len(target))
          if target[j - 1].islower() and target[j].islower() and target[j - 1].isalpha()
      )


  def build_stream(draw: DrawFn, target: str) -> list[KeystrokeEvent]:
      """Draw a well-formed keystroke stream for target: a list of KeystrokeEvent rows.

      Each step draws correct / wrong / backspace (backspace only when index > 0). A printable key
      compares with target[index], records target_index = index, and advances; the row is a first
      attempt iff no earlier printable key recorded that index. A backspace steps index back (clamped
      at 0) and records the new index with null expected_char/first_attempt. seq is contiguous from 0;
      t_down_ms strictly increases by a drawn positive delta; after_pause is drawn freely. The block
      may be left unfinished (attribution tolerates a missing tail).
      """
      n_actions = draw(st.integers(min_value=0, max_value=24))
      rows: list[KeystrokeEvent] = []
      index = 0
      t_down = float(draw(st.integers(min_value=0, max_value=100)))
      recorded: set[int] = set()
      for _ in range(n_actions):
          if index >= len(target):
              break
          choices = ["correct", "wrong"]
          if index > 0:
              choices.append("backspace")
          kind = draw(st.sampled_from(choices))
          after_pause = draw(st.booleans())
          t_down += float(draw(st.integers(min_value=1, max_value=4000)))
          seq = len(rows)
          if kind == "backspace":
              index = max(index - 1, 0)
              rows.append(
                  KeystrokeEvent(
                      block_id="prop",
                      seq=seq,
                      key="Backspace",
                      code="Backspace",
                      t_down_ms=t_down,
                      target_index=index,
                      expected_char=None,
                      outcome="backspace",
                      first_attempt=None,
                      after_pause=after_pause,
                      handler_ms=0.5,
                      dispatch_lag_ms=1.25,
                  )
              )
              continue
          expected = target[index]
          if kind == "correct":
              typed = expected
              outcome = "correct"
          else:
              typed = _WRONG_FOR[expected]
              outcome = "error"
          first_attempt = index not in recorded
          recorded.add(index)
          rows.append(
              KeystrokeEvent(
                  block_id="prop",
                  seq=seq,
                  key=typed,
                  code=f"Key{typed.upper()}" if typed != " " else "Space",
                  t_down_ms=t_down,
                  target_index=index,
                  expected_char=expected,
                  outcome=outcome,
                  first_attempt=first_attempt,
                  after_pause=after_pause,
                  handler_ms=0.5,
                  dispatch_lag_ms=1.25,
              )
          )
          index += 1
      return rows
  ```
  Note: a "wrong" key at a space position types a letter (`_WRONG_FOR[" "] == "a"`), mirroring fixture
  case h (a letter typed where a space is expected); a "wrong" at a letter position types a different
  letter. Either way the row's `outcome` is `"error"` and its `target_index` is the current index, so
  the stream stays well-formed.

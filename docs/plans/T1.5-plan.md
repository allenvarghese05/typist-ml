## 1. Summary

When this plan is done, `apps/web/src/features/session/` holds a `TypingSurface` React component and
a plain, React-free `TypingDisplayStore`. The component attaches `window` keydown/keyup/blur/focus
listeners, calls `preventDefault` on handled keys, drives one `KeystrokeRecorder` per block, and
fans every recorded row into both the display store and a caller-supplied `KeystrokeSink`. The store
observes that row stream and exposes a per-cell snapshot through `useSyncExternalStore`, so each of
the 600 characters is its own subscribed cell: a keystroke re-renders only the cells that changed,
never the surface or the text container. The store also runs the D26 idle rule (5 s warning, 10 s
abandon, wall-clock, reset only by recorded rows) and surfaces pause-on-blur, and the surface emits
block start/complete/abandon lifecycle events (each tagged with an `attempt` number) to its caller.
jsdom plus Testing Library are added for the one component test file.

## 2. Design

- **Two objects, one data flow.** `KeystrokeRecorder` stays exactly as merged (plain, React-free;
  6.1). A **new, separate** `TypingDisplayStore` observes the recorder's row stream (owner answer 2):
  the surface gives the recorder a fan-out sink whose `onRow` calls `store.applyRow(row)` and then
  the caller's `sink.onRow(row)`. The store never touches the recorder; the recorder never knows the
  store exists. `useSyncExternalStore` subscribes to the **store**, not the recorder.
- **Per-cell subscription, so no full re-render per key (acceptance).** The text is a static list of
  `CharCell` components, each memoised and each subscribed via `useSyncExternalStore` to
  `store.getCellSnapshot(index)`, which returns a **primitive string** (`"untyped"`, `"correct"`,
  `"error"`, or those plus `"-cursor"`). On a keystroke the store notifies; React re-reads every
  cell's snapshot but re-renders only the two or three whose string changed (the old cursor cell, the
  typed cell, the new cursor cell). The top-level `TypingSurface` and the memoised `TextView`
  subscribe to nothing per key, so they render once per block. This is the structural guarantee the
  acceptance criterion asks for; proven by a render-counter test (owner answer 8), with no latency
  assertion. Rejected alternative: a single store snapshot returning the whole cursor/outcome array —
  that re-renders the 600-char container on every key, the exact failure 9.2 warns against.
- **Primitive snapshots avoid the `getSnapshot` loop.** Returning a string (compared by value under
  `Object.is`) sidesteps the React-19 infinite-loop pitfall of returning a fresh object each call
  (brief risk 2). Progress, phase and paused snapshots are likewise primitives.
- **Idle rule lives in the store, timer-driven, wall-clock (owner answers 1, 10; D26).** On block
  start and on every recorded row the store arms two `setTimeout`s: `idleWarningMs` → `warning`,
  `idleAbandonMs` → `abandoned`. Only `applyRow` (a recorded row) reschedules them; blur/focus do
  not, so a 10 s blur with no typing abandons the block regardless of focus. Reaching the last index
  clears the timers and moves to `done`. Rejected alternative: a `now()`-polling interval — more code
  for the same result; `setTimeout` is wall-clock enough and deterministic under `vi.useFakeTimers`.
- **One performance-clock origin for both timing and display (owner answer 6).** The surface captures
  `blockStartMs = performance.now()` once, when the block becomes active (inside the mount effect),
  and passes it to the recorder. No `POST /blocks/{bid}/start`, no second clock. Live WPM is **not**
  rendered (11.3's typing-screen elements are block label, text, error highlight, progress bar, pause
  — no WPM), so no per-key timer re-render is introduced; if elapsed is ever shown it must use this
  same origin.
- **Lifecycle to a caller callback, not the frozen `KeystrokeSink`.** `KeystrokeSink` (onRow/onKeyUp)
  is T1.6's contract and is left untouched. Block start/complete/abandon go to a separate
  `onLifecycle?` prop. Each event carries `attempt` (0, 1, …). A restart is observable as
  `abandon(attempt n)` then `start(attempt n+1)` with a fresh `blockStartMs`; this is the smallest
  thing that satisfies "emits abandon/restart to its sink interface" (owner answer 1) and also
  records the owner's flagged future attempt-identity signal without building persistence.
- **Abandon → explicit restart (D26: "must be restarted").** At 10 s idle the store enters
  `abandoned` and the surface shows an overlay with a `Restart block` button. Clicking it bumps an
  `attempt` state, which recreates the store and recorder (new origin, `seq` from 0, fresh display)
  and emits `start(attempt n+1)`. Restart is a rare top-level re-render, never per key.
- **Listeners on `window`, cleaned up, StrictMode-safe (12.1; brief edge cases 1, 17).** All four
  listeners are added and removed in one effect keyed on the store identity; the recorder is created
  inside the effect. StrictMode's mount→unmount→mount runs the cleanup, so listeners never double. If
  `document.hasFocus()` is false at start, the effect calls `recorder.onBlur()` + `store.pause()`
  (edge case 2).
- **preventDefault only on handled keys (12.1; edge case 11).** `preventDefault` fires when no
  Ctrl/Meta/Alt is held and the key is `Backspace` or matches `/^[a-z ]$/` — the recorder's recorded
  set. Tab, arrows and Ctrl/Meta/Alt chords are left alone for navigation and shortcuts.
- **Stand-in sink + fixtures, no networking (owner answers 3, 7).** A `createCollectorSink()`
  in-memory collector catches rows, key-ups and lifecycle events; `App` renders one `TypingSurface`
  with a fixture passage and the collector, so the component ships in the `vite build` bundle (D21)
  and gives the owner a manual-check page.
- **No autocorrect/spellcheck by construction (11.3).** The surface has no `input`/`textarea`/
  `contenteditable`; it reads `window` keys and renders `span`s, so there is no field to autocorrect.

- `displayStore.ts` (complete):
  ```ts
  import type { KeystrokeRow } from "../../telemetry/types";

  /** How one target position should render (design doc 11.3). */
  export type CellStatus = "untyped" | "correct" | "error";

  /** Where the block is in its lifecycle (D26). */
  export type BlockPhase = "active" | "warning" | "abandoned" | "done";

  /** Everything a TypingDisplayStore needs; one store per block attempt. */
  export interface TypingDisplayStoreOptions {
    /** The block's target text (a to z or space); the store only paints it, never validates it. */
    readonly targetText: string;
    /** Milliseconds of no recorded row before the idle warning (D26). */
    readonly idleWarningMs: number;
    /** Milliseconds of no recorded row before the block is abandoned (D26). */
    readonly idleAbandonMs: number;
    /** Called once when the last position is reached (phase becomes "done"). */
    readonly onComplete?: () => void;
    /** Called once when the abandon timer fires (phase becomes "abandoned"). */
    readonly onAbandon?: () => void;
  }

  /**
   * The live display state for one block attempt, observing the recorder's row stream (owner answer
   * 2). It is a plain class with no React import (6.1): React reads it through useSyncExternalStore
   * and the snapshots are primitives, so getSnapshot never allocates a fresh reference.
   *
   * It owns three things: the per-position status array and cursor index (painted from each recorded
   * row), the blur "paused" flag, and the D26 idle rule. The idle timers are wall-clock setTimeouts
   * reset only by applyRow (a recorded row), never by blur or focus, so a long blur still abandons
   * (owner answer 10). No statistics, no network, no randomness.
   */
  export class TypingDisplayStore {
    /** The block's target text. */
    readonly target: string;
    /** target.length; the cursor is "done" when it reaches this. */
    readonly length: number;
    readonly #idleWarningMs: number;
    readonly #idleAbandonMs: number;
    readonly #onComplete: (() => void) | undefined;
    readonly #onAbandon: (() => void) | undefined;
    readonly #listeners = new Set<() => void>();
    readonly #statuses: CellStatus[];
    #cursorIndex = 0;
    #phase: BlockPhase = "active";
    #paused = false;
    #warningTimer: ReturnType<typeof setTimeout> | null = null;
    #abandonTimer: ReturnType<typeof setTimeout> | null = null;

    constructor(options: TypingDisplayStoreOptions) {
      this.target = options.targetText;
      this.length = options.targetText.length;
      this.#idleWarningMs = options.idleWarningMs;
      this.#idleAbandonMs = options.idleAbandonMs;
      this.#onComplete = options.onComplete;
      this.#onAbandon = options.onAbandon;
      this.#statuses = Array.from({ length: this.length }, () => "untyped" as CellStatus);
    }

    /** Subscribe for useSyncExternalStore. Returns an unsubscribe. Arrow so the reference is stable. */
    subscribe = (listener: () => void): (() => void) => {
      this.#listeners.add(listener);
      return () => {
        this.#listeners.delete(listener);
      };
    };

    /** Current cursor index (0 to length). Arrow for a stable getSnapshot. */
    getCursorIndex = (): number => this.#cursorIndex;

    /** Characters committed so far, for the progress bar. Equals the cursor index. */
    getTypedCount = (): number => this.#cursorIndex;

    /** Current lifecycle phase. Arrow for a stable getSnapshot. */
    getPhase = (): BlockPhase => this.#phase;

    /** True while the window is blurred. Arrow for a stable getSnapshot. */
    isPaused = (): boolean => this.#paused;

    /**
     * One cell's render state as a primitive string: its status, plus "-cursor" when the cursor is
     * on it. A primitive keeps useSyncExternalStore from looping (equal strings are Object.is-equal).
     */
    getCellSnapshot(index: number): string {
      const status = this.#statuses[index] ?? "untyped";
      return index === this.#cursorIndex ? `${status}-cursor` : status;
    }

    /** Begin the idle timers (called when the block becomes active, from the surface effect). */
    start(): void {
      this.#armIdle();
    }

    /**
     * Paint one recorded keystroke row and reset the idle timer. A correct/error row marks its
     * position and advances the cursor; a backspace row clears the position it lands on (11.3: wrong
     * characters are left in place until Backspace) and moves the cursor back. Reaching the last
     * position ends the block. Ignored once abandoned or done.
     */
    applyRow(row: KeystrokeRow): void {
      if (this.#phase === "abandoned" || this.#phase === "done") {
        return;
      }
      switch (row.outcome) {
        case "correct":
          this.#statuses[row.target_index] = "correct";
          this.#cursorIndex = row.target_index + 1;
          break;
        case "error":
          this.#statuses[row.target_index] = "error";
          this.#cursorIndex = row.target_index + 1;
          break;
        case "backspace":
          this.#statuses[row.target_index] = "untyped";
          this.#cursorIndex = row.target_index;
          break;
      }
      if (this.#cursorIndex >= this.length) {
        this.#clearIdle();
        this.#phase = "done";
        this.#emit();
        this.#onComplete?.();
        return;
      }
      this.#armIdle();
      this.#emit();
    }

    /** Window blurred: show paused. Does not touch the idle timers (owner answer 10). */
    pause(): void {
      if (this.#paused) {
        return;
      }
      this.#paused = true;
      this.#emit();
    }

    /** Window focused: clear paused. Does not reset the idle timers. */
    resume(): void {
      if (!this.#paused) {
        return;
      }
      this.#paused = false;
      this.#emit();
    }

    /** Clear timers and drop subscribers (effect cleanup / restart). */
    dispose(): void {
      this.#clearIdle();
      this.#listeners.clear();
    }

    #armIdle(): void {
      this.#clearIdle();
      if (this.#phase === "abandoned" || this.#phase === "done") {
        return;
      }
      if (this.#phase === "warning") {
        this.#phase = "active";
      }
      this.#warningTimer = setTimeout(() => {
        if (this.#phase === "active") {
          this.#phase = "warning";
          this.#emit();
        }
      }, this.#idleWarningMs);
      this.#abandonTimer = setTimeout(() => {
        this.#clearIdle();
        this.#phase = "abandoned";
        this.#emit();
        this.#onAbandon?.();
      }, this.#idleAbandonMs);
    }

    #clearIdle(): void {
      if (this.#warningTimer !== null) {
        clearTimeout(this.#warningTimer);
        this.#warningTimer = null;
      }
      if (this.#abandonTimer !== null) {
        clearTimeout(this.#abandonTimer);
        this.#abandonTimer = null;
      }
    }

    #emit(): void {
      for (const listener of this.#listeners) {
        listener();
      }
    }
  }
  ```

  import { memo, type ReactElement, useEffect, useMemo, useRef, useState, useSyncExternalStore } from "react";
  import { KeystrokeRecorder } from "../../telemetry/KeystrokeRecorder";
  import type { KeystrokeSink } from "../../telemetry/types";
  import { TypingDisplayStore } from "./displayStore";
  import { IDLE_ABANDON_MS, IDLE_WARNING_MS } from "./sessionConfig";

  /**
   * A block lifecycle signal the surface reports to its caller (owner answer 1). The caller's sink
   * is for rows (T1.6's EventBuffer later); these are the block-level events. A restart is observable
   * as abandon(attempt n) then start(attempt n+1); attempt is the owner's flagged future
   * block-identity signal, recorded now, not persisted.
   */
  export type BlockLifecycleEvent =
    | { readonly kind: "start"; readonly attempt: number; readonly blockStartMs: number }
    | { readonly kind: "complete"; readonly attempt: number }
    | { readonly kind: "abandon"; readonly attempt: number };

  /** Test-only render counters (owner answer 8). Undefined in production. */
  export interface RenderProbe {
    readonly onSurfaceRender?: () => void;
    readonly onTextRender?: () => void;
  }

  /** Props for one block. Text and sink come from the caller (owner answer 3); no API. */
  export interface TypingSurfaceProps {
    /** Shown as "Block N"; the arm is never named (3.3). */
    readonly blockLabel: string;
    /** The block's target text, a to z or space (validated by the recorder). */
    readonly targetText: string;
    /** Receives recorded rows and key-ups (collector now, EventBuffer later). */
    readonly sink: KeystrokeSink;
    /** Receives block start/complete/abandon events. */
    readonly onLifecycle?: (event: BlockLifecycleEvent) => void;
    /** Idle warning threshold (default IDLE_WARNING_MS). */
    readonly idleWarningMs?: number;
    /** Idle abandon threshold (default IDLE_ABANDON_MS). */
    readonly idleAbandonMs?: number;
    /** Performance clock for the block-start origin (default () => performance.now()). */
    readonly now?: () => number;
    /** Test-only render probes. */
    readonly probe?: RenderProbe;
  }

  /** The recorder's recorded set minus Backspace: used for preventDefault and detection. */
  const HANDLED_CHAR = /^[a-z ]$/;

  /**
   * The typing block screen (design doc 11.3). Attaches the window key/blur/focus listeners, drives
   * one KeystrokeRecorder per attempt, fans rows into the display store and the caller's sink, and
   * renders text/cursor/error-highlight/progress/overlay. It subscribes to nothing per key, so it
   * renders once per block; only changed CharCells re-render (acceptance; 9.2).
   */
  export function TypingSurface(props: TypingSurfaceProps): ReactElement {
    props.probe?.onSurfaceRender?.();
    const {
      blockLabel,
      targetText,
      idleWarningMs = IDLE_WARNING_MS,
      idleAbandonMs = IDLE_ABANDON_MS,
      probe,
    } = props;

    const [attempt, setAttempt] = useState(0);

    // Latest callbacks via refs so the store/effect do not depend on their identity.
    const lifecycleRef = useRef(props.onLifecycle);
    lifecycleRef.current = props.onLifecycle;
    const sinkRef = useRef(props.sink);
    sinkRef.current = props.sink;
    const nowRef = useRef(props.now);
    nowRef.current = props.now;

    // One store per (targetText, attempt). Idle timers are armed in the effect, not here, so a
    // discarded useMemo (StrictMode/concurrent) leaks no timer.
    const store = useMemo(
      () =>
        new TypingDisplayStore({
          targetText,
          idleWarningMs,
          idleAbandonMs,
          onComplete: () => lifecycleRef.current?.({ kind: "complete", attempt }),
          onAbandon: () => lifecycleRef.current?.({ kind: "abandon", attempt }),
        }),
      [targetText, attempt, idleWarningMs, idleAbandonMs],
    );

    useEffect(() => {
      const clock = nowRef.current ?? (() => performance.now());
      const blockStartMs = clock();
      const fanOut: KeystrokeSink = {
        onRow: (row) => {
          store.applyRow(row);
          sinkRef.current.onRow(row);
        },
        onKeyUp: (update) => {
          sinkRef.current.onKeyUp(update);
        },
      };
      const recorder = new KeystrokeRecorder({ targetText, blockStartMs, sink: fanOut });
      if (!document.hasFocus()) {
        recorder.onBlur();
        store.pause();
      }
      store.start();
      lifecycleRef.current?.({ kind: "start", attempt, blockStartMs });

      const onKeyDown = (e: KeyboardEvent): void => {
        if (store.getPhase() === "abandoned") {
          return;
        }
        const handled =
          !e.ctrlKey && !e.metaKey && !e.altKey && (e.key === "Backspace" || HANDLED_CHAR.test(e.key));
        if (handled) {
          e.preventDefault();
        }
        recorder.onKeyDown(e);
      };
      const onKeyUp = (e: KeyboardEvent): void => {
        recorder.onKeyUp(e);
      };
      const onBlur = (): void => {
        recorder.onBlur();
        store.pause();
      };
      const onFocus = (): void => {
        recorder.onFocus();
        store.resume();
      };
      window.addEventListener("keydown", onKeyDown);
      window.addEventListener("keyup", onKeyUp);
      window.addEventListener("blur", onBlur);
      window.addEventListener("focus", onFocus);
      return () => {
        window.removeEventListener("keydown", onKeyDown);
        window.removeEventListener("keyup", onKeyUp);
        window.removeEventListener("blur", onBlur);
        window.removeEventListener("focus", onFocus);
        store.dispose();
      };
    }, [store, targetText, attempt]);

    const restart = (): void => {
      setAttempt((a) => a + 1);
    };

    return (
      <section aria-label={blockLabel} className="mx-auto max-w-3xl p-8">
        <h2 className="text-sm font-semibold uppercase tracking-wide text-gray-500">{blockLabel}</h2>
        <TextView store={store} probe={probe} />
        <ProgressBar store={store} />
        <BlockOverlay store={store} onRestart={restart} />
      </section>
    );
  }

  const TextView = memo(function TextView({
    store,
    probe,
  }: {
    readonly store: TypingDisplayStore;
    readonly probe?: RenderProbe;
  }): ReactElement {
    probe?.onTextRender?.();
    // Keys are built off the map (not the JSX index arg) so noArrayIndexKey is not triggered.
    const cells = useMemo(
      () => Array.from(store.target, (char, index) => ({ char, index, key: `${index}:${char}` })),
      [store],
    );
    return (
      <p
        aria-label="passage"
        className="mt-4 whitespace-pre-wrap break-words font-mono text-xl leading-relaxed"
      >
        {cells.map((cell) => (
          <CharCell key={cell.key} store={store} index={cell.index} char={cell.char} />
        ))}
      </p>
    );
  });

  const CharCell = memo(function CharCell({
    store,
    index,
    char,
  }: {
    readonly store: TypingDisplayStore;
    readonly index: number;
    readonly char: string;
  }): ReactElement {
    const state = useSyncExternalStore(store.subscribe, () => store.getCellSnapshot(index));
    const isCursor = state.endsWith("-cursor");
    const status = isCursor ? state.slice(0, -"-cursor".length) : state;
    const color =
      status === "error" ? "text-red-600" : status === "correct" ? "text-gray-900" : "text-gray-400";
    const cursor = isCursor ? " underline decoration-2" : "";
    return (
      <span className={`${color}${cursor}`} data-cell={index} data-state={state}>
        {char === " " ? "\u00a0" : char}
      </span>
    );
  });

  function ProgressBar({ store }: { readonly store: TypingDisplayStore }): ReactElement {
    const typed = useSyncExternalStore(store.subscribe, store.getTypedCount);
    const total = store.length;
    const pct = total === 0 ? 0 : (typed / total) * 100;
    return (
      <div
        aria-valuemax={total}
        aria-valuemin={0}
        aria-valuenow={typed}
        className="mt-6 h-2 w-full overflow-hidden rounded bg-gray-200"
        role="progressbar"
      >
        <div className="h-full bg-gray-800" style={{ width: `${pct}%` }} />
      </div>
    );
  }

  function BlockOverlay({
    store,
    onRestart,
  }: {
    readonly store: TypingDisplayStore;
    readonly onRestart: () => void;
  }): ReactElement | null {
    const phase = useSyncExternalStore(store.subscribe, store.getPhase);
    const paused = useSyncExternalStore(store.subscribe, store.isPaused);
    if (phase === "done") {
      return (
        <p className="mt-4 text-green-700" role="status">
          Block complete.
        </p>
      );
    }
    if (phase === "abandoned") {
      return (
        <div className="mt-4" role="alert">
          <p className="text-red-700">Block abandoned after too long without typing.</p>
          <button
            className="mt-2 rounded bg-gray-800 px-3 py-1 text-white"
            onClick={onRestart}
            type="button"
          >
            Restart block
          </button>
        </div>
      );
    }
    if (phase === "warning") {
      return (
        <p className="mt-4 text-amber-700" role="alert">
          Still there? Keep typing.
        </p>
      );
    }
    if (paused) {
      return (
        <p className="mt-4 text-gray-600" role="status">
          Paused — the window lost focus.
        </p>
      );
    }
    return null;
  }

  import type { KeystrokeRow, KeystrokeSink, KeyUpUpdate } from "../../telemetry/types";
  import type { BlockLifecycleEvent } from "./TypingSurface";

  /** An in-memory sink standing in for T1.6's EventBuffer (owner answer 7). Keeps everything it sees. */
  export interface CollectorSink extends KeystrokeSink {
    readonly rows: KeystrokeRow[];
    readonly keyUps: KeyUpUpdate[];
    readonly lifecycle: BlockLifecycleEvent[];
    /** Pass as TypingSurface's onLifecycle to record block events alongside rows. */
    readonly recordLifecycle: (event: BlockLifecycleEvent) => void;
  }

  /** Builds a fresh collector. Cheap, never throws, holds no React (callable from a handler). */
  export function createCollectorSink(): CollectorSink {
    const rows: KeystrokeRow[] = [];
    const keyUps: KeyUpUpdate[] = [];
    const lifecycle: BlockLifecycleEvent[] = [];
    return {
      rows,
      keyUps,
      lifecycle,
      onRow: (row) => {
        rows.push(row);
      },
      onKeyUp: (update) => {
        keyUps.push(update);
      },
      recordLifecycle: (event) => {
        lifecycle.push(event);
      },
    };
  }

## 8. Review focus

1. **Per-cell subscription actually prevents the full re-render.** Confirm `CharCell`'s
   `getSnapshot` returns a primitive string (no fresh object/array), `TextView` is memoised and
   subscribes to nothing, and the render-counter test (step 3 test 2) genuinely holds `onSurfaceRender`
   and `onTextRender` at 1 while cells change — the whole acceptance criterion rests here.
2. **Idle rule exactness (D26, owner answer 10).** In `displayStore.ts`: timers are reset only by
   `applyRow`, not by `pause`/`resume`; both warning and abandon are armed from the same reset; the
   abandon path fires while paused (step 2 tests 8, 10); `dispose` clears them (test 12).
3. **Listener lifecycle and StrictMode safety.** The effect adds and removes all four `window`
   listeners and disposes the store; the recorder is created inside the effect with
   `blockStartMs = now()`; `document.hasFocus()` false path pauses at start; restart recreates store +
   recorder cleanly (no leaked listeners or timers across attempts).
4. **preventDefault scope (12.1, edge case 11).** Only `Backspace` and `/^[a-z ]$/` with no
   Ctrl/Meta/Alt are prevented; Tab, arrows and chords are not (step 3 test 4).
5. **Fan-out order and append-only spirit.** `fanOut.onRow` calls `store.applyRow(row)` then
   `sink.onRow(row)`; the row object is never mutated; the store derives cursor/outcome only from the
   recorder's rows (one source of truth; the recorder stays React-free).

## 1. Summary

When this plan is done, `apps/web/src/telemetry/EventBuffer.ts` holds an `EventBuffer` class that
implements the frozen `KeystrokeSink` contract. It takes a `block_id` (constructor arg) and
injectable `transport`, `timers` and `lifecycleTarget`; it buffers each row until its key-up or
`keyUpWaitMs` (2000 ms), flushes only **ready** rows every 50 rows / every 5000 ms / on an explicit
block-end `flush()`, retries failed POSTs with exponential backoff (500 ms × 2ⁿ, capped 8000 ms,
forever), and on `pagehide` sends everything remaining with `navigator.sendBeacon` as an
`application/json` Blob. Defaults live in `apps/web/src/telemetry/eventBufferConfig.ts`. On the
backend, `POST /api/v1/blocks/{block_id}/events` accepts `{ "events": [...] }`, validates each row
(D13 charset + backspace/t_up invariants), inserts with `INSERT ... ON CONFLICT (block_id, seq) DO
NOTHING`, returns `{ "accepted", "duplicates" }`, and returns 404 for an unknown block. Vitest tests
cover the buffer; pytest integration tests on a temporary SQLite file cover the endpoint, including
the acceptance case (same batch twice stores once). No `TypingSurface`/`App` change, no `client.ts`,
no `openapi-typescript`, no migration.

## 2. Design

- **EventBuffer is a standalone `KeystrokeSink` (owner answers 8, 9).** It is not wired into
  `TypingSurface` (no block row can exist yet, so a live buffer would only 404 on the FK). It takes
  `block_id` in the constructor; one buffer per attempt, mirroring one recorder/store per attempt.
- **Reading (a): flushes send ready rows only (owner answer 1).** A row is *ready* when its key-up
  has arrived **or** `keyUpWaitMs` has passed since `onRow`. `onRow` copies the row into a `#pending`
  map and arms one `keyUpWaitMs` timer; `onKeyUp` fills `t_up_ms`/`dwell_ms` on the still-pending row
  and promotes it immediately; the wait timer promotes it (with `t_up_ms` left null) otherwise. The
  50-row, 5 s-interval and block-end `flush()` paths send only the `#ready` queue; a block-end flush
  never forces pending rows out — the buffer keeps living until each pending row becomes ready. So
  every row is POSTed exactly once with its final `t_up_ms`. A key-up that arrives after its row is
  already ready/sent is **dropped** (`#pending` no longer has it) — "keyup stays null", exactly 12.4.
  `record_key_up` stays an unrouted service; T1.6 adds no key-up route (owner answer 2).
- **Handlers only enqueue (12.5; brief risk 5/6).** `onRow`/`onKeyUp` do nothing but map-writes and
  one timer arm, each wrapped in `try/catch` so they never throw into the key handler (brief risk 6).
  All network and batching happen off the handler path: threshold/interval/retry flushes run from
  timer callbacks (`#scheduleImmediate` arms a 0 ms timer; it never calls `transport.send`
  synchronously from inside `onRow`/`onKeyUp`).
- **Single-flight send with backoff (owner answer 7).** At most one `transport.send` is in flight. A
  flush splices the whole `#ready` queue into one batch; on success the backoff resets and any newly
  ready rows reschedule; on failure the batch is put back at the front of `#ready` and a backoff
  timer reflushes. Idempotency on the server makes an already-committed-but-unacknowledged batch
  harmless on resend (brief edge cases 6, 15). Retries continue forever while the buffer lives.
- **Unload via sendBeacon (owner answer 6).** The buffer registers a `pagehide` listener on an
  injectable `lifecycleTarget` (default `window`, `null` off-window). On `pagehide` it beacons
  **all** remaining rows (ready + pending) as one `application/json` Blob; the response is unreadable
  and the batch is best-effort (an earlier successful batch is harmless on the next load's resend).
- **Request shape `{ events: [row, ...] }`, `block_id` in the path only (owner answer 4).** The wire
  row is exactly `KeystrokeRow` (snake_case, no renaming, no `block_id`, no `release_to_press_ms`).
  The transport serialises `{ events }` with `JSON.stringify`.
- **Config, not literals (17.1; owner answer 7).** `eventBufferConfig.ts` exports
  `DEFAULT_EVENT_BUFFER_CONFIG` and the `EventBufferConfig` type; these are transport knobs, so they
  live in telemetry, not `experiment_config`. The constructor merges `options.config` over defaults.
- **Backend: thin router → service → schema (17.1).** The router validates the body with
  `EventBatchIn`, calls `store_events`, maps `BlockNotFoundError` to 404, and returns the
  `EventBatchResult` schema (never a table model). The service checks the block exists (owner answer
  11b), then one idempotent multi-row insert with `rowcount` for `accepted` (owner answer 5; brief
  edge case 15), `duplicates = len(events) - accepted`. An empty batch is a 0/0 no-op (edge case 7).
  `release_to_press_ms` is never written and stays NULL (owner answer 3).
- **Validation in the schema (owner answer 10).** `seq >= 0`, `outcome ∈ {correct,error,backspace}`,
  `key` is a single `a–z`/space or `"Backspace"`, `code` non-empty, backspace ⇒ `expected_char` and
  `first_attempt` null (non-backspace ⇒ both set), `t_up_ms` null ⇔ `dwell_ms` null. No
  monotonic/contiguous `seq` requirement (batches interleave under retry; 12.6 checks gaps later).
  An invalid row rejects the whole batch with 422 (nothing inserted).
- **Rejected alternatives.** (1) Posting rows eagerly without key-ups and adding a key-up route —
  rejected: reading (a) is the literal 12.4 text, needs one endpoint, never updates a stored row from
  the upload path (owner answer 1). (2) A pre-`SELECT` idempotency check — rejected: it races a
  concurrent retry; `ON CONFLICT DO NOTHING` + the unique index is the design (brief risk 2). (3)
  `openapi-typescript` + `client.ts` now — rejected: deferred to its first real user, as T0.2/T1.5
  deferred their tools (owner answer 12).

### Contract this plan honours (frozen `KeystrokeSink`)

`EventBuffer implements KeystrokeSink`: `onRow(row: KeystrokeRow): void`,
`onKeyUp(update: KeyUpUpdate): void`. Both are synchronous, cheap, and never throw (T1.4 plan
contract). The row object is never mutated; the buffer copies it. `types.ts` is **not** edited.

    /** Flush ready rows on this fixed interval. */

    readonly backoffBaseMs: number;
    /** Ceiling for the retry delay. */
    readonly backoffMaxMs: number;

- `apps/web/src/telemetry/EventBuffer.ts` (complete):
  ```ts
  import { apiPath } from "../api/paths";
  import { DEFAULT_EVENT_BUFFER_CONFIG, type EventBufferConfig } from "./eventBufferConfig";
  import type { KeystrokeRow, KeystrokeSink, KeyUpUpdate } from "./types";

  /** The JSON body of POST /api/v1/blocks/{block_id}/events (T1.6 owner answer 4). */
  export interface EventBatch {
    readonly events: readonly KeystrokeRow[];
  }

  /**
   * How a batch leaves the browser. Injected so tests use a fake; the default uses fetch for
   * flushes and navigator.sendBeacon for page unload (no openapi-typescript, no client.ts — owner
   * answer 12).
   */
  export interface EventTransport {
    /**
     * POST the batch for one block. Resolves on a 2xx response, rejects on any other status or a
     * network error. Timed, threshold and block-end flushes retry on rejection.
     */
    send(blockId: string, batch: EventBatch): Promise<void>;
    /**
     * Best-effort synchronous send for page unload (navigator.sendBeacon). Returns whether the user
     * agent queued the request; the response is never read (owner answer 6).
     */
    sendBeacon(blockId: string, batch: EventBatch): boolean;
  }

  /** Timer seam so tests drive readiness, interval and backoff with fake timers. */
  export interface Timers {
    setTimeout(handler: () => void, ms: number): number;
    clearTimeout(handle: number): void;
    setInterval(handler: () => void, ms: number): number;
    clearInterval(handle: number): void;
  }

  /** Minimal page-unload hook (window in production); injected as a fake in tests. */
  export interface PageHideTarget {
    addEventListener(type: "pagehide", listener: () => void): void;
    removeEventListener(type: "pagehide", listener: () => void): void;
  }

  /** Everything an EventBuffer needs; one buffer per block attempt (owner answers 8, 9). */
  export interface EventBufferOptions {
    /** The block this buffer uploads to; it addresses POST /blocks/{blockId}/events (owner answer 4). */
    readonly blockId: string;
    /** Where batches go. Defaults to createFetchTransport(). */
    readonly transport?: EventTransport;
    /** Timer source. Defaults to the global timers (controllable with vi.useFakeTimers()). */
    readonly timers?: Timers;
    /**
     * Page-unload source for sendBeacon. Defaults to window when it exists, else null (no unload
     * hook). Pass null to disable, or a fake target in tests.
     */
    readonly lifecycleTarget?: PageHideTarget | null;
    /** Overrides merged over DEFAULT_EVENT_BUFFER_CONFIG. */
    readonly config?: Partial<EventBufferConfig>;
  }

  /** The production transport: fetch for flushes, navigator.sendBeacon for unload. */
  export function createFetchTransport(): EventTransport {
    return {
      async send(blockId, batch) {
        const response = await fetch(apiPath(`/blocks/${encodeURIComponent(blockId)}/events`), {
          method: "POST",
          headers: { "content-type": "application/json" },
          body: JSON.stringify(batch),
          keepalive: true,
        });
        if (!response.ok) {
          throw new Error(`events upload failed with status ${response.status}`);
        }
      },
      sendBeacon(blockId, batch) {
        const blob = new Blob([JSON.stringify(batch)], { type: "application/json" });
        return navigator.sendBeacon(apiPath(`/blocks/${encodeURIComponent(blockId)}/events`), blob);
      },
    };
  }

  /** Global timers behind the Timers seam. In the DOM lib these return numbers. */
  const browserTimers: Timers = {
    setTimeout: (handler, ms) => setTimeout(handler, ms),
    clearTimeout: (handle) => {
      clearTimeout(handle);
    },
    setInterval: (handler, ms) => setInterval(handler, ms),
    clearInterval: (handle) => {
      clearInterval(handle);
    },
  };

  /** A KeystrokeRow being buffered, so t_up_ms/dwell_ms can be filled before it is sent. */
  type BufferedRow = { -readonly [K in keyof KeystrokeRow]: KeystrokeRow[K] };

  /**
   * Buffers one block's keystroke rows and uploads them idempotently (design doc 12.4; T1.6).
   *
   * It implements KeystrokeSink. onRow copies a row and waits for its key-up or keyUpWaitMs; onKeyUp
   * fills that row's t_up_ms/dwell_ms and releases it. A row is sent only once it is ready (key-up
   * arrived, or keyUpWaitMs passed with t_up_ms left null — owner answer 1). Ready rows flush every
   * flushRows, every flushIntervalMs, and on an explicit flush() at block end; a block-end flush
   * never forces a pending row out. Failed sends retry with exponential backoff forever. On pagehide
   * every remaining row is sent with navigator.sendBeacon. onRow/onKeyUp only enqueue and never
   * throw; all network happens off the key-handler path. No statistics, no randomness.
   */
  export class EventBuffer implements KeystrokeSink {
    readonly #blockId: string;
    readonly #transport: EventTransport;
    readonly #timers: Timers;
    readonly #config: EventBufferConfig;
    readonly #lifecycleTarget: PageHideTarget | null;
    readonly #onPageHide = (): void => {
      this.#beaconRemaining();
    };

    /** Rows waiting for their key-up or the keyUpWaitMs timeout, keyed by seq. */
    readonly #pending = new Map<number, BufferedRow>();
    /** The keyUpWaitMs readiness timer per pending seq. */
    readonly #waitTimers = new Map<number, number>();
    /** Rows ready to send, in the order they became ready. */
    readonly #ready: BufferedRow[] = [];

    #intervalTimer: number | null = null;
    #immediateTimer: number | null = null;
    #retryTimer: number | null = null;
    #sending = false;
    #backoffExponent = 0;
    #closed = false;

    constructor(options: EventBufferOptions) {
      this.#blockId = options.blockId;
      this.#transport = options.transport ?? createFetchTransport();
      this.#timers = options.timers ?? browserTimers;
      this.#config = { ...DEFAULT_EVENT_BUFFER_CONFIG, ...options.config };
      this.#lifecycleTarget =
        options.lifecycleTarget === undefined
          ? typeof window === "undefined"
            ? null
            : window
          : options.lifecycleTarget;
      this.#intervalTimer = this.#timers.setInterval(() => {
        this.#flush();
      }, this.#config.flushIntervalMs);
      this.#lifecycleTarget?.addEventListener("pagehide", this.#onPageHide);
    }

    /** Buffer a new row (KeystrokeSink). Cheap, never throws into the key handler. */
    onRow(row: KeystrokeRow): void {
      try {
        if (this.#closed) {
          return;
        }
        const buffered: BufferedRow = { ...row };
        this.#pending.set(buffered.seq, buffered);
        const seq = buffered.seq;
        const handle = this.#timers.setTimeout(() => {
          this.#promote(seq);
        }, this.#config.keyUpWaitMs);
        this.#waitTimers.set(seq, handle);
      } catch {
        // The KeystrokeSink contract forbids throwing into the key handler.
      }
    }

    /** Fill a buffered row's key-up and release it (KeystrokeSink). Late/unknown key-ups are dropped. */
    onKeyUp(update: KeyUpUpdate): void {
      try {
        if (this.#closed) {
          return;
        }
        const row = this.#pending.get(update.seq);
        if (row === undefined) {
          // Row already ready or sent (owner answer 1): keyup stays null; drop it.
          return;
        }
        row.t_up_ms = update.t_up_ms;
        row.dwell_ms = update.dwell_ms;
        this.#promote(update.seq);
      } catch {
        // Never throw into the key handler.
      }
    }

    /** Send every ready row now (block end, design doc 12.4). Pending rows keep waiting (owner answer 1). */
    flush(): void {
      this.#flush();
    }

    /** Stop all timers and the pagehide listener. Call when the attempt is finished or discarded. */
    dispose(): void {
      this.#closed = true;
      if (this.#intervalTimer !== null) {
        this.#timers.clearInterval(this.#intervalTimer);
        this.#intervalTimer = null;
      }
      if (this.#immediateTimer !== null) {
        this.#timers.clearTimeout(this.#immediateTimer);
        this.#immediateTimer = null;
      }
      if (this.#retryTimer !== null) {
        this.#timers.clearTimeout(this.#retryTimer);
        this.#retryTimer = null;
      }
      for (const handle of this.#waitTimers.values()) {
        this.#timers.clearTimeout(handle);
      }
      this.#waitTimers.clear();
      this.#lifecycleTarget?.removeEventListener("pagehide", this.#onPageHide);
    }

    /** Move a pending row to the ready queue and clear its wait timer. */
    #promote(seq: number): void {
      const row = this.#pending.get(seq);
      if (row === undefined) {
        return;
      }
      this.#pending.delete(seq);
      const handle = this.#waitTimers.get(seq);
      if (handle !== undefined) {
        this.#timers.clearTimeout(handle);
        this.#waitTimers.delete(seq);
      }
      this.#ready.push(row);
      if (this.#ready.length >= this.#config.flushRows) {
        this.#scheduleImmediate();
      }
    }

    /** Arm a 0 ms flush so the key handler never does network work directly. */
    #scheduleImmediate(): void {
      if (
        this.#closed ||
        this.#immediateTimer !== null ||
        this.#sending ||
        this.#retryTimer !== null
      ) {
        return;
      }
      this.#immediateTimer = this.#timers.setTimeout(() => {
        this.#immediateTimer = null;
        this.#flush();
      }, 0);
    }

    /** Send the whole ready queue as one batch, single-flight. */
    #flush(): void {
      if (this.#closed || this.#sending || this.#retryTimer !== null) {
        return;
      }
      if (this.#ready.length === 0) {
        return;
      }
      const batch = this.#ready.splice(0, this.#ready.length);
      this.#sending = true;
      this.#transport.send(this.#blockId, { events: batch }).then(
        () => {
          this.#onSendSuccess();
        },
        () => {
          this.#onSendError(batch);
        },
      );
    }

    #onSendSuccess(): void {
      this.#sending = false;
      this.#backoffExponent = 0;
      if (!this.#closed && this.#ready.length > 0) {
        this.#scheduleImmediate();
      }
    }

    #onSendError(batch: BufferedRow[]): void {
      this.#ready.unshift(...batch);
      this.#sending = false;
      if (this.#closed) {
        return;
      }
      const delay = Math.min(
        this.#config.backoffBaseMs * 2 ** this.#backoffExponent,
        this.#config.backoffMaxMs,
      );
      this.#backoffExponent += 1;
      this.#retryTimer = this.#timers.setTimeout(() => {
        this.#retryTimer = null;
        this.#flush();
      }, delay);
    }

    #beaconRemaining(): void {
      if (this.#closed) {
        return;
      }
      const remaining: BufferedRow[] = [...this.#ready, ...this.#pending.values()];
      if (remaining.length === 0) {
        return;
      }
      this.#transport.sendBeacon(this.#blockId, { events: remaining });
    }
  }

  import re
  from typing import Literal, Self

  from pydantic import BaseModel, Field, model_validator

  KeystrokeOutcomeLiteral = Literal["correct", "error", "backspace"]

  _TYPED_KEY = re.compile(r"[a-z ]")


  class KeystrokeEventIn(BaseModel):
      """One keystroke_events row as the browser sends it (T1.4 KeystrokeRow; owner answers 4, 10).

      Field names are the column names. block_id is not here (it is the path, owner answer 4) and
      release_to_press_ms is never sent (owner answer 3). Nullable fields are required but may be
      null. The validator enforces the D13 charset and the backspace/t_up invariants; an invalid row
      rejects the whole batch with 422.
      """

      seq: int = Field(ge=0)
      key: str
      code: str = Field(min_length=1)
      t_down_ms: float
      t_up_ms: float | None
      dwell_ms: float | None
      iki_ms: float | None
      target_index: int = Field(ge=0)
      expected_char: str | None
      outcome: KeystrokeOutcomeLiteral
      first_attempt: bool | None
      after_pause: bool
      handler_ms: float
      dispatch_lag_ms: float

      @model_validator(mode="after")
      def _check_invariants(self) -> Self:
          if self.outcome == "backspace":
              if self.key != "Backspace":
                  raise ValueError("a backspace row must have key 'Backspace'")
              if self.expected_char is not None or self.first_attempt is not None:
                  raise ValueError("a backspace row must have null expected_char and first_attempt")
          else:
              if self.key == "Backspace" or _TYPED_KEY.fullmatch(self.key) is None:
                  raise ValueError("key must be a single a-z or space character")
              if self.expected_char is None or self.first_attempt is None:
                  raise ValueError("a non-backspace row must set expected_char and first_attempt")
          if (self.t_up_ms is None) != (self.dwell_ms is None):
              raise ValueError("t_up_ms and dwell_ms must both be null or both set")
          return self

      events: list[KeystrokeEventIn]

  """Idempotent batch insert into keystroke_events (design doc 12.4; T1.6 owner answers 1, 3, 5)."""

  from dataclasses import dataclass

  from sqlalchemy.dialects.sqlite import insert as sqlite_insert
  from sqlmodel import Session

  from typist.models import KeystrokeEvent, SessionBlock
  from typist.schemas.events import KeystrokeEventIn


  class BlockNotFoundError(LookupError):
      """No session_blocks row has the given id."""


  @dataclass(frozen=True)
  class EventIngestResult:
      """Rows inserted versus skipped as duplicates by store_events."""

      accepted: int
      duplicates: int


  def store_events(
      session: Session, block_id: str, events: list[KeystrokeEventIn]
  ) -> EventIngestResult:
      """Insert a batch of keystroke rows for one block, idempotently, and commit.

      Uses INSERT ... ON CONFLICT (block_id, seq) DO NOTHING (section 12.4), so re-sending a batch
      never duplicates rows: accepted is the number actually inserted (the statement rowcount),
      duplicates is the rest (owner answer 5). release_to_press_ms is left NULL (owner answer 3). An
      empty batch is a no-op returning 0/0. Raises BlockNotFoundError, inserting nothing, if the
      block does not exist (the FK would otherwise raise; the router turns this into 404 — owner
      answer 11b).
      """
      if session.get(SessionBlock, block_id) is None:
          raise BlockNotFoundError(block_id)
      if not events:
          return EventIngestResult(accepted=0, duplicates=0)
      values = [{"block_id": block_id, **event.model_dump()} for event in events]
      statement = (
          sqlite_insert(KeystrokeEvent)
          .values(values)
          .on_conflict_do_nothing(index_elements=["block_id", "seq"])
      )
      result = session.exec(statement)
      accepted = result.rowcount
      session.commit()
      return EventIngestResult(accepted=accepted, duplicates=len(events) - accepted)
  ```

      "/blocks/{block_id}/events",
      response_model=EventBatchResult,
      responses={status.HTTP_404_NOT_FOUND: {"description": "block not found"}},
  )
  def post_block_events(
      block_id: str,
      batch: EventBatchIn,
      session: Annotated[Session, Depends(get_session)],
  ) -> EventBatchResult:
      """Insert the batch for block_id and return accepted/duplicate counts.

      Idempotent: re-sending a batch stores it once (ON CONFLICT DO NOTHING). Returns 404 if the

          ) from error

## 8. Review focus

1. **Idempotency and counts (the acceptance criterion).** `store_events` uses
   `sqlite_insert(...).on_conflict_do_nothing(index_elements=["block_id","seq"])` and reads
   `result.rowcount` (not a pre-count); `duplicates = len(events) - accepted`. Confirm a single
   multi-row insert (list `.values`) so `rowcount` is the number actually inserted, and that the
   acceptance and partial-overlap tests pass with the exact counts.
2. **Ready-row-only sending and the 2 s rule (owner answer 1).** In `EventBuffer`: `onRow` arms a
   `keyUpWaitMs` timer; `onKeyUp` fills and promotes a still-pending row; a key-up after a row is
   already ready/sent is dropped (`#pending` lookup misses); `flush()`/interval/threshold send only
   `#ready`; a block-end `flush()` never forces pending rows. Tests 1–8.
3. **Single-flight retry/backoff never drops a batch (brief risks 1, 6).** On failure the batch is
   `unshift`ed back to `#ready`, one send is ever in flight, backoff is `min(base*2**n, max)` then
   `n++`, reset on success, forever. Tests 9, 10.
4. **Handlers stay cheap and never throw (12.5; brief risk 5/6).** `onRow`/`onKeyUp` only touch maps
   and arm one timer, inside `try/catch`; network is always deferred via `#scheduleImmediate`'s 0 ms
   timer or the interval/retry timers. Confirm no `transport.send` is reachable synchronously from a
   handler.
5. **Validation exactly matches owner answer 10, and 404 vs 422.** `KeystrokeEventIn` enforces
   `seq>=0`, outcome literal, key charset/`"Backspace"`, non-empty code, backspace⇔null
   expected_char/first_attempt, t_up⇔dwell nullness; the router maps `BlockNotFoundError` to 404 and
   lets Pydantic produce 422. No monotonic-seq or expected_char-charset check sneaks in.

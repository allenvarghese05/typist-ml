## 1. Summary

- `apps/web/src/telemetry/KeystrokeRecorder.ts`: a plain class (no React, no `window`, no
  `document`) fed keydown/keyup events and blur/focus notifications by its caller (T1.5). It
  filters events, drives the merged `TextCursor`, and emits one snake_case `keystroke_events` row
  per recorded keydown, then one key-up update (`seq`, `t_up_ms`, `dwell_ms`) per matching key-up,
  paired by `code`, whenever it arrives.
- `apps/web/src/telemetry/types.ts` gains `KeystrokeRow`, `KeyUpUpdate` and `KeystrokeSink`, the
  output interface T1.6's EventBuffer will implement. Existing types are unchanged.
- `__tests__/KeystrokeRecorder.test.ts`: 29 tests with plain-object synthetic events (owner answer
  9) covering repeat, modifiers, overlapping keys (the acceptance criterion), plus timing, IKI,
  pause flag, block-done and overhead fields.
- No config change, no new dependency, `TextCursor.ts` untouched.

## 2. Design

- **Plain class, injected everything.** Constructor options: `targetText` (the recorder builds
  its own private `TextCursor`, so nobody else can move it), `blockStartMs` (owner answer 3),
  `sink` (output), optional `now` clock (default `() => performance.now()`). The clock is the only
  source of `handler_ms`/`dispatch_lag_ms`, so tests get exact overhead values without real
  timing. No randomness is involved.
- **Output: push to a sink, rows are never mutated after hand-off.** `sink.onRow(row)` at keydown
  with `t_up_ms` and `dwell_ms` both `null`; `sink.onKeyUp({ seq, t_up_ms, dwell_ms })` when the
  matching key-up arrives, early or late (owner answers 2 and 4). T1.6 merges the update into an
  unsent row or forwards a late one (`record_key_up`); the 2-second rule, batching and `block_id`
  are T1.6's. This mirrors Figure 5's `EventBuffer.completeDwell(seq, tUp)` and keeps the
  append-only spirit (only key-up time and dwell ever change).
- **Keydown pipeline (order matters):**
  1. `start = now()` (handler start, owner answer 1).
  2. `repeat` true: return. The key is still held; its open entry stays.
  3. Any other keydown is a new physical press: delete `open[code]`. This is owner answer 8 read
     literally ("a key-up always pairs with the most recent press of that key"): if the most
     recent press was filtered or ignored, its key-up pairs with nothing. It also closes brief
     edge case 4 (chord released out of order).
  4. Blurred, or Ctrl/Meta/Alt held: return (12.1, owner answers 5 and 7).
  5. `key === "Backspace"` calls `cursor.backspace()`; `key` matching `/^[a-z ]$/` calls
     `cursor.type(key)`; anything else returns. This is the same regex `TextCursor.type()`
     validates, so the cursor can never throw from the handler. `shiftKey` is not read: the
     character decides (owner answer 7), so Shift+Space and Shift+Backspace are accepted and `"A"`
     is dropped by the regex.
  6. Cursor returned `null` (block done): return; no row, no `seq`, no IKI anchor, no open entry.
  7. Build the row: `t_down_ms = timeStamp − blockStartMs`; `iki_ms` from the previous
     **recorded** row's `t_down_ms` (null at seq 0); cursor fields copied; `after_pause` takes and
     clears the pending flag; `dispatch_lag_ms = start − timeStamp`. Advance `seq`, IKI anchor,
     set `open[code]`.
  8. `row.handler_ms = now() − start`, then `sink.onRow(row)`. The sink call is delivery, outside
     the measured span (flag F1).
- **Key-up:** look up `open[code]`; if absent return; else delete it and emit the update with
  `dwell_ms = t_up_ms − t_down_ms`. No filters (modifiers at release time, blur state and
  `isDone()` are irrelevant to a real release; the last character's key-up arrives after the block
  is done and must still pair). No clock read (owner answer 1: key-ups are not measured).
- **Blur/focus:** `onBlur()` sets `blurred = true` and `pausePending = true`; `onFocus()` sets
  `blurred = false`. Keydowns are dropped while blurred, so the pending flag lands on the first row
  recorded after focus returns, whatever key it is (owner answer 6, T1.2 answer 11c); several
  blurs give one flag; a blur before the first key flags seq 0 (D24 literal).
- **Times are not rounded.** Every stored time is the float `event.timeStamp − blockStartMs`, and
  `dwell_ms`/`iki_ms` subtract those stored values. Values like `0.3 − 0.1 = 0.19999999999999998`
  are kept as is. The golden fixture's 0.25 ms grid is a fixture convention only (T1.2 answer
  13a); the tests here pick whole numbers and halves so every subtraction is exact.
- **Event type:** `KeyInput = Pick<KeyboardEvent, "key" | "code" | "repeat" | "ctrlKey" |
  "metaKey" | "altKey" | "shiftKey" | "timeStamp">` (owner answer 9). A real `KeyboardEvent` is
  assignable to it (T1.5 passes events straight through); tests pass plain objects.
- **No `isTrusted` check** (owner answer 10). **No stats, no 2000 ms pause logic, no
  release-to-press** (CLAUDE.md, D24, T1.2 answer 10a).
- Rejected: the recorder returning the row from `onKeyDown` instead of a sink (T1.5 would have to
  route rows to T1.6 itself, and key-ups would need a second channel anyway). Rejected: a
  `performance` global swapped in tests (`vi.spyOn(performance, "now")` works but couples tests to
  call order on a global; injection is simpler).

### Interface for T1.5 and T1.6 (contract)

| Who | Uses | Meaning |
|---|---|---|
| T1.5 | `new KeystrokeRecorder({ targetText, blockStartMs: performance.now(), sink })` when the block becomes active | One recorder per block (a restarted block gets a new one: `seq` from 0, new origin). |
| T1.5 | `onKeyDown(e)`, `onKeyUp(e)` from its `window` listeners | Pass the real `KeyboardEvent`; `preventDefault` is T1.5's. |
| T1.5 | `onBlur()`, `onFocus()` | From `window` blur/focus. Call `onBlur()` right after construction if the page is not focused. |
| T1.5 | `isDone()` | True once the cursor reached the end of the target. |
| T1.6 | implements `KeystrokeSink` | `onRow(row)`: a new row, `t_up_ms`/`dwell_ms` null. `onKeyUp(update)`: fill that `seq`'s `t_up_ms` and `dwell_ms` (copy, do not mutate the row object), or forward it as a late key-up. Must not throw. |

  /**
   * One keystroke_events row as the browser produces it (design doc 8.1, 12.1, 12.2; T1.4 owner
   * answers 1 to 8). Field names are the column names. id and block_id are not the recorder's
   * (T1.6 adds block_id); release_to_press_ms is never a row field (T1.2 answer 10a). Every time
   * is in milliseconds, exactly KeyboardEvent.timeStamp minus the block start, never rounded.
   */
  export interface KeystrokeRow {
    /** Order within the block, contiguous from 0; one per recorded keydown. */
    readonly seq: number;
    /** KeyboardEvent.key: a to z, " " or "Backspace". */
    readonly key: string;
    /** KeyboardEvent.code (the physical key), stored as given. */
    readonly code: string;
    /** Key-down time relative to the block start. */
    readonly t_down_ms: number;
    /** Null in the row the recorder emits; T1.6 fills it from a KeyUpUpdate (or the server does). */
    readonly t_up_ms: number | null;
    /** t_up_ms minus t_down_ms; null while t_up_ms is null. */
    readonly dwell_ms: number | null;
    /** t_down_ms minus the previous recorded row's t_down_ms (Backspace rows count); null at seq 0. */
    readonly iki_ms: number | null;
    /** From TextCursor (T1.3). */
    readonly target_index: number;
    /** From TextCursor; null for Backspace. */
    readonly expected_char: string | null;
    /** From TextCursor. */
    readonly outcome: Outcome;
    /** From TextCursor; null for Backspace. */
    readonly first_attempt: boolean | null;
    /** True only on the first row recorded after a blur (D24; T1.4 owner answer 6). */
    readonly after_pause: boolean;
    /** Clock at the end of the keydown handler minus clock at its start (T1.4 owner answer 1). */
    readonly handler_ms: number;
    /** Clock at the keydown handler's start minus KeyboardEvent.timeStamp (T1.4 owner answer 1). */
    readonly dispatch_lag_ms: number;
  }

  /** A key-up paired by code with the row it releases; sent whenever it arrives (T1.4 answer 4). */
  export interface KeyUpUpdate {
    /** seq of the row this key-up belongs to. */
    readonly seq: number;
    /** Key-up time relative to the block start. */
    readonly t_up_ms: number;
    /** t_up_ms minus that row's t_down_ms. */
    readonly dwell_ms: number;
  }

  /**
   * Where KeystrokeRecorder sends its output (implemented by T1.6's EventBuffer). Calls are
   * synchronous, from inside the key handlers, so implementations must be cheap and must not throw.
   */
  export interface KeystrokeSink {
    /** A new row, created at keydown, with t_up_ms and dwell_ms null. Never mutated afterwards. */
    onRow(row: KeystrokeRow): void;
    /** The key-up for an earlier row, early or late. */
    onKeyUp(update: KeyUpUpdate): void;
  }

- `apps/web/src/telemetry/KeystrokeRecorder.ts` (complete):
  ```ts
  import { TextCursor } from "./TextCursor";
  import type { CursorStep, KeystrokeRow, KeystrokeSink } from "./types";

  /**
   * The KeyboardEvent fields the recorder reads (T1.4 owner answer 9). A real KeyboardEvent is
   * assignable; tests pass plain objects. shiftKey is part of the shape but not read: the
   * character decides (T1.4 owner answer 7).
   */
  export type KeyInput = Pick<
    KeyboardEvent,
    "key" | "code" | "repeat" | "ctrlKey" | "metaKey" | "altKey" | "shiftKey" | "timeStamp"
  >;

  /** Everything a KeystrokeRecorder needs; one recorder per block. */
  export interface KeystrokeRecorderOptions {
    /** The block's target text; TextCursor rules apply (one or more characters a to z or space). */
    readonly targetText: string;
    /**
     * Block start on the browser's performance clock, the same clock as KeyboardEvent.timeStamp
     * (T1.4 owner answer 3). Every stored time is event.timeStamp minus this value.
     */
    readonly blockStartMs: number;
    /** Receives rows at keydown and key-up updates (T1.6's EventBuffer). */
    readonly sink: KeystrokeSink;
    /**
     * High-resolution clock for handler_ms and dispatch_lag_ms. Defaults to performance.now().
     * Tests inject a fake clock so overhead values are exact.
     */
    readonly now?: () => number;
  }

  /** A key the cursor's type() accepts: one lowercase letter a to z or a space (D13, 12.1). */
  const TYPED_KEY = /^[a-z ]$/;
  const BACKSPACE = "Backspace";

  /** A recorded keydown still waiting for its key-up. */
  interface OpenPress {
    readonly seq: number;
    readonly tDownMs: number;
  }

  /** KeystrokeRow while it is being built, so handler_ms can be written last. */
  type WritableRow = { -readonly [K in keyof KeystrokeRow]: KeystrokeRow[K] };

  /**
   * Turns one block's keyboard events into keystroke_events rows (design doc 12.1, 12.2, Figure 5).
   *
   * The caller attaches the window listeners and forwards keydown, keyup, blur and focus; the
   * recorder never touches window or document (T1.4 owner answer 5). A keydown becomes a row only
   * when it is not a repeat, no Ctrl, Meta or Alt is held, the page is not blurred, its key is a to
   * z, space or Backspace (Shift does not matter, uppercase is dropped; owner answer 7), and the
   * TextCursor does not ignore it because the block is done. The row is sent to the sink at once
   * with t_up_ms and dwell_ms null. Its key-up is paired by code with the most recent press of that
   * physical key and sent as a KeyUpUpdate whenever it arrives (owner answers 4 and 8).
   *
   * No statistics, no 2000 ms pause rule, no release-to-press, no randomness.
   */
  export class KeystrokeRecorder {
    readonly #cursor: TextCursor;
    readonly #blockStartMs: number;
    readonly #sink: KeystrokeSink;
    readonly #now: () => number;
    /** Open presses by KeyboardEvent.code. */
    readonly #open = new Map<string, OpenPress>();
    /** seq of the next recorded row. */
    #nextSeq = 0;
    /** t_down_ms of the previous recorded row; null before the first row. */
    #lastDownMs: number | null = null;
    /** True between onBlur() and onFocus(); keydowns are dropped. */
    #blurred = false;
    /** True from a blur until the next recorded row takes the after_pause flag. */
    #pausePending = false;

    /**
     * @throws RangeError if `blockStartMs` is not a finite number, or (from TextCursor) if
     *   `targetText` is empty or has a character other than a to z or space.
     */
    constructor(options: KeystrokeRecorderOptions) {
      if (!Number.isFinite(options.blockStartMs)) {
        throw new RangeError(
          `KeystrokeRecorder blockStartMs must be a finite number: ${String(options.blockStartMs)}`,
        );
      }
      this.#cursor = new TextCursor(options.targetText);
      this.#blockStartMs = options.blockStartMs;
      this.#sink = options.sink;
      // An arrow, not performance.now itself: calling the method unbound throws in browsers.
      this.#now = options.now ?? (() => performance.now());
    }

    /** True once the cursor has reached the end of the target; later keys are ignored. */
    isDone(): boolean {
      return this.#cursor.isDone();
    }

    /**
     * Handles one keydown. Records at most one row and sends it to the sink.
     *
     * handler_ms spans from the first statement to just before sink.onRow (cursor call and row
     * creation included); dispatch_lag_ms is the clock at the first statement minus
     * event.timeStamp (owner answer 1). Filtered and ignored keydowns produce nothing.
     */
    onKeyDown(e: KeyInput): void {
      const start = this.#now();
      if (e.repeat) {
        // Auto-repeat of a key that is still held: same press, keep its open entry.
        return;
      }
      // A new press of this physical key: an older press still open has lost its key-up, and the
      // next key-up belongs to this press, recorded or not (owner answer 8).
      this.#open.delete(e.code);
      if (this.#blurred || e.ctrlKey || e.metaKey || e.altKey) {
        return;
      }
      let step: CursorStep | null;
      if (e.key === BACKSPACE) {
        step = this.#cursor.backspace();
      } else if (TYPED_KEY.test(e.key)) {
        step = this.#cursor.type(e.key);
      } else {
        return;
      }
      if (step === null) {
        // The block is done: not recorded (T1.2 answer 9b, T1.3 contract).
        return;
      }
      const tDownMs = e.timeStamp - this.#blockStartMs;
      const seq = this.#nextSeq;
      const row: WritableRow = {
        seq,
        key: e.key,
        code: e.code,
        t_down_ms: tDownMs,
        t_up_ms: null,
        dwell_ms: null,
        iki_ms: this.#lastDownMs === null ? null : tDownMs - this.#lastDownMs,
        target_index: step.target_index,
        expected_char: step.expected_char,
        outcome: step.outcome,
        first_attempt: step.first_attempt,
        after_pause: this.#pausePending,
        handler_ms: 0,
        dispatch_lag_ms: start - e.timeStamp,
      };
      this.#pausePending = false;
      this.#nextSeq = seq + 1;
      this.#lastDownMs = tDownMs;
      this.#open.set(e.code, { seq, tDownMs });
      row.handler_ms = this.#now() - start;
      this.#sink.onRow(row);
    }

    /**
     * Handles one keyup. If its code has an open press, sends that row's key-up time and dwell to
     * the sink. Never filtered and never timed: a release is real whenever it arrives, including
     * after the block is done or while blurred (owner answers 1 and 4).
     */
    onKeyUp(e: KeyInput): void {
      const open = this.#open.get(e.code);
      if (open === undefined) {
        return;
      }
      this.#open.delete(e.code);
      const tUpMs = e.timeStamp - this.#blockStartMs;
      this.#sink.onKeyUp({ seq: open.seq, t_up_ms: tUpMs, dwell_ms: tUpMs - open.tDownMs });
    }

    /** The window lost focus: drop keydowns until onFocus(); flag the next recorded row (D24). */
    onBlur(): void {
      this.#blurred = true;
      this.#pausePending = true;
    }

    /** The window regained focus: keydowns are recorded again. */
    onFocus(): void {
      this.#blurred = false;
    }
  }
  ```

    code: string,
    timeStamp: number,
    modifiers: Partial<Modifiers> = {},
  ): KeyInput {
    return {
      key,
      code,
      timeStamp,
      repeat: false,
      ctrlKey: false,
      metaKey: false,
      altKey: false,
      shiftKey: false,
      ...modifiers,
    };
  }

  interface Collector {
    readonly sink: KeystrokeSink;
    readonly rows: KeystrokeRow[];
    readonly keyUps: KeyUpUpdate[];
  }

  function collector(): Collector {
    const rows: KeystrokeRow[] = [];
    const keyUps: KeyUpUpdate[] = [];
    return {
      rows,
      keyUps,
      sink: {
        onRow: (row) => {
          rows.push(row);
        },
        onKeyUp: (update) => {
          keyUps.push(update);
        },
      },
    };
  }

  interface Harness extends Collector {
    readonly recorder: KeystrokeRecorder;
    /** Keydown at START + at; the clock reads START + at + LAG for the whole handler. */
    down(key: string, code: string, at: number, modifiers?: Partial<Modifiers>): void;
    /** Keyup at START + at. */
    up(key: string, code: string, at: number, modifiers?: Partial<Modifiers>): void;
  }

  /** A recorder with block start START and a clock that makes handler_ms 0, dispatch_lag_ms LAG. */
  function setup(targetText: string): Harness {
    let clock = 0;
    const output = collector();
    const recorder = new KeystrokeRecorder({
      targetText,
      blockStartMs: START,
      sink: output.sink,
      now: () => clock,
    });
    return {
      ...output,
      recorder,
      down(key, code, at, modifiers) {
        clock = START + at + LAG;
        recorder.onKeyDown(keyEvent(key, code, START + at, modifiers));
      },
      up(key, code, at, modifiers) {
        recorder.onKeyUp(keyEvent(key, code, START + at, modifiers));
      },
    };
  }

  function pick<K extends keyof KeystrokeRow>(
    rows: readonly KeystrokeRow[],
    field: K,
  ): Array<KeystrokeRow[K]> {
    return rows.map((row) => row[field]);
  }

## Flags

- **F1** `handler_ms` ends just before `sink.onRow(row)`: the handler's own work (filter, cursor,
  row creation) is measured; the sink call (T1.6's buffer) is not, because the row must already
  hold the value when it is handed off. If the owner wants the sink cost included, it would need a
  separate mechanism; not done here.
- **F2** Owner answer 8 is applied to filtered and ignored presses too: any non-repeat keydown of
  a code removes that code's open entry, so a key-up after Ctrl+`a` (or after a post-done key)
  never pairs with an older, unreleased `a` (brief edge case 4). This follows the answer's wording
  "a key-up always pairs with the most recent press of that key".
- **F3** Key-ups are never filtered, including while blurred (owner answer 4 "every matching
  key-up whenever it arrives"); answer 5's "drops keys between blur and focus" is applied to
  keydowns only.
- **F4** `dispatch_lag_ms` assumes `event.timeStamp` and `performance.now()` share the performance
  timeline. True in current Chrome, Firefox and Safari as far as known, but **verify on the owner's
  browser in T1.5**: an epoch-based `timeStamp` would make every lag a huge number (and every
  `t_down_ms` wrong too unless `blockStartMs` came from the same clock).
- **F5** No rounding: stored times can carry float noise (`1234.5000000000001`). IKI can be 0 if
  the browser coarsens two timestamps to the same value; values are stored as computed, never
  clamped (12.6 checks own oddities).
- **F6** Owner answer 2 moves `iki_ms`/`dwell_ms` computation to the browser, refining T1.2 answer
  10a. No ADR is written in this task; the owner may want one.
- **F7** `KeyInput` includes `shiftKey` (answer 9's field list) though the recorder never reads it
  (answer 7). The design-doc layout's `overhead.ts` is not created (no stats in the browser).
- **F8** The design PDF still cannot be rendered here; design rules come from the brief's verbatim
  quotations.

# T3.1 Plan — Character n-gram model and Markov generator; tune beta

## 1. Summary

This plan implements `Arm.MARKOV` (design doc §13.4, D03), the statistical pseudo-word drill generator for Typist-ML's 4-arm experiment. It creates an in-memory order-3 character n-gram model trained on the 20,000-word corpus weighted by $\sqrt{\text{frequency}}$, adds the `MarkovGenerator` with $\beta$ target-transition bias, word-length bounds (3–10 chars), and a 2-use word cap, and introduces the `0009_markov_config` migration seeding `markov_beta = 10.0` (tuned so median density lands inside $[0.15, 0.40]$). Finally, it registers `Arm.MARKOV` into `build_default_generators` in `worker.py`, unblocking autonomous background generation for Markov drill jobs.

## 2. Design

- **Trigram character n-gram model (`CharNGramModel` in `typist/corpus/ngram.py`):** An order-3 Markov model conditions each character on the preceding 2 characters ($P(c_i \mid c_{i-2}, c_{i-1})$) with word-start sentinel `'^'` (initial context `('^', '^')`) and word-end sentinel `'$'`. Training builds directly from `WordIndex` in memory in under 30ms, avoiding uncommitted file dependencies under `data/` and keeping CI fast on Linux and macOS.
  - *Rejected alternative:* Serializing `ngram.json` to disk during `typist corpus build`. Rejected because in-memory training takes < 30ms and avoids uncommitted artifacts under `data/` (owner answer 1).
- **Steered pseudo-word sampling with $\beta$ bias (`MarkovGenerator` in `typist/generation/markov.py`):** When the immediately preceding character $c_{i-1}$ matches the first character of any target bigram, the transition probabilities of the second character(s) are multiplied by $\beta$ before normalization (§13.4 step 2). To guarantee phonotactic validity and fairness:
  1. Sentinels mask out `'$'` when word length is $< 3$ so words are at least 3 letters (owner answer 4a).
  2. Sampling terminates at character 10 if `'$'` has not been chosen, ensuring words never exceed 10 letters (owner answer 4b).
  3. Context dead-ends discard the candidate word and resample from scratch with the seeded RNG (owner answer 5).
  4. Pseudo-words are tracked and capped at 2 uses per drill, matching `ControlGenerator` and `HeuristicGenerator` (owner answer 8), guaranteeing the drill never trips the validator's `max_word_repeats` (3) rule.
  5. Text accumulates until adding the next word would exceed `spec.length_chars` (300 characters), cutting cleanly on a word boundary; measured drill lengths land between 290 and 300 characters, strictly satisfying the 270-character validator floor.
  - *Rejected alternative:* Steering first letters of target bigrams at word start. Rejected because §13.4 step 2 strictly prescribes conditioning on the preceding character and relying on $\beta$ tuning plus the worker's 5-attempt retry loop for coverage (owner answer 7).
- **Beta tuning (`markov_beta = 10.0`):** In the 4-arm experiment (D03, §3.3, §9.1), each targeted arm receives 4 target bigrams (`assignment_per_set = 4`). Empirical evaluation reveals that the default $\beta = 4.0$ yields a median density of ~0.11 (under-targeting below $d_{min}=0.15$). Tuning $\beta$ to 10.0 achieves a median density of 0.1754 on the standard 4-target set (`common`), safely inside $[d_{min}, d_{max}] = [0.15, 0.40]$ without triggering repetition rules or overshooting $d_{max}=0.40$, satisfying the verbatim acceptance criteria. (3-target sets naturally have ~3/4 density of 4-target sets; calibration of $d_{min}$ across all arm sizes is handled in T3.4).
  - *Rejected alternative:* Leaving $\beta = 4.0$ in `experiment_config`. Rejected because $\beta = 4.0$ fails the acceptance criterion by having median density below 0.15.
- **Worker registration (`worker.py`):** `build_default_generators()` reads `markov_beta` from `experiment_config` (raising `MissingConfigError("markov_beta")` if absent) and registers `Arm.MARKOV: MarkovGenerator(index, validator_config, markov_beta)`.

```python
"""Order-3 character n-gram model trained from WordIndex (design doc 7, 13.4 step 1).

CharNGramModel is an in-memory character-level trigram model: given context (c_{i-2}, c_{i-1}), it
provides the weighted transition counts for c_i. Word start is represented by sentinel ('^', '^');
word end is represented by sentinel '$'. Padded characters for word 'the' are:
  ['^', '^', 't', 'h', 'e', '$']
Transitions:
  ('^', '^') -> 't'
  ('^', 't') -> 'h'
  ('t', 'h') -> 'e'
  ('h', 'e') -> '$'
Each word's transitions are weighted by sqrt(frequency) (13.4 step 1). Training takes < 30ms for
20,000 words. Pure Python 3.12: no external model files, no mlx-lm, runs identically on Linux CI.
"""

from collections import defaultdict
from collections.abc import Mapping
from dataclasses import dataclass
import math
from typing import Final

from typist.corpus.word_index import WordIndex

START_CHAR: Final[str] = "^"
END_CHAR: Final[str] = "$"
START_CONTEXT: Final[tuple[str, str]] = (START_CHAR, START_CHAR)


@dataclass(frozen=True)
class CharNGramModel:
    """Immutable order-3 character n-gram model with start and end sentinels."""

    transitions: dict[tuple[str, str], dict[str, float]]

    @classmethod
    def from_word_index(cls, index: WordIndex) -> "CharNGramModel":
        """Build a character trigram model from WordIndex words weighted by sqrt(frequency)."""
        counts: dict[tuple[str, str], dict[str, float]] = defaultdict(lambda: defaultdict(float))
        for word in index.words:
            freq = index.frequencies.get(word, 0.0)
            if freq <= 0.0:
                continue
            weight = math.sqrt(freq)
            chars = [START_CHAR, START_CHAR, *word, END_CHAR]
            for i in range(2, len(chars)):
                ctx = (chars[i - 2], chars[i - 1])
                c = chars[i]
                counts[ctx][c] += weight
        # Convert to standard dict of dicts
        frozen_transitions: dict[tuple[str, str], dict[str, float]] = {
            ctx: dict(next_map) for ctx, next_map in counts.items()
        }
        return cls(transitions=frozen_transitions)

    def get_transitions(self, context: tuple[str, str]) -> Mapping[str, float]:
        """Return the next character weights for context, or an empty mapping if unknown."""
        return self.transitions.get(context, {})
```

```python
"""The Markov drill generator: character n-gram pseudo-words with beta target bias (design doc 13.4).

MarkovGenerator implements Arm.MARKOV (D03). Pseudo-words are sampled character-by-character from an
order-3 character n-gram model (CharNGramModel) with sentinels '^' and '$'. When sampling, if the
immediately preceding character is the first letter of a target bigram, the transition probability
of that bigram's second letter is multiplied by markov_beta before renormalization (13.4 step 2;
owner answer 7). Pseudo-words are constrained to 3-10 characters (13.4 step 3; owner answer 4):
  - End marker '$' is masked out when word length < 3
  - If length reaches 10, the word is terminated
  - Dead-end contexts discard the candidate word and resample with the seeded RNG (owner answer 5)
Each pseudo-word is capped at _MAX_USES_PER_DRILL (2) uses per drill, matching control and heuristic
generators (owner answer 8). The generator stops when the next word would exceed spec.length_chars
(300), terminating cleanly at a word boundary (measured 290-300 characters, >= 270 floor).
Randomness is strictly random.Random(spec.seed). Pure: returns one DrillCandidate per call.
"""

from collections import defaultdict
import random
from typing import Final

from typist.corpus.ngram import CharNGramModel, END_CHAR, START_CHAR, START_CONTEXT
from typist.corpus.word_index import WordIndex
from typist.generation.base import Arm, DrillCandidate, DrillSpec
from typist.generation.sampling import weighted_choice
from typist.generation.validator import ValidatorConfig

_VERSION: Final[str] = "markov-v1"
_MAX_USES_PER_DRILL: Final[int] = 2  # Matches control.py and heuristic.py (owner answer 8)
_MIN_WORD_LEN: Final[int] = 3  # 13.4 step 3 pseudo-word bounds (owner answer 4)
_MAX_WORD_LEN: Final[int] = 10


class MarkovGenerator:
    """The 13.4 character-level Markov pseudo-word generator for Arm.MARKOV."""

    arm = Arm.MARKOV
    version = _VERSION

    def __init__(
        self,
        index: WordIndex,
        config: ValidatorConfig,
        beta: float,
        model: CharNGramModel | None = None,
    ) -> None:
        """index supplies words/frequencies for model training; config is accepted for uniform
        generator signature; beta is markov_beta from experiment_config; model can be injected
        or is trained from index."""
        self._config = config
        self._beta = beta
        self._model = model if model is not None else CharNGramModel.from_word_index(index)

    def _sample_word(
        self, rng: random.Random, target_map: dict[str, set[str]]
    ) -> str:
        """Sample one pseudo-word of 3 to 10 characters using the seeded RNG.

        Discard and retry if a dead end is reached before valid completion (owner answer 5).
        """
        while True:
            chars = [START_CHAR, START_CHAR]
            dead_end = False
            while True:
                word_len = len(chars) - 2
                if word_len == _MAX_WORD_LEN:
                    break
                ctx = (chars[-2], chars[-1])
                next_transitions = self._model.get_transitions(ctx)
                if not next_transitions:
                    dead_end = True
                    break
                prev_char = chars[-1]
                boosted_seconds = target_map.get(prev_char, set())
                candidates: list[str] = []
                weights: list[float] = []
                for char, base_weight in next_transitions.items():
                    if char == END_CHAR and word_len < _MIN_WORD_LEN:
                        continue
                    w = base_weight * (self._beta if char in boosted_seconds else 1.0)
                    candidates.append(char)
                    weights.append(w)
                if not candidates or sum(weights) <= 0.0:
                    dead_end = True
                    break
                next_char = weighted_choice(rng, candidates, weights)
                if next_char == END_CHAR:
                    break
                chars.append(next_char)
            word_len = len(chars) - 2
            if dead_end or word_len < _MIN_WORD_LEN:
                continue
            return "".join(chars[2:])

    def generate(self, spec: DrillSpec) -> DrillCandidate:
        """Compose one Markov drill candidate deterministically for spec.seed.

        Emits pseudo-words separated by single spaces up to spec.length_chars at a word boundary.
        """
        rng = random.Random(spec.seed)
        target_map: dict[str, set[str]] = defaultdict(set)
        for bigram in spec.target_bigrams:
            if len(bigram) == 2:
                target_map[bigram[0]].add(bigram[1])

        used: dict[str, int] = {}
        words: list[str] = []
        length = 0

        while True:
            word = self._sample_word(rng, target_map)
            if used.get(word, 0) >= _MAX_USES_PER_DRILL:
                continue
            addition = len(word) + (1 if words else 0)
            if length + addition > spec.length_chars:
                break
            used[word] = used.get(word, 0) + 1
            length += addition
            words.append(word)

        text = " ".join(words)
        return DrillCandidate(
            text=text,
            raw_output=text,
            generator_version=_VERSION,
            seed=spec.seed,
        )
```

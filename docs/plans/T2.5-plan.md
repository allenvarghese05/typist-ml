# T2.5 plan — Worker loop and GenerationService

*Architect blueprint. The builder implements this verbatim and makes no design decisions. The
brief's "## Owner answers" (1–5) are binding and are implemented exactly as written; nothing here
overrides them.*

## 1. Summary

When this plan is done: `generation/service.py` defines `derive_drill_seed`, `claim_next_job`
(single-statement atomic SQLite `UPDATE ... WHERE id = (SELECT ...) AND status = 'pending'
RETURNING id`), and `GenerationService` (`generate_with_retries` and `run_job`), which loads frozen
weak bigrams from `bigram_assignment` (empty for `control`), runs the up-to-5-attempt
validate-and-retry loop through `validate()`, flushes accepted `Drill` rows before inserting
`GenerationAttempt` rows (satisfying `fk_generation_attempts_drill_id_drills`), preserves partial
progress across multi-drill jobs, and logs all rejected attempts and job failures (`status =
"failed"`, `retries += 1`, `error`, `finished_at`). `worker.py` defines the atomic heartbeat-file
helpers (`heartbeat_path`, `write_heartbeat`, `read_heartbeat_age_s`), `build_default_generators`,
`run_worker_once`, and `run_worker` (graceful `SIGINT`/`SIGTERM` shutdown). `schemas/health.py` and
`api/routers/health.py` expose `worker_heartbeat_age_s: float | None = None` on `GET /api/v1/health`
without ever affecting `status` or HTTP status code; `cli.py` adds `typist worker [--once]
[--poll-interval]`; `.gitignore` adds `*.heartbeat`. Unit and integration tests prove atomic job
claiming, attempt/failure logging, partial-progress recovery, seed determinism, CLI worker
execution, and `/health` heartbeat age.

## 2. Design

`GenerationService` (`services/api/src/typist/generation/service.py`) is the single database writer
for drill generation (§6.1, §9.1). Generators remain pure `DrillSpec -> DrillCandidate` functions
and `validate` remains a pure fairness gate. `GenerationService` receives a `Session`, a generator
registry `Mapping[Arm, DrillGenerator]`, `known_words: Collection[str]`, an optional
`ValidatorConfig` (loaded via `load_validator_config(session)` if `None`), and `max_attempts: int =
DEFAULT_MAX_ATTEMPTS` (5). Passing a `Mapping[Arm, DrillGenerator]` lets M2 wire `{Arm.CONTROL:
ControlGenerator(...), Arm.HEURISTIC: HeuristicGenerator(...)}` while M3 adds `MARKOV` and `LLM`,
and lets unit/integration tests inject deterministic fake generators to exercise retry, exhaustion,
and exception paths without touching the 20,000-word corpus or `mlx-lm`.

**Atomic job claim (`claim_next_job`):** In SQLite WAL mode, a two-step `SELECT` followed by
`UPDATE` can race across connections unless serialized by a write lock. `claim_next_job(session,
now=None)` executes a single atomic `UPDATE generation_jobs SET status = 'running', started_at =
:now WHERE id = (SELECT id FROM generation_jobs WHERE status = 'pending' ORDER BY created_at ASC,
id ASC LIMIT 1) AND status = 'pending' RETURNING id` (owner answer 4; §6.2, §10.2), commits the
transaction immediately, and returns `session.get(GenerationJob, claimed_id)` (or `None` when no
pending row exists). Because SQLite serializes `UPDATE` statements at the database level and checks
`status = 'pending'` in the outer `WHERE`, two workers or overlapping poll calls can never claim the
same job.

**Seed derivation (`derive_drill_seed`):** Per owner answer 3 and §13.5, `derive_drill_seed`
computes `hashlib.sha256(f"{assignment_seed}:{participant_id}:{arm.value}:{drill_number}:{job_retries}:{attempt}".encode("utf-8")).digest()`
and returns `int.from_bytes(digest[:8], "big") & 0x7FFF_FFFF` (a deterministic non-negative 31-bit
integer fitting both SQLite `INTEGER` and JS safe integers, never using Python's randomized
`hash()`). `drill_number` is the count of existing `Drill` rows for `(participant_id, arm)` at the
moment that drill slot starts, so replenishment jobs for the same participant and arm never reuse
`drill_number = 0`. Including `job_retries` ensures that if a failed job is later reset to `pending`
and re-run, its attempts get a fresh seed sequence (§10.2 Figure 8: `"job retries + 1, new seed
later"`).

**Validate-and-retry loop (`generate_with_retries`):** Runs `attempt` from `0` to
`self._max_attempts - 1` (default 5). On `attempt == 0`, if `spec.seed != 0`, it uses `spec.seed`;
otherwise it derives the seed via `derive_drill_seed(assignment_seed, spec.participant_id,
spec.arm, drill_number, 0, job_retries)`. On `attempt > 0`, if `spec.seed != 0` and
`assignment_seed == 0` (direct caller passing a custom base seed), it derives
`derive_drill_seed(spec.seed, spec.participant_id, spec.arm, drill_number, attempt, job_retries)`;
otherwise it derives `derive_drill_seed(assignment_seed, spec.participant_id, spec.arm,
drill_number, attempt, job_retries)`. For each attempt it calls `generator.generate(attempt_spec)`
and `validate(candidate.text, attempt_spec, self._validator_config, self._known_words)`. If
accepted, it constructs `Drill(..., status="ready")`, adds and flushes it **first** so `drill.id`
exists in `drills`, then (when `job_id` is provided) adds `GenerationAttempt(job_id=job_id,
drill_id=drill.id, accepted=True, reject_reasons=[], ...)`, commits, and returns the `Drill` (brief
Edge Case 1). If rejected, when `job_id` is provided it adds and commits
`GenerationAttempt(job_id=job_id, drill_id=None, accepted=False, reject_reasons=[r.value for r in
result.reasons], ...)` so the audit row survives even when all attempts fail. If all
`self._max_attempts` attempts are rejected, it raises `DrillGenerationExhaustedError`.

**Job execution (`run_job`):** Looks up the `GenerationJob` by `job_id` (raising `JobNotFoundError`
if absent). If `job.status == "pending"`, transitions it to `"running"` and sets `job.started_at =
utc_now()`.Inside a `try` block, it verifies `job.arm` has a registered generator in
`self._generators`, loads generation config keys (`d_min`, `d_max`, `drill_length_chars`,
`assignment_seed`) from `experiment_config`, and resolves `target_bigrams`: for `Arm.CONTROL`,
`target_bigrams = ()` regardless of `bigram_assignment` rows (owner answer 4; brief Edge Case 4);
for targeted arms (`HEURISTIC`, `MARKOV`, `LLM`), it queries `BigramAssignment` for
`(job.participant_id, job.arm)` ordered by `baseline_rank ASC, bigram ASC` and raises
`MissingAssignmentError` if empty (brief Edge Case 5). To support idempotent partial-progress
recovery (owner answer 2), it counts already-accepted attempts for `job.id` (`SELECT count(*) FROM
generation_attempts WHERE job_id = :job_id AND drill_id IS NOT NULL`) and generates `remaining =
max(0, job.requested - already_accepted)` drills. Before each drill slot, it queries the current
count of `Drill` rows for `(job.participant_id, arm)` as `drill_number`. When all requested drills
succeed, it sets `job.status = "done"`, `job.error = None`, `job.finished_at = utc_now()`, and
commits. If `DrillGenerationExhaustedError` or any setup/generator `Exception` occurs, it rolls back
any uncommitted flush, re-fetches `job`, increments `job.retries += 1`, sets `job.status =
"failed"`, `job.error = str(exc)`, `job.finished_at = utc_now()`, commits, logs the failure with
`logger.error(...)`, and returns the list of drills accepted before the failure.

**Worker loop and heartbeat (`worker.py`, `schemas/health.py`, `api/routers/health.py`):** Per owner
answer 1, the worker writes its UTC epoch timestamp (`f"{utc_now().timestamp():.6f}\n"`) atomically
via a `.tmp` sibling and `os.replace` to `heartbeat_path(db_path)` (`<db_path.name>.heartbeat` in
`db_path.parent`) on startup and on every poll cycle (before and after job execution). `GET
/api/v1/health` reads `request.app.state.settings.db_path` (via a `get_settings_dep` or `Request` on
`app.state.settings`), computes `read_heartbeat_age_s(db_path)` as `max(0.0, round((utc_now() -
heartbeat_dt).total_seconds(), 3))` when the heartbeat file exists and parses cleanly, or `None`
when missing/unparseable or when `db == "error"`. This requires no database table, so unmigrated
databases in `test_health.py` never fail with `OperationalError: no such table`, and Linux CI (where
the worker never runs) always gets `status: "ok", db: "ok", worker_heartbeat_age_s: None`.

Rejected: storing the heartbeat in SQLite `experiment_config` or a new table (breaks unmigrated-DB
health checks in `test_health.py` and causes write contention with WAL readers/writers). Rejected:
auto-requeueing failed jobs to `pending` inside `run_job` (risks infinite loops on unachievable
specs and hides failures from `/admin/jobs`; owner answer 2).

  ```python
  """GenerationService and atomic job claiming (design doc 6.2, 9.1, 10.2, 13.5; T2.5).

  GenerationService is the only class that talks to SQLite during drill generation (9.1). Pure
  generators (control, heuristic, markov, llm) turn a DrillSpec into a DrillCandidate without touching
  the database; GenerationService loads the frozen bigram_assignment rows and experiment_config keys,
  derives deterministic per-attempt seeds, runs the shared validate() gate up to max_attempts (5)
  times per drill, logs every candidate in generation_attempts, and inserts accepted drills with
  status='ready'. On an accepted attempt, the Drill row is flushed before inserting the
  GenerationAttempt row so fk_generation_attempts_drill_id_drills is satisfied (brief edge case 1).
  No mlx-lm import here, so this module runs on Linux CI (CLAUDE.md; D09).
  """

  from collections.abc import Collection, Mapping
  from dataclasses import dataclass, replace
  from datetime import datetime
  import hashlib
  import logging
  from typing import Final

  import sqlalchemy as sa
  from sqlmodel import Session, col, select

  from typist.db import utc_now
  from typist.generation.base import Arm, DrillCandidate, DrillGenerator, DrillSpec
  from typist.generation.validator import (
      MissingConfigError,
      ValidatorConfig,
      load_validator_config,
      validate,
  )
  from typist.models import (
      BigramAssignment,
      Drill,
      ExperimentConfig,
      GenerationAttempt,
      GenerationJob,
  )

  logger = logging.getLogger(__name__)

  DEFAULT_MAX_ATTEMPTS: Final[int] = 5

  _SERVICE_CONFIG_KEYS: Final[tuple[str, ...]] = (
      "drill_length_chars",
      "d_min",
      "d_max",
      "assignment_seed",
  )


  class GenerationError(RuntimeError):
      """Base error for drill generation orchestration failures."""


  class JobNotFoundError(GenerationError):
      """The requested generation_jobs.id does not exist."""


  class UnregisteredArmError(GenerationError):
      """No DrillGenerator is registered for the job's arm."""


  class MissingAssignmentError(GenerationError):
      """A targeted arm job has no frozen bigram_assignment rows for (participant_id, arm)."""


  class DrillGenerationExhaustedError(GenerationError):
      """All max_attempts candidate generations for a single drill were rejected by the validator."""


  @dataclass(frozen=True)
  class _ServiceConfig:
      """experiment_config parameters needed to build a DrillSpec and derive seeds."""

      length_chars: int
      min_density: float
      max_density: float
      assignment_seed: int


  def _load_service_config(session: Session) -> _ServiceConfig:
      """Read drill_length_chars, d_min, d_max, and assignment_seed from experiment_config."""
      values: dict[str, object] = {}
      for key in _SERVICE_CONFIG_KEYS:
          row = session.get(ExperimentConfig, key)
          if row is None:
              raise MissingConfigError(key)
          values[key] = row.value
      return _ServiceConfig(
          length_chars=int(str(values["drill_length_chars"])),
          min_density=float(str(values["d_min"])),
          max_density=float(str(values["d_max"])),
          assignment_seed=int(str(values["assignment_seed"])),
      )


  def derive_drill_seed(
      assignment_seed: int,
      participant_id: str,
      arm: Arm,
      drill_number: int,
      attempt: int,
      job_retries: int = 0,
  ) -> int:
      """Return a deterministic non-negative 31-bit integer seed for one generation attempt (13.5).

      Hashes f"{assignment_seed}:{participant_id}:{arm.value}:{drill_number}:{job_retries}:{attempt}"
      with SHA-256 and masks the top 8 bytes to 0x7FFF_FFFF (fits signed 32-bit / SQLite INTEGER and
      JS safe integers, and never uses Python's randomized hash(); owner answer 3).
      """
      payload = (
          f"{assignment_seed}:{participant_id}:{arm.value}:{drill_number}:{job_retries}:{attempt}"
      )
      digest = hashlib.sha256(payload.encode("utf-8")).digest()
      return int.from_bytes(digest[:8], "big") & 0x7FFF_FFFF


  def claim_next_job(session: Session, now: datetime | None = None) -> GenerationJob | None:
      """Atomically claim the oldest pending generation job and return it, or None if none pending.

      Uses a single UPDATE ... WHERE id = (SELECT id FROM generation_jobs WHERE status = 'pending'
      ORDER BY created_at ASC, id ASC LIMIT 1) AND status = 'pending' RETURNING id statement (section
      6.2, 10.2; owner answer 4), commits immediately, and returns the refreshed GenerationJob. Two
      concurrent workers or poll cycles can never claim the same job.
      """
      claimed_at = now if now is not None else utc_now()
      stmt = sa.text(
          """
          UPDATE generation_jobs
          SET status = 'running', started_at = :started_at
          WHERE id = (
              SELECT id FROM generation_jobs
              WHERE status = 'pending'
              ORDER BY created_at ASC, id ASC
              LIMIT 1
          )
          AND status = 'pending'
          RETURNING id
          """
      ).bindparams(
          sa.bindparam("started_at", claimed_at, type_=sa.DateTime(timezone=True))
      )
      row = session.connection().execute(stmt).first()
      if row is None:
          session.rollback()
          return None
      claimed_id = str(row[0])
      session.commit()
      job = session.get(GenerationJob, claimed_id)
      if job is not None:
          session.refresh(job)
      return job


  class GenerationService:
      """Orchestrates drill generation, validation retries, attempt logging, and drill persistence."""

      def __init__(
          self,
          session: Session,
          generators: Mapping[Arm, DrillGenerator],
          known_words: Collection[str],
          validator_config: ValidatorConfig | None = None,
          max_attempts: int = DEFAULT_MAX_ATTEMPTS,
      ) -> None:
          """Initialize the service with a DB session, arm->generator mapping, and corpus word set.

          If validator_config is None, loads it on demand from experiment_config via
          load_validator_config(session). max_attempts defaults to 5 (section 10.2, 13.5).
          """
          if max_attempts < 1:
              raise ValueError("max_attempts must be >= 1")
          self._session = session
          self._generators = dict(generators)
          self._known_words = known_words
          self._validator_config = validator_config
          self._max_attempts = max_attempts

      def _get_validator_config(self) -> ValidatorConfig:
          if self._validator_config is None:
              self._validator_config = load_validator_config(self._session)
          return self._validator_config

      def _load_target_bigrams(self, participant_id: str, arm: Arm) -> tuple[str, ...]:
          """Return target bigrams for (participant_id, arm): () for CONTROL, else frozen rows."""
          if arm is Arm.CONTROL:
              return ()
          rows = self._session.exec(
              select(BigramAssignment)
              .where(
                  col(BigramAssignment.participant_id) == participant_id,
                  col(BigramAssignment.arm) == arm.value,
              )
              .order_by(col(BigramAssignment.baseline_rank), col(BigramAssignment.bigram))
          ).all()
          if not rows:
              raise MissingAssignmentError(
                  f"no bigram_assignment rows for participant {participant_id!r} and arm {arm.value!r}"
              )
          return tuple(row.bigram for row in rows)

      def _existing_drill_count(self, participant_id: str, arm: Arm) -> int:
          """Count existing Drill rows for (participant_id, arm) to determine the next drill_number."""
          stmt = (
              select(sa.func.count())
              .select_from(Drill)
              .where(
                  col(Drill.participant_id) == participant_id,
                  col(Drill.arm) == arm.value,
              )
          )
          return int(self._session.exec(stmt).one())

      def _accepted_drills_for_job(self, job_id: str) -> int:
          """Count already-accepted drills linked to job_id in generation_attempts."""
          stmt = (
              select(sa.func.count())
              .select_from(GenerationAttempt)
              .where(
                  col(GenerationAttempt.job_id) == job_id,
                  col(GenerationAttempt.drill_id).is_not(None),
              )
          )
          return int(self._session.exec(stmt).one())

      def generate_with_retries(
          self,
          spec: DrillSpec,
          *,
          job_id: str | None = None,
          assignment_seed: int = 0,
          drill_number: int = 0,
          job_retries: int = 0,
      ) -> Drill:
          """Generate and validate one drill with up to max_attempts tries, saving attempts and drill.

          For attempt 0, uses spec.seed if non-zero, else derive_drill_seed(assignment_seed,
          spec.participant_id, spec.arm, drill_number, 0, job_retries). For attempt > 0, derives a
          fresh seed via derive_drill_seed (using assignment_seed if non-zero else spec.seed as the
          base seed). Every attempt is validated with validate(); when job_id is given, every attempt
          is persisted to generation_attempts. On acceptance, inserts and flushes the Drill row
          (status='ready') BEFORE inserting the GenerationAttempt row so fk_generation_attempts_drill_id_drills
          is satisfied, commits, and returns the Drill. Raises DrillGenerationExhaustedError if all
          max_attempts tries are rejected.
          """
          generator = self._generators.get(spec.arm)
          if generator is None:
              raise UnregisteredArmError(f"no generator registered for arm {spec.arm.value!r}")
          validator_config = self._get_validator_config()
          base_seed = assignment_seed if assignment_seed != 0 else spec.seed
          last_reasons: tuple[str, ...] = ()

          for attempt in range(self._max_attempts):
              if attempt == 0 and spec.seed != 0:
                  attempt_seed = spec.seed
              else:
                  attempt_seed = derive_drill_seed(
                      base_seed,
                      spec.participant_id,
                      spec.arm,
                      drill_number,
                      attempt,
                      job_retries,
                  )
              attempt_spec = replace(spec, seed=attempt_seed)
              candidate: DrillCandidate = generator.generate(attempt_spec)
              result = validate(
                  candidate.text, attempt_spec, validator_config, self._known_words
              )
              reason_tokens = [reason.value for reason in result.reasons]

              if result.accepted:
                  drill = Drill(
                      participant_id=attempt_spec.participant_id,
                      arm=attempt_spec.arm.value,
                      target_bigrams=list(attempt_spec.target_bigrams),
                      text=candidate.text,
                      target_density=result.metrics.target_density,
                      mean_word_len=result.metrics.mean_word_len,
                      real_word_ratio=result.metrics.real_word_ratio,
                      generator_version=candidate.generator_version,
                      model_id=candidate.model_id,
                      prompt_version=candidate.prompt_version,
                      seed=candidate.seed,
                      status="ready",
                  )
                  self._session.add(drill)
                  self._session.flush()
                  if job_id is not None:
                      attempt_row = GenerationAttempt(
                          job_id=job_id,
                          drill_id=drill.id,
                          raw_output=candidate.raw_output,
                          clean_text=candidate.text,
                          density=result.metrics.target_density,
                          accepted=True,
                          reject_reasons=[],
                          gen_ms=candidate.gen_ms,
                          gen_tokens=candidate.gen_tokens,
                          tokens_per_sec=candidate.tokens_per_sec,
                          peak_memory_mb=candidate.peak_memory_mb,
                      )
                      self._session.add(attempt_row)
                  self._session.commit()
                  self._session.refresh(drill)
                  return drill

              last_reasons = tuple(reason_tokens)
              if job_id is not None:
                  rejected_row = GenerationAttempt(
                      job_id=job_id,
                      drill_id=None,
                      raw_output=candidate.raw_output,
                      clean_text=candidate.text,
                      density=result.metrics.target_density,
                      accepted=False,
                      reject_reasons=reason_tokens,
                      gen_ms=candidate.gen_ms,
                      gen_tokens=candidate.gen_tokens,
                      tokens_per_sec=candidate.tokens_per_sec,
                      peak_memory_mb=candidate.peak_memory_mb,
                  )
                  self._session.add(rejected_row)
                  self._session.commit()

          raise DrillGenerationExhaustedError(
              f"exhausted {self._max_attempts} attempts for participant {spec.participant_id!r} "
              f"arm {spec.arm.value!r} drill {drill_number} (last reasons: {list(last_reasons)})"
          )

      def run_job(self, job_id: str) -> list[Drill]:
          """Run a generation job to completion or failure, returning the drills generated in this run.

          Loads the GenerationJob (raising JobNotFoundError if missing). If status is 'pending',
          transitions it to 'running' with started_at=utc_now(). Resolves the arm generator, config,
          and target bigrams (empty for CONTROL; frozen bigram_assignment rows for targeted arms).
          Generates the remaining requested drills (job.requested minus any drills already accepted
          for this job_id) via generate_with_retries, committing each drill and attempt as they happen.
          When all requested drills are ready, marks job.status='done', job.error=None,
          job.finished_at=utc_now(). On DrillGenerationExhaustedError or any other setup/generator
          exception, increments job.retries += 1, sets job.status='failed', job.error=str(exc),
          job.finished_at=utc_now(), commits, logs the failure, and returns the drills generated
          before the failure (owner answer 2).
          """
          job = self._session.get(GenerationJob, job_id)
          if job is None:
              raise JobNotFoundError(f"no generation_jobs row with id {job_id!r}")
          if job.status == "pending":
              job.status = "running"
              job.started_at = utc_now()
              self._session.add(job)
              self._session.commit()
              self._session.refresh(job)

          created_drills: list[Drill] = []
          try:
              arm = Arm(job.arm)
              if arm not in self._generators:
                  raise UnregisteredArmError(f"no generator registered for arm {arm.value!r}")
              service_config = _load_service_config(self._session)
              self._get_validator_config()
              target_bigrams = self._load_target_bigrams(job.participant_id, arm)
              already_accepted = self._accepted_drills_for_job(job.id)
              remaining = max(0, job.requested - already_accepted)

              for _ in range(remaining):
                  drill_number = self._existing_drill_count(job.participant_id, arm)
                  seed = derive_drill_seed(
                      service_config.assignment_seed,
                      job.participant_id,
                      arm,
                      drill_number,
                      0,
                      job.retries,
                  )
                  spec = DrillSpec(
                      participant_id=job.participant_id,
                      arm=arm,
                      target_bigrams=target_bigrams,
                      length_chars=service_config.length_chars,
                      min_density=service_config.min_density,
                      max_density=service_config.max_density,
                      seed=seed,
                  )
                  drill = self.generate_with_retries(
                      spec,
                      job_id=job.id,
                      assignment_seed=service_config.assignment_seed,
                      drill_number=drill_number,
                      job_retries=job.retries,
                  )
                  created_drills.append(drill)

              job = self._session.get(GenerationJob, job_id)
              if job is not None:
                  job.status = "done"
                  job.error = None
                  job.finished_at = utc_now()
                  self._session.add(job)
                  self._session.commit()
          except Exception as exc:
              self._session.rollback()
              failed_job = self._session.get(GenerationJob, job_id)
              if failed_job is not None:
                  failed_job.retries += 1
                  failed_job.status = "failed"
                  failed_job.error = str(exc)
                  failed_job.finished_at = utc_now()
                  self._session.add(failed_job)
                  self._session.commit()
              logger.error("generation job %s failed: %s", job_id, exc)
          return created_drills
  ```

  ```python
  """Generation worker process: heartbeat file, generator wiring, and job poll loop (design doc 6.2,
  7, 10.2, 13.7, 14.1; D11; T2.5).

  The worker polls generation_jobs for pending rows, claims one atomically via claim_next_job, and
  runs it through GenerationService. On startup and on every poll cycle (before and after running a
  job) it writes a UTC timestamp to a sibling heartbeat file (<db_path.name>.heartbeat) atomically via
  os.replace (owner answer 1), which GET /api/v1/health reads to report worker_heartbeat_age_s without
  touching SQLite or failing on unmigrated databases. No mlx-lm import at module level, so tests and
  Linux CI can import and exercise the worker loop with control, heuristic, or fake generators (CLAUDE.md).
  """

  from collections.abc import Callable, Mapping
  from datetime import UTC, datetime
  import logging
  import os
  from pathlib import Path
  import signal
  import threading
  from types import FrameType
  from typing import Final

  from sqlalchemy import Engine
  from sqlmodel import Session

  from typist.corpus.word_index import WordIndex
  from typist.db import utc_now
  from typist.generation.base import Arm, DrillGenerator
  from typist.generation.control import ControlGenerator
  from typist.generation.heuristic import HeuristicGenerator
  from typist.generation.service import GenerationService, claim_next_job
  from typist.generation.validator import MissingConfigError, ValidatorConfig, load_validator_config
  from typist.models import ExperimentConfig

  logger = logging.getLogger(__name__)

  DEFAULT_POLL_INTERVAL_S: Final[float] = 2.0


  def heartbeat_path(db_path: Path) -> Path:
      """Return the sibling heartbeat file path for db_path: <db_path.name>.heartbeat (owner answer 1)."""
      return db_path.with_name(f"{db_path.name}.heartbeat")


  def write_heartbeat(db_path: Path, now: datetime | None = None) -> Path:
      """Atomically write the current UTC timestamp (ISO-8601) to heartbeat_path(db_path).

      Writes to a .tmp sibling and replaces the target with os.replace so /health never reads a
      partially-written file. Creates the parent directory if needed. Returns the heartbeat file path.
      """
      recorded_at = now if now is not None else utc_now()
      target = heartbeat_path(db_path)
      target.parent.mkdir(parents=True, exist_ok=True)
      tmp = target.with_name(f"{target.name}.{os.getpid()}.tmp")
      tmp.write_text(recorded_at.isoformat(), encoding="utf-8")
      os.replace(tmp, target)
      return target


  def read_heartbeat_age_s(db_path: Path, now: datetime | None = None) -> float | None:
      """Return the age in seconds (rounded to 3 decimals, >= 0.0) of the worker heartbeat, or None.

      Returns None when the heartbeat file does not exist or cannot be parsed as a timezone-aware or
      UTC ISO-8601 datetime (owner answer 1). Never raises on missing or malformed files.
      """
      target = heartbeat_path(db_path)
      try:
          raw = target.read_text(encoding="utf-8").strip()
          heartbeat_dt = datetime.fromisoformat(raw)
      except (OSError, ValueError):
          return None
      if heartbeat_dt.tzinfo is None:
          heartbeat_dt = heartbeat_dt.replace(tzinfo=UTC)
      reference = now if now is not None else utc_now()
      age = (reference - heartbeat_dt).total_seconds()
      return max(0.0, round(age, 3))


  def build_default_generators(
      session: Session, index: WordIndex
  ) -> tuple[ dict[Arm, DrillGenerator], ValidatorConfig ]:
      """Build the M2 default generators (CONTROL and HEURISTIC) from experiment_config and index.

      Reads validator_config via load_validator_config(session) and control_word_pool from
      experiment_config (raising MissingConfigError if absent). Returns (generators, validator_config).
      """
      validator_config = load_validator_config(session)
      pool_row = session.get(ExperimentConfig, "control_word_pool")
      if pool_row is None:
          raise MissingConfigError("control_word_pool")
      pool_size = int(pool_row.value)
      generators: dict[Arm, DrillGenerator] = {
          Arm.CONTROL: ControlGenerator(index, validator_config, pool_size),
          Arm.HEURISTIC: HeuristicGenerator(index, validator_config, pool_size),
      }
      return generators, validator_config


  def run_worker_once(
      engine: Engine,
      db_path: Path,
      index: WordIndex,
      *,
      generators: Mapping[Arm, DrillGenerator] | None = None,
      known_words: frozenset[str] | None = None,
  ) -> str | None:
      """Write a heartbeat, claim at most one pending job, run it if found, and write a heartbeat.

      Returns the claimed job_id if a job was claimed and processed, or None if no pending job existed.
      """
      write_heartbeat(db_path)
      words = known_words if known_words is not None else frozenset(index.words)
      with Session(engine) as session:
          job = claim_next_job(session)
          if job is None:
              return None
          job_id = job.id
          if generators is not None:
              arm_generators: Mapping[Arm, DrillGenerator] = generators
              validator_config: ValidatorConfig | None = None
          else:
              arm_generators, validator_config = build_default_generators(session, index)
          service = GenerationService(
              session,
              arm_generators,
              words,
              validator_config=validator_config,
          )
          service.run_job(job_id)
      write_heartbeat(db_path)
      return job_id


  def run_worker(
      engine: Engine,
      db_path: Path,
      index: WordIndex,
      *,
      once: bool = False,
      poll_interval_s: float = DEFAULT_POLL_INTERVAL_S,
      stop_event: threading.Event | None = None,
      generators: Mapping[Arm, DrillGenerator] | None = None,
  ) -> int:
      """Run the generation worker loop until stopped (or for a single cycle when once=True).

      Installs SIGINT/SIGTERM handlers (when called on the main thread) that set the stop event so
      `just dev` and Ctrl-C exit cleanly without leaving zombie processes (brief edge case 9). When
      a job is claimed, immediately loops to check for another pending job before sleeping; sleeps for
      poll_interval_s only when the queue is empty. Returns the number of jobs processed.
      """
      stopper = stop_event if stop_event is not None else threading.Event()
      known_words = frozenset(index.words)
      write_heartbeat(db_path)

      previous_sigint: Callable[[int, FrameType | None], object] | int | None = None
      previous_sigterm: Callable[[int, FrameType | None], object] | int | None = None
      install_signals = not once and threading.current_thread() is threading.main_thread()

      def _handle_signal(_signum: int, _frame: FrameType | None) -> None:
          stopper.set()

      if install_signals:
          previous_sigint = signal.getsignal(signal.SIGINT)
          previous_sigterm = signal.getsignal(signal.SIGTERM)
          signal.signal(signal.SIGINT, _handle_signal)
          signal.signal(signal.SIGTERM, _handle_signal)

      processed = 0
      try:
          if once:
              claimed = run_worker_once(
                  engine,
                  db_path,
                  index,
                  generators=generators,
                  known_words=known_words,
              )
              return 1 if claimed is not None else 0

          while not stopper.is_set():
              claimed = run_worker_once(
                  engine,
                  db_path,
                  index,
                  generators=generators,
                  known_words=known_words,
              )
              if claimed is not None:
                  processed += 1
                  continue
              stopper.wait(timeout=poll_interval_s)
      finally:
          if install_signals:
              if previous_sigint is not None:
                  signal.signal(signal.SIGINT, previous_sigint)
              if previous_sigterm is not None:
                  signal.signal(signal.SIGTERM, previous_sigterm)
      return processed
  ```

# T4.4 Implementation Plan — README with numbers, method, limitations, N: Every claim traces to a number in the database

## 1. Summary

This plan completes Milestone M4 by rewriting repository `README.md` into the public scientific record of the Typist-ML experiment, where every claim, interval, and table cell traces directly to SQLite database records. It enhances `run_pipeline_simulation` and CLI `test-pipeline` to support complete 10-practice-day reference pilot generation with unblinded builder attribution (`is_builder=True`, 14 completed sessions, ~28,450 keystrokes). It implements the `typist check-readme` CLI command and automated unit test suite `test_readme_claims.py` verifying the four §15.3 core elements, numerical traceability ($0.00$ claim divergence), and strict D18/D19 honesty constraints (unblinded builder disclosure, no WASM, no p-values).

## 2. Design

- **Traceability Architecture & Formatting:** `README.md` embeds the exact programmatic snippets produced by `services/api/src/typist/services/figures.py` (`format_generation_table`, `format_overhead_line`, `format_limitations_paragraph`) alongside the primary outcome chart `docs/figures/set_error_rate_change.png`. Outcome tables report Jeffreys 95% Beta credible intervals and empirical bootstrap 95% CIs matching `participant_results`.
  *Rejected alternative:* Manual markdown drafting with loose estimates was rejected because it introduces rounding errors and violates the acceptance criterion.
- **Reference Pilot Dataset Generation:** Resolves drill pool depletion in `run_pipeline_simulation` by triggering pool replenishment and worker generation inside the multi-day practice loop, enabling realistic 14-session pilot generation (`practice_days=10`, `error_rate=0.05`, `seed=42`, `is_builder=True`) in under 5 seconds.
  *Rejected alternative:* Mocking database queries with hardcoded fake objects was rejected because it breaks end-to-end relational consistency across `KeystrokeEvent`, `BigramStat`, and `Drill`.
- **Hermetic CI & Live Local Verification:** Adds automated unit tests in `services/api/tests/unit/test_readme_claims.py` executing against a deterministic in-memory/isolated reference database fixture in pytest, plus a CLI command `typist check-readme` for live local database verification.
  *Rejected alternative:* Requiring `data/typist.db` in git was rejected because `data/` is strictly gitignored per `GEMINI.md`.
- **Honesty Rules Enforcement (D18, D19, §18):** `README.md` explicitly discloses $N=1$ unblinded builder status, presents descriptive within-person comparisons, documents the four-arm RCT methodology alongside the two-set fallback contingency mode, links to pre-registration `docs/analysis-plan.md`, and rigorously excludes WASM, cloud AI, and p-value claims.
  *Rejected alternative:* Pooling builder and peer data or claiming statistical significance was rejected because $N=1$ precludes inferential population hypothesis testing.

### Step 2: Implement CLI command `typist check-readme` and Justfile recipe

- **Files touched:**
  - `services/api/src/typist/cli.py`
  - `justfile`

- **Exact change:**
  1. In `services/api/src/typist/cli.py`, add imports for `format_generation_table`, `format_overhead_line`, `format_limitations_paragraph`, `overview_report`, `participant_results`, and define the `check-readme` command:

  ```python
  @app.command("check-readme")
  def check_readme_command(
      readme_path: Path = typer.Option(  # noqa: B008
          REPO_ROOT / "README.md",
          "--readme",
          help="Path to README.md file to verify.",
      ),
      pid: str | None = typer.Option(
          None,
          "--pid",
          help="Participant id to verify against (default: first completed participant).",
      ),
  ) -> None:
      """Verify that all experimental claims and numbers in README.md trace to database records (T4.4)."""
      if not readme_path.exists():
          typer.echo(f"README file not found at {readme_path}", err=True)
          raise typer.Exit(code=1)

      readme_text = readme_path.read_text(encoding="utf-8")
      settings = get_settings()
      engine = create_db_engine(settings.db_path)

      with Session(engine) as session:
          if pid is not None:
              participant = session.get(Participant, pid)
              if participant is None:
                  typer.echo(f"Participant {pid!r} not found", err=True)
                  raise typer.Exit(code=1)
          else:
              participant = session.exec(
                  select(Participant)
                  .where(col(Participant.status) == "done")
                  .order_by(col(Participant.created_at))
              ).first()
              if participant is None:
                  typer.echo("no completed participants found (status 'done')", err=True)
                  raise typer.Exit(code=1)

          overview = overview_report(session)
          results = participant_results(session, participant.id)

          # 1. Section 15.3 item 1: Chart reference
          if "docs/figures/set_error_rate_change.png" not in readme_text:
              typer.echo("FAIL: Primary outcome chart reference missing in README", err=True)
              raise typer.Exit(code=1)

          # 2. Section 15.3 item 2: Generation summary table
          gen_table = format_generation_table(overview)
          for line in gen_table.strip().splitlines():
              if line.strip() not in readme_text:
                  typer.echo(f"FAIL: Generation table mismatch. Missing line: {line}", err=True)
                  raise typer.Exit(code=1)

          # 3. Section 15.3 item 3: Overhead line
          overhead_line = format_overhead_line(overview)
          if overhead_line not in readme_text:
              typer.echo(f"FAIL: Overhead line mismatch.\nExpected: {overhead_line}", err=True)
              raise typer.Exit(code=1)

          # 4. Section 15.3 item 4: Limitations paragraph
          limitations = format_limitations_paragraph(session, overview)
          if limitations not in readme_text:
              typer.echo(f"FAIL: Limitations paragraph mismatch.\nExpected: {limitations}", err=True)
              raise typer.Exit(code=1)

          # 5. Outcome metrics verification
          for s in results.sets:
              base_str = f"{s.baseline_errors}/{s.baseline_attempts}"
              ret_str = f"{s.retest_errors}/{s.retest_attempts}"
              if base_str not in readme_text:
                  typer.echo(
                      f"FAIL: Baseline counts for Set {s.set_label} ({base_str}) missing in README",
                      err=True,
                  )
                  raise typer.Exit(code=1)
              if ret_str not in readme_text:
                  typer.echo(
                      f"FAIL: Retest counts for Set {s.set_label} ({ret_str}) missing in README",
                      err=True,
                  )
                  raise typer.Exit(code=1)

          # 6. Honesty rules check (D18, D19)
          if "builder, unblinded" not in readme_text and "unblinded" not in readme_text:
              typer.echo("FAIL: Builder unblinded disclosure missing in README", err=True)
              raise typer.Exit(code=1)

          forbidden = ["webassembly", "wasm", "statistically significant", "p-value", "p < 0.05"]
          for term in forbidden:
              if term in readme_text.lower():
                  typer.echo(f"FAIL: Forbidden marketing/significance term {term!r} found in README", err=True)
                  raise typer.Exit(code=1)

      typer.echo("README claims check passed: all numbers trace to database records.")
  ```

  2. In `justfile`, add recipe:
  ```just

      #!/usr/bin/env bash

          exit 0
      fi
      cd services/api
      uv run --locked typist check-readme {{args}}
  ```

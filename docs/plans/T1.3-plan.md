## 2. Design

- **Cursor state.** `target` (readonly), a private index, and a private `#attempted: boolean[]`
  (true once a printable key has been recorded at that position; never cleared). This is exactly
  signed derivation A.4: "A printable key compares with `target[index]`, records `target_index =
  index`, then does `index += 1`. A Backspace does `index = max(index − 1, 0)` and records the new
  index. A key is a first attempt when no earlier row was recorded at its `target_index` by a
  printable key."
- **Return values (owner answers 1 and 7).** `type()` returns a `TypedStep`; `backspace()` returns
  a `BackspaceStep`. Each holds the four cursor-owned row fields in snake_case, so T1.4 can spread
  it into a row with no renaming. Both return `null` when the key is ignored because the block is
  done (T1.2 answer 9b, owner answer 2): `null` means "do not record a row".
- **Validation first, then the done check.** An invalid key throws even after `isDone()`. Owner
  answer 3: a bug upstream must be loud, never silently absorbed.
- **A wrong last character is permanent (owner answer 2, stated plainly).** The block is done the
  instant the index reaches `target.length`. Every later key is ignored, Backspace included. So a
  wrong final character stays as a first-attempt error and the typist cannot correct it. Real
  session data will show this; it is intended.
- **Target validation.** A target must match `^[a-z ]+$`: empty targets and any character outside
  a to z and space throw (owner answer 3). Leading, trailing or doubled spaces are not rejected;
  the shape of block text is the corpus's concern (flag F2).
- **Loading the fixture: Vite `?raw` import, no config change.**
  `import goldenText from "../../../../../services/api/tests/fixtures/golden_session.json?raw";`
  (five `..` from `src/telemetry/__tests__/` reach the repository root).
  - Types: `vite/client` (already in `tsconfig.app.json` `types`) declares
    `declare module '*?raw' { const src: string; export default src }` (checked:
    `vite@8.3.1/client.d.ts` lines 249 to 252). `tsc -b` needs no `resolveJsonModule`, and the JSON
    file never enters the TS program, so TS6307 cannot arise.

  ```ts
  /**
   * Per-keystroke values produced by TextCursor (design doc 12.3, Figure 5). Field names are the
   * keystroke_events column names (snake_case), the one naming scheme across the TypeScript/Python
   * boundary (T1.2 owner answer 3, T1.3 owner answer 7).
   */

  /** keystroke_events.outcome. A string union, not an enum (tsconfig erasableSyntaxOnly). */
  export type Outcome = "correct" | "error" | "backspace";

  /** What TextCursor.type() reports for a printable key (a to z or space). */
  export interface TypedStep {
    /** Position the key was compared with: the cursor index before the key moved it. */
    readonly target_index: number;
    /** target[target_index], a to z or " ". */
    readonly expected_char: string;
    /** "correct" when the key equals expected_char, otherwise "error". */
    readonly outcome: Exclude<Outcome, "backspace">;
    /** True when no earlier printable key was recorded at target_index (12.3). */
    readonly first_attempt: boolean;
  }

  /** What TextCursor.backspace() reports. */
  export interface BackspaceStep {
    /** Post-move cursor position, max(index - 1, 0) (D25). */
    readonly target_index: number;
    readonly expected_char: null;
    readonly outcome: "backspace";
    readonly first_attempt: null;
  }

  /** Either step: the four cursor-owned fields of one keystroke_events row. */
  export type CursorStep = TypedStep | BackspaceStep;
  ```

- `apps/web/src/telemetry/TextCursor.ts` (complete):
  ```ts
  import type { BackspaceStep, TypedStep } from "./types";

  /** One key the cursor accepts through type(): a lowercase letter a to z or a space (D13, 12.1). */
  const TYPED_CHAR = /^[a-z ]$/;
  /** A block's target text: one or more characters, each a to z or space (D13). */
  const TARGET_TEXT = /^[a-z ]+$/;

  /**
   * Aligns keystrokes with one block's target text by position (design doc 12.3, Figure 5).
   *
   * A printable key is compared with target[index], reported as correct or error, and the index
   * moves forward one position either way; there is no word-based realignment (T1.2 answer 9c).
   * Backspace moves the index back one position, never below 0, and reports the position it lands
   * on (D25). The first printable key ever recorded at a position is its first attempt; retyping
   * after a Backspace is not, whether or not the erased key was correct.
   *
   * The block is done when the index reaches target.length, whatever errors remain (T1.2 answer
   * 9a). After that every key, Backspace included, is ignored and returns null, so a wrong last
   * character stays a first-attempt error (T1.2 answer 9b, T1.3 owner answer 2).
   *
   * The cursor holds no display state and computes no statistics (T1.3 owner answers 4 and 5).
   */
  export class TextCursor {
    /** The block's target text. */
    readonly target: string;
    /** Position the next printable key is compared with, from 0 to target.length. */
    #index = 0;
    /** #attempted[i] is true once a printable key has been recorded at position i. Never cleared. */
    readonly #attempted: boolean[];

    /**
     * @param target The block's target text.
     * @throws RangeError if `target` is empty or has a character other than a to z or space.
     */
    constructor(target: string) {
      if (!TARGET_TEXT.test(target)) {
        throw new RangeError(
          `TextCursor target must be one or more characters a to z or space: ${JSON.stringify(target)}`,
        );
      }
      this.target = target;
      this.#attempted = Array.from({ length: target.length }, () => false);
    }

    /** Position the next printable key is compared with; only type() and backspace() move it. */
    get index(): number {
      return this.#index;
    }

    /** True when the index has reached the end of the target, regardless of errors left on screen. */
    isDone(): boolean {
      return this.#index === this.target.length;
    }

    /**
     * Records one printable key at the current index and moves the index forward by one.
     *
     * @param char The typed character (KeyboardEvent.key): exactly one of a to z or " ".
     * @returns The four row fields, or null when the block is already done (the key is ignored and
     *   must not be recorded).
     * @throws RangeError if `char` is not exactly one character a to z or space. Checked before the
     *   done check, so an invalid key throws even after the block is done.
     */
    type(char: string): TypedStep | null {
      if (!TYPED_CHAR.test(char)) {
        throw new RangeError(
          `TextCursor.type expects one character a to z or space: ${JSON.stringify(char)}`,
        );
      }
      if (this.isDone()) {
        return null;
      }
      const index = this.#index;
      const expected = this.target.charAt(index);
      const firstAttempt = this.#attempted[index] !== true;
      this.#attempted[index] = true;
      this.#index = index + 1;
      return {
        target_index: index,
        expected_char: expected,
        outcome: char === expected ? "correct" : "error",
        first_attempt: firstAttempt,
      };
    }

    /**
     * Moves the index back one position (not below 0). Never changes first-attempt state.
     *
     * @returns The row fields with target_index = the post-move index (D25; 0 for a Backspace at
     *   index 0, which is still a row), or null when the block is already done (ignored, not
     *   recorded).
     */
    backspace(): BackspaceStep | null {
      if (this.isDone()) {
        return null;
      }
      this.#index = Math.max(this.#index - 1, 0);
      return {
        target_index: this.#index,
        expected_char: null,
        outcome: "backspace",
        first_attempt: null,
      };
    }
  }
  ```

  ```ts
  import { describe, expect, it } from "vitest";
  import goldenText from "../../../../../services/api/tests/fixtures/golden_session.json?raw";
  import { TextCursor } from "../TextCursor";
  import type { CursorStep, Outcome } from "../types";

  // T1.3 acceptance: "All fixture outcomes match". Replays every keystroke row of the golden
  // fixture through one TextCursor and compares the four cursor-owned fields with exact equality
  // (T1.2 owner answers 2, 4, 13b). The fixture is read in place from services/api as text through
  // Vite's ?raw import (typed by vite/client); it is never copied (T1.2 answer 20). Nothing
  // session-level and no bigram stats are checked here (T1.3 owner answer 4; CLAUDE.md).

  const ROW_COUNT = 89;
  // Row 88's note: "Index 64 < 65, so isDone is false."
  const FINAL_INDEX = 64;

  interface GoldenRow {
    readonly seq: number;
    readonly key: string;
    readonly target_index: number;
    readonly expected_char: string | null;
    readonly outcome: Outcome;
    readonly first_attempt: boolean | null;
  }

  interface Golden {
    readonly targetText: string;
    readonly rows: readonly GoldenRow[];
  }

  function isRecord(value: unknown): value is Record<string, unknown> {
    return typeof value === "object" && value !== null && !Array.isArray(value);
  }

  function isOutcome(value: unknown): value is Outcome {
    return value === "correct" || value === "error" || value === "backspace";
  }

  /** Narrows one fixture row to the fields the replay reads. Checks types only, never values. */
  function parseRow(value: unknown, position: number): GoldenRow {
    if (!isRecord(value)) {
      throw new Error(`golden fixture: keystrokes[${position}] is not an object`);
    }
    const { seq, key, target_index, expected_char, outcome, first_attempt } = value;
    if (
      typeof seq !== "number" ||
      typeof key !== "string" ||
      typeof target_index !== "number" ||
      !(typeof expected_char === "string" || expected_char === null) ||
      !isOutcome(outcome) ||
      !(typeof first_attempt === "boolean" || first_attempt === null)
    ) {
      throw new Error(`golden fixture: keystrokes[${position}] has an unexpected field type`);
    }
    return { seq, key, target_index, expected_char, outcome, first_attempt };
  }

  /** Parses the fixture text into the target text and the keystroke rows, in file order. */
  function parseGolden(text: string): Golden {
    const root: unknown = JSON.parse(text);
    if (!isRecord(root)) {
      throw new Error("golden fixture: the root is not an object");
    }
    const session = root.session;
    const targetText = isRecord(session) ? session.target_text : undefined;
    const keystrokes = root.keystrokes;
    if (typeof targetText !== "string" || !Array.isArray(keystrokes)) {
      throw new Error("golden fixture: session.target_text or keystrokes is missing");
    }
    const rawRows: readonly unknown[] = keystrokes;
    return { targetText, rows: rawRows.map((row, position) => parseRow(row, position)) };
  }

  const golden = parseGolden(goldenText);

  /** Replays every row through a fresh cursor: "Backspace" rows call backspace(), others type(key). */
  function replay(): { cursor: TextCursor; steps: Array<CursorStep | null> } {
    const cursor = new TextCursor(golden.targetText);
    const steps = golden.rows.map((row) =>
      row.key === "Backspace" ? cursor.backspace() : cursor.type(row.key),
    );
    return { cursor, steps };
  }

  describe("TextCursor against the golden fixture", () => {
    it("reads all 89 rows in seq order", () => {
      expect(golden.rows).toHaveLength(ROW_COUNT);
      expect(golden.rows.map((row) => row.seq)).toStrictEqual(
        Array.from({ length: ROW_COUNT }, (_, position) => position),
      );
    });

    it("reproduces target_index, expected_char, outcome and first_attempt on every row", () => {
      const { steps } = replay();
      const expected = golden.rows.map((row) => ({
        target_index: row.target_index,
        expected_char: row.expected_char,
        outcome: row.outcome,
        first_attempt: row.first_attempt,
      }));
      expect(steps).toStrictEqual(expected);
    });

    it("ends at index 64 with the block unfinished", () => {
      const { cursor } = replay();
      expect(cursor.index).toBe(FINAL_INDEX);
      expect(cursor.isDone()).toBe(false);
    });
  });
  ```

  - `toStrictEqual` on the whole 89-element array: `null` and `undefined` are not interchangeable,
